# 規約検査：ある日わかった弟子 v4

## 規約8違反（確実）——系列で唯一、本文に太字が残っている

87行目：

> **開いた。**

隣国の錠が開く、この作品の山場である。そして山場だからこそ、規約8が名指しした失敗——**構文で作れなかった強調を、活字で作っている**——にそのまま該当する。検査した14作の本文で太字はこの一箇所だけであり、系列全体がこの規約を満たしたなかで、最も強調したかった一文だけが残った、という形になっている。

ana-no-koe v2 と tsugi-no-ji v3 は変更点欄に「太字を本文から全廃した」と明記している。本作 v4 の変更点欄は検算三件の修正を記しながら、この太字には触れていない。**見落としであって意図ではない**と推定できるが、判断は著者がする。

修正自体は一語である。規約8が挙げる代替（前を長くして当該文だけ短くする／独立した一行として前後を空ける）のうち、**後者は既に満たされている**——「開いた。」は既に独立行で、前後に区切りがある。太字を外すだけで構文上の強調は残る。

## 規約6（適合、ただし境界）

非現実の設定は一つ——鍵と錠の対応が修行で変わり、最後は一本の鍵で未知の錠まで開く。これは正則化→汎化の機構そのものであり、規約6の「良い例」として README に挙げられた当の機構である。適合。

境界として記す：序盤の「ふたつの錠に、同じところがあった」だけなら現実の錠前にもある。非現実が立ち上がるのは鍵が減っていく過程からで、設定の輪郭はやや遅れて現れる。

## 規約5（適合）

試行→返事は四組以上：八つで九つ→六つめの鍵で開く／取りすぎ→三月ふたつしか開かない／一本→九つ全部開く／隣国の錠→開いた。事態は複雑化しており、静止画ではない。

## 規約7（重複の一角）

宣言「事実を二つ並べて切る」は結末行（鍵一本を持ち帰る／師の腰に八つ）と合致する。ただしこの型は kotae-no-nuru-ido v3、tsugi-no-ji v3 と**三作で重複**しており、系列で最も使われている型になっている。系列順が宣言されていないため「直前の作と同じか」は判定できない。全体表を参照。

## 規約13違反（全数違反の一部）

`read_aloud_from:` / `read_alone_from:` の宣言なし。本作は「概念の種」系列で巻末に「きみが答えを見つけるかもしれない」と子どもの読者へ直接呼びかけており、**対象年齢の宣言が最も効く作品のひとつ**である。宣言が無いかぎり、この呼びかけが届く年齢かどうかは評価不能のままになる。

## 結論

規約8の一箇所が確実な違反で、修正は太字を外すだけである。ただし規約1により v4 は書き換えられないので、対応するなら v5 になる。その際に規約13の二段宣言を足せば、本作の確実な違反は消える。
