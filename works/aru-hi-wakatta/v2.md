# ある日わかった弟子（第二稿）

ある弟子が、師のもとで九つの型を習った。

型はひとつずつ、道具に宿っていた。九つの型には、九つの道具があった。

弟子は三年で、九つとも寸分たがわず出せるようになった。ひとつもまちがえなくなった。

「もう終わりですね」と弟子は言った。

師は答えず、道具をひとつ取り上げた。

**「八つで、九つを出しなさい」**

弟子は困った。取られたのは七つめの型の道具である。七つめを出す道具が、もう無い。

弟子は、残った八つを手に取って、代わりになるものを探した。

長くかかった。

だがある日、六つめの道具で、七つめの型が出た。

**ふたつの型に、同じところがあったのである。**

師は、道具をもうひとつ取り上げた。

「七つで、九つを出しなさい」

こうして道具は減っていった。

外から見ている者には、何も変わらなかった。弟子は三年目から、九つの型を寸分たがわず出し続けている。まちがいはひとつもない。

**測れるところは、三年目からずっと同じだった。**

減っていたのは、道具の数だけである。

**そして、道具の数を数えていた者は、ひとりもいなかった。**

五年たった。

ある朝、弟子の手には、道具がひとつしか残っていなかった。

そのひとつで、九つの型が全部出た。

弟子は、それを見た。

**九つの型は、九つではなかった。ひとつのことを、九つの道具で隠していただけだった。**

その日、弟子はためしに、習っていない型を出してみた。

出た。

弟子は師に聞いた。「なぜ、取り上げたのですか」

師は言った。

「持っているうちは、持っているものしか出せない」

弟子は聞いた。「なぜ、きょうだったのですか」

師は言った。

「わたしも知らない」

——弟子は、五年のあいだ何をしていたのか。
まちがえずにいたことか。手放していたことか。
外から見ていた者に、そのどちらかが見えただろうか。

# 巻末

## 一　この話は、何の話だったか

| 話のなか | ほんとうの名前 |
| --- | --- |
| 九つの型に九つの道具 | 型ごとの丸暗記。九つを別々に覚えている状態 |
| 三年でひとつもまちがえなくなる | **訓練したものに対する誤りがゼロになる。ここで普通は終わりだと思う** |
| 「もう終わりですね」 | 測れる誤りが無くなった地点 |
| 道具を取り上げる | **正則化。正しさを保ったまま、単純さへ加えられる圧** |
| 六つめの道具で七つめの型が出た | 型のあいだの共通構造が見つかった |
| 測れるところは三年目からずっと同じ | **訓練の誤りは平らなまま。変化は測っていない場所で進む** |
| 道具の数を数えていた者がいない | 誰も見ていない量が、本当に動いていた量だった |
| 道具がひとつになる | 九つの規則ではなく、ひとつの規則に圧縮された |
| 習っていない型が出た | **汎化** |
| ある朝、突然 | **グロッキング（grokking）** |
| 「わたしも知らない」 | 研究者にもわかっていない |

## 二　もっと知りたい人へ

- Power et al. (2022) *Grokking: Generalization Beyond Overfitting on Small Algorithmic Datasets* — この現象を最初に報告した論文
- Nakkiran et al. (2019) *Deep Double Descent* — 「覚えきってから、また上手くなる」という、これと近い不思議

> 参照は記憶に基づく。原典確認を要する。

## 三　まだ、誰も答えを持っていない問い

**なぜ、ある日なのか。**

道具は少しずつ減っていた。だとすれば、わかるのも少しずつのはずである。

そうならない。ある朝、突然わかる。

**少しずつ減らしたものが、なぜ、いっぺんに変わるのか。**

まだ説明されていない。きみが答えを見つけるかもしれない。

## v1からの変更点

[批評01](critiques/v1-01-human.md) への応答。

**根本の誤りは、設定が現実的すぎたことだった。** 師と弟子が修行する話は現実に存在するので、寓話に梃子が無く、普通の修行譚に落ちた。

v2 は「型が道具に宿る」という**現実に無い設定**をひとつ置いた。この設定が、そのまま機構になっている——九つの仕事を八つの道具でやれと言われたら、共通するところを探すしかない。**圧縮が汎化を強制する**という正則化の機構が、設定そのものから出る。

そのうえで批評01の三点に対応した。

1. **「もう終わり」の地点を作った。** 三年でまちがいがゼロになる。ここで普通は止める
2. **続ける内容を「もっとやる」ではなく「減らす」にした。** これが人間の修行の像との差になる
3. **測定の平坦さを本文に入れた。** 「測れるところは三年目からずっと同じだった」「道具の数を数えていた者はひとりもいなかった」——これで[門番](../monban/v2.md)と主題が繋がった

結末の問いも変えた。v1 は「なぜ、きょうだったのか」だけだったが、v2 は**外から見ていた者に何が見えたか**を問う。測れないものが動いていたという主題に着地する。
