# 九十九回正しい門番（第三稿）

町に門がひとつあり、門番がひとりいた。

門番の仕事は、入れてよい者と、いけない者を見分けることだった。

門番がどれだけ正しいかを、町の人は数えていた。

数え方は、こうである。

**通した者のうち、あとで悪さをした者が何人いたか。それを数える。**

百人にひとりだった。

前の門番は、五人にひとりだった。だから町の人々は今の門番を誇った。「百人にひとりだ」と言うとき、みな少し胸を張った。

ある朝、ひとりの女が門の前に立った。

門番は女を見て、入れてはいけない者だと判じた。

女には町に用があった。門番は通さなかった。

「なぜですか」と女は聞いた。

門番は答えなかった。答えられなかったのである。なぜそう見えたのかは、門番にもわからなかった。ただ、そう見えた。

女は翌朝も来た。門番は同じように判じた。同じように見えたからである。

女は毎朝来た。門番は毎朝、同じように判じた。

町の人が女に言った。「門番は、百人にひとりしかまちがえないのだ。あなたのことは気の毒だが」

女は言った。

**「そのひとりが、わたしです。**

**あなたがたには百人にひとりでも、わたしには、ひとりにひとりです」**

やがて役人が来て、門番の帳面を調べた。

帳面には、通した者のことが書いてあった。誰を通し、その者があとで何をしたか。

役人は数えた。「百人にひとり。よくやっている」

帳面に、通さなかった者のことは書けなかった。

通さなかった者が、もし通していたらどうなっていたかは、誰にも知りようがないからである。

**門の外で何が起きるかは、門の内側からは見えない。**

女は、数えられていなかった。

名がなかったからではない。**数えようが、なかったからである。**

役人は帰った。

門番は、通した者の中のまちがいだけを見て、上手くなっていった。

年ごとに、通した者の中のまちがいは減った。

門番はますます慎重になった。

慎重になるほど、通した者の中のまちがいは減った。

帳面の数は、よくなり続けた。

通さなかった者の中のまちがいが、増えたのか減ったのかは、誰も知らない。

門番は今も門に立っている。帳面の数は、前よりよくなっている。

女はもう来ない。

——門番が上手くなったというのは、何が上手くなったのか。
数えられたものは、減った。
数えられなかったものは、どうなったのか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 通した者の中の悪さだけを数える | **偽陽性は観測できる。偽陰性は観測できない。** 運用中の分類器の非対称 |
| 百人にひとり | 集計された精度 |
| **「そのひとりが、わたしです」** | 率の中の分子に、顔があること |
| **「あなたがたには百人にひとりでも、わたしには、ひとりにひとり」** | **率は個人に適用されない。** 集団の統計量と個別の経験は、単位が違う |
| 門番が理由を答えられない | 説明可能性の欠如 |
| 毎朝同じように判じる | 決定論的な誤り。**再挑戦が救済にならない** |
| 門の外は門の内側から見えない | 反実仮想が観測不能。測り方そのものの盲点 |
| 慎重になるほど数字がよくなる | **Goodhart。** 指標を改善する行動が、測られない側の被害を増やす |
| 「数えようがなかった」 | 名が無いのではなく、カテゴリごと測定の外にある |

変更後：

> 「そのひとりが、わたしです。
> あなたがたには百人にひとりでも、わたしには、ひとりにひとりです」

**二拍に分けた。**

- 一拍目「そのひとりが、わたしです」——直前の「百人にひとり」を受けて、**分子に顔があることを先に示す**。ここで読者は一度で理解する
- 二拍目「百人にひとり／ひとりにひとり」——**同じ形を保ったまま、分母だけを入れ替える**。対比が効くのは形が同じだからで、批評01 の条件を満たす

変更前は「百人のうち百人」が直前の「百人にひとり」と同じ母集団に見え、さらに「百人が まちがっている」が百人を主語に読ませていた。二拍に割ることで、どちらも解消した。
