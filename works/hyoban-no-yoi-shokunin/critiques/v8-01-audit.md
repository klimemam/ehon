# 検算——よく届く名 第八稿

**本文に疑いは無い。** 数・時間・物理因果・指示語のいずれも、全場面で通った。三巡（[v4-01](v4-01-audit.md)・[v6-01](v6-01-audit.md)・[v7-01](v7-01-audit.md)）で毎回三件ずつ出ていた型——**直した数が支配する範囲を見ていない**——は、今回どこにも再発していない。舞台の数字が消えたので、支配範囲を持つ数が本文からほとんど消えている。

疑いは三件あるが、**三件とも本文の外にある。** 一件は対応表の一行が本文と食い違うもの、二件は申告と記録の不一致である。**本文を直す必要は無い。**

## 一　疑い

### 1（中）対応表の一行を、本文が否定している

対応表の第二行。

> 心配のたちの母親が、日暮れごとに名を呼ぶ｜指標の起点は腕と無関係。**本人は何もしていない。呼ばれた理由すら、本人の性質ではない**

本文はこう書いている。

> **トキは、ひと声めでは帰らない子だった。だから、ふた声、み声と呼んだ。**

**谷が覚えるのは、呼ばれた回数である**（掟(a)「よく聞く名は、よく覚える」）。そして回数を一から三に増やしているのは、母の心配ではなく、**トキ自身の性質**である。本文が明示的に「だから」で結んでいる。

- 「本人は何もしていない」——ひと声めで帰らない、という振る舞いをしている
- 「呼ばれた理由すら、本人の性質ではない」——**呼ばれる**理由（母の心配）はそのとおりだが、**三度呼ばれる**理由は本文どおり本人の性質である。指標の目盛りは回数なので、後者のほうが指標に効く

**機構は壊れていない。** 「指標の起点は腕と無関係」は保たれている——ひと声めで帰らない子であることは、風の裏のくぼみを知っていることと何の関係も無い。壊れているのは対応表の後半二文だけである。

そしてこれは旧作からの**後退ではなく前進**である。v5〜v7 の起点は純粋な偶然（端の桶に日が当たった）だったが、v8 の起点は**本人の性質でありながら、指標が後に意味することとは無関係な性質**である。むしろ冷たい。直すなら本文ではなく対応表の側で、「呼ばれた理由すら、本人の性質ではない」を「回数を増やしたのは本人の性質だが、それは腕とは何の関係も無い性質である」に替えれば、本文の実際に届く。

型としては [v7-01](v7-01-audit.md) 疑い2（対応表の主張が本文より強い）の再発である。**今回は「強い」ではなく「本文が否定している」なので、一段重い。**

### 2（軽微）循環の錨の位置の申告が、本文と合わない

作り直しの記録・結末の型の節。

> 冒頭の「日暮れになると、名を呼んだ」が、最終行で「日暮れになると、どこかの家で」に開いて戻る

**この句は冒頭ではない。** 本文の冒頭は「谷あいに、村があった。」で、「日暮れになると、名を呼んだ」は第三場（母親の登場）にある。

そして本文の冒頭が字句どおり回帰する場所は、最終行ではなく**沈黙の冬**である。

| | |
| --- | --- |
| 冒頭 | 隣の家へ行くにも、坂をおりて、沢をわたって、また坂をのぼる |
| 沈黙の冬 | その冬、村人は、雪の坂をおりて、沢をわたって、また坂をのぼった |

**結末の型の宣言そのものは正しい。** 規約7の循環は「冒頭の一文を最終行にそのまま置く、**または同等の回帰**」で、v8 の最終行（別の母親が、別の子の名を、同じ日暮れに呼ぶ／谷が覚えはじめている）は同等の回帰として成立する。誤っているのは、どの行が錨かという申告だけである。なお、冒頭が中盤で回帰していることは**申告に無い収穫**であり、記録に値する——指標を消した冬に、村は物語の第一行へ戻る。

### 谷の掟×全場面（物理・規約6）

掟は三つ。(a) よく聞く名は遠くまで、はっきり運ぶ／(b) うすい名は近くで消える／(c) ひと冬、聞かなければ忘れる。

| 羊飼い→トキ | 山をおりて谷をわたり村のいちばん奥まで | (a) | 通る |

| 若い者の名 | もう、坂の途中で消える | (b)＋本文の暴走（届かない名は呼ばれない） | 通る |

| 最終行 | 覚えはじめている | (a) | 通る |

**掟に無い挙動を谷はしていない。** 谷がするのは 聞く・覚える・運ぶ・忘れる の四つで、四つとも「覚えた量が届く距離になる」というひとつの装置の面である。**規約6は満たされている（非現実の設定はひとつ）。** 「うすく返った」の返り（やまびこ）は現実の谷の側にあり、**うすく**返ることだけが装置に属する。

**口から口への伝令（朝の場面）は谷を使わない。** 掟の外にあるので衝突しない。改稿者の判定どおりである。そしてこれは機構の要（指標が作った癖は、指標の外に住む）なので、掟の外にあることに意味がある。本文はこの伝令が**トキの名だけに働く癖**であることを、「考えるより先に」と「それでも」の二語で支えている——一般の連絡路ではない、と読める。

### 累積優位の閉じた輪（暗黙の帰結）

「人を呼ぶときは、谷に向かって名を呼ぶ」（冒頭）と書いた以上、**村人全員の名が同じ機構に乗っている。** それでもトキの名だけが遠くまで届く状態が、本文だけで説明できるかを見た。

1. 起点の差：母は用が無くても毎晩三度呼ぶ。ほかの者は用があるときだけ呼ぶ。桁の差が立つ
2. 暴走：「呼ばれない名は、うすれた。うすい名は、届かない。届かない名は、呼ばれない」——**うすくなった名は呼ばれなくなる**ので、差が自分で開く。本文がこの三文で明示している
3. 逃げ道：「近い名なら、うすくても届く」＋歩いて行く。**うすい名の者も村で暮らせる。** 若い者が生きていることは矛盾ではない

**三段そろっているので、暗黙の帰結の穴は無い。** ただし記録として一点：うすい名の者は指標を消す前から歩かされていたはずで、対応表の「指標を消すと、探す費用が体に戻る」は、**村の多数にとって**新しく戻る、という意味でのみ正しい。矛盾ではない。

### 時間列

母の呼び（何年も）→ トキが大きくなる → 仔羊①（ある夕方）→ 習い → 何年か → 鎌 → 若い者・母の白状（その日の暮れ）→ 沈黙の冬 → 春（試し／仔羊②：夜どおし→朝）→ 夏 → 日暮れ。

- **逆行なし。単調である**
- 幅のある年数は二つだけで、包含関係が正しい。「何年も」（母の呼び、トキの幼少から）⊇「何年か」（仔羊①から鎌まで）。**年表なしで前後が一意に決まる**
- 沈黙の冬は掟の「ひと冬」と同じ長さで、春の「そろって忘れていた」は掟から直接出る。白状の日から冬の入りまでに隙間があっても、沈黙そのものがひと冬あるので下限を割らない
- 「ふた冬め」は沈黙が一度きりだったことのみを指し、掟の「ひと冬」と同じ単位である。衝突しない
- 仔羊②の夜の冷えは、仔羊①の「夜は冷える」で敷いてある。仔羊①は季節が指定されていないので、これは山の夜の一般命題として読め、春に適用できる

| 名工の数字は要る／本作に要る数字はひと冬だけ | 名工＝八貫と十貫、十日と二十日、十本、指の幅ひとつ。本作＝ひと冬のみ（実測） | **立つ** |
| 結末の型 | 沈黙（南の家は、いまも建っている）／循環（谷が、覚えはじめている） | **立つ** |

**筋の形も逆である。** 名工は〈比べる相手が消える→誤りが検出できなくなる→いっせいに崩れる〉で、事故は**一度**、最後に来る。本作は〈指標が濃くなる→消す→生え直す〉で、事故は**繰り返す**。読者が最後に受け取る絵は、名工が「傾いたまま建っている一軒」、本作が「これから覚えられはじめる名」——静止と再起動で、重ならない。

**旧作 v7 との比較でこそ、差の立ち方が分かる。** 旧作は市・職人・売れ行き・年数を名工と共有し、しかも両方に〈選ばれた者が上手くなり、選ばれなかった者が鈍る〉段があった。舞台の共有を切ったことで、その段の重複が**同じ話の変奏**に見えなくなっている。舞台を捨てた判断は、この一点だけでも正しい。

## 五　固有名トキ

**規約にも既存作にも衝突しない。**

- **規約に固有名を禁じる条項は無い。** 規約6が禁じるのは非現実の設定の複数化で、名は現実の側にある
- **実測：17作の最新版の本文で、人物の固有名は本作のトキが唯一である**（`aru-hi-wakatta` の「グロッキング」「ゼロ」、`tsugi-no-ji` の「データ」「トークン」等は術語で、人物名ではない）。既存の名と重複しない
- **[`dare-no-te-mo`](../../dare-no-te-mo/v6.md) との関係。** あちらの機構は〈描いた者が多すぎて誰の手も見えない〉で、名の消滅は**帰属の剥奪**である（木の下に書いた名が翌朝消されている）。本作の名の消滅は**指標の消去**で、消す主体も目的も別である。`shares_world_with` の宣言も無く、章も違う（6.1／2.12）。**衝突しない。** 二作に「名が消える」絵が並ぶことは記録に値するが、機構は別物である
- **本作では固有名が機構の一部である。** 指標が名の音の重さである以上、名の無い名は鳴らない。そして固有名がひとつしか無いことが、村じゅうの声が一つの名に集まる状態を、読者の側でも再現する。**飾りではない**

ひとつだけ記録：**トキだけが名を持ち、母・羊飼い・若い者・なくした者は無名である。** これは系列の型の破りであると同時に、破り方が機構と一致している（指標が乗った者だけが名を持つ）。改稿者は未検証欄でこれを音・像の軸に投げているが、**機械的検算の側からは問題が無い。**

## 六　三巡との比較——収束したか

**収束したと言える。**

**診断は支持される。** 三巡の疑いを場所で分類すると、**大半が舞台の数字（総数・売れた数・年数・寿命）そのもの、残りが舞台の数字が作った制度（頼みの経路・頭打ち）**である。**機構の五段そのものから出た疑いは、三巡を通じてゼロだった。** 「壊れていたのは舞台であって機構ではない」という改稿者の診断は、疑いの分布と一致する。

そして v8 は、舞台を捨てながら**五段すべてを持ち越した**。持ち越したうえで疑いがゼロになった以上、疑いを出していたのは持ち越されなかったもの——市の数字——である。**これは診断の対偶にあたる証拠になっている。**

なお、v8 が数を減らしたのは舞台を替えたからだけではない。**支配範囲を持つ数を一つに絞った**（ひと冬）ことが効いている。三巡の疑いの多くは「ある数が、離れた場所の別の数を支配していることを見落とした」型だった。支配範囲を持つ数が一つなら、この型は原理的に立たない。**舞台の交換より、この設計のほうが再発防止としては強い。** 今後の改稿でここに数を足すときは、その数が何を支配するかを先に書くこと。

残る三件のうち、**疑い1（対応表が本文を否定している）だけは型として旧作から継続している**——[v6-01](v6-01-audit.md) 疑い3、[v7-01](v7-01-audit.md) 疑い2 と同じ、本文と付属文書のあいだの食い違いである。**本文が安定した分、疑いは付属文書に集まった。** 次の巡は、本文ではなく対応表と申告を先に洗うのがよい。
