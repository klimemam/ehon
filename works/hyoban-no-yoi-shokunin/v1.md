# 評判のよい職人

ある町には百人の職人がいた。

町の人は、仕事を頼むたびに職人へ星をつけた。

最初はみな同じくらい仕事をもらっていたが、ある職人が偶然、星を五つもらった。

次の日、人々は彼に仕事を頼んだ。

仕事をたくさんしたので、彼はさらに上手になった。

ますます星が増えた。

ほかの職人には仕事が来なくなった。

仕事が来ないので、彼らは上手になる機会も失った。

やがて町には、一人の素晴らしい職人と、九十九人の未熟な職人が残った。

ある日、素晴らしい職人が病気になった。

その日、町の人々は初めて気づいた。

**「評判は能力を測っていたのではなく、能力を作っていたのだ。」**

---

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 偶然、星を五つもらった | **初期条件が偶然である。** 最も優れた者が勝ったのではない |
| 仕事をしたので上手になった | 評価が実力を生む経路。累積的優位（Merton 1968, Matthew effect） |
| 仕事が来ないので上手になる機会を失った | 敗者側の能力が実際に低下する。**格差は事後的に正当化される** |
| 職人が病気になった | 集中した系の単一障害点 |
| 「測っていたのではなく、作っていた」 | **遂行性（performativity）。** 指標が対象を構成する |

## 「写せる名工」との違い

[`utsuseru-meiko/v1.md`](../utsuseru-meiko/v1.md) と結末は似ているが、**機構がまったく違う。**

| | 写せる名工 | 評判のよい職人 |
| --- | --- | --- |
| 集中の原因 | コピー可能性が供給制約を外す | 評判と実力の正のフィードバック |
| 最初の差 | **本当に上手かった** | **偶然だった** |
| 二番手が沈む理由 | 需要が名工に全部行く | 仕事が来ないので実際に下手になる |
| 破綻の形 | 全員が同じ誤りをする（相関） | 一人が倒れると代わりがいない（単一障害点） |
| 学術名 | winner-take-most, correlated risk | 累積的優位、遂行性、Matthew effect |

**両立しうる。** 現実の市場では両方が同時に働く。だが寓話としては分けるべきで、混ぜると [`kabe-to-igata`](../kabe-to-igata/) v2 と同じ過密になる。

とくに「最初の差が偶然だった」は写せる名工に無い要素で、**これが入ると話の意味が変わる。** 写せる名工は「優れた者に集中した結果、多様性を失った」だが、評判のよい職人は「**誰でもよかった者が、選ばれたことによって優れた者になった**」。後者のほうが、実際の市場に近い可能性がある。

## Goodhart との関係

これは Goodhart 四型（[`backlog.md`](../common/backlog.md) 11.1）のどれでもない。

Goodhart は「指標を目標にすると、指標が目標を測らなくなる」。ここで起きているのは「**指標が目標を作ってしまう**」であり、方向が逆である。指標は嘘をついていない——星の多い職人は本当に上手い。**上手くしたのが星だというだけである。**

**Goodhart 族に第五の型として追加すべきかもしれない。未検証。**
