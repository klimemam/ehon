# 規約検査：壁と鋳型 v1 ／ ehon-v1.html

本作はこの系列の基底であり、規約5・7・9の実例として README に引かれている当の作品である。したがって以下の違反の多くは「規約が本作から作られ、本作より厳しくなった」ことの記録であって、瑕疵の発見ではない。ただし規約9だけは、いま直せる対象（HTML）に対する実質的な指摘である。

## 規約9——図中キャプション四箇所が地の文の言い換え（symmetrical）

前提の注意：**ファイル名は ehon-v1.html だが、奥付には「第二稿（v2）」とあり、本文も v1.md と異なる**（千人が毎夜溶けて鋳型に戻る／十人が谷を出る／つっかえ棒の挿話）。どの版の絵本なのか、ファイル名か奥付のどちらかを直すべきである。

SVG 内の `<text>` を全数照合した結果、**図案そのものは enhancing 以上を達成している**——見開き一の「？」（数えられなさの記号化）、見開き六の川の線の密度（速さの可視化）、見開き十三の点線（失われた幅）は、いずれも文に無い情報を絵が足している。

**違反はキャプションに集中している。** 次の四箇所は、同じ見開きの地の文をほぼそのまま図中に再掲している：

| 見開き | 図中テキスト | 地の文 |
| --- | --- | --- |
| 五 | 「同じ角度」「十とも、回らない」 | 「十人とも、同じ角度で組んだ」「十の水車は、十とも回らなかった」 |
| 六 | 「世界が、違う返事をした」 | 「世界が、場所ごとに違う返事をしたことである」 |
| 七 | 「食い違ったまま並ぶ」 | 「壁の上で食い違ったまま並んだ」 |
| 十 | 「文字は一色になった」 | 「壁に彫られる文字は一色になり」 |

規約9はこれを symmetrical と呼び、「最低の設計」と明記している。判定の根拠は単純で、**これらのキャプションを消しても絵は成立する**。傾いた水車が十基並んでいれば「同じ角度」は見え、一色の壁は一色に見える。キャプションは絵の一部ではなく、本文の要約として働いている——語と絵の言い換えである。

なお「厚」「止」「灰」「深い」「細い道」などの一字ラベルも本文語の抜き書きだが、図の部位を指す指示語として機能しており、違反度は低い。見開き八の「回った」は作中の彫り文字（叙述内の物）であり言い換えではない。同見開きの「これは彫られなかった」は境界事例——絵に「彫られなかったもの」を指させる仕事をしており、これは counterpointing の入口に最も近い一枚である。キャプションではなく描画（たとえば壁の文字列と水車のあいだの断絶だけ）で同じことが言えれば、規約9が最も強いと呼ぶ設計に届く。

## 規約6——非現実の設定が二つ（判定に迷う）

字義どおり数えれば二つある：①鋳型から人が生まれる、②一日で消える記憶。どちらも飾りではなく機構（weight の同一性／context の揮発性）であり、規約6の「そのまま機構でなければならない」は二つとも満たす。

迷いを明記する：README 規約6自身が「『壁と鋳型』の鋳型から人が生まれる設定、一日で消える記憶」と**二つを並べて例示している**。つまり規約の起草者は、これを「鋳型世界」という一つの複合設定と見なしている可能性が高い。字義（ひとつだけ）と例示（二つ併記)が規約内部で食い違っており、**違反は本作にではなく規約の書き方にあるとも読める。** 著者はどちらかに倒すべきである——「ひとつの世界設定（複数の性質を持ってよい）」と書き直すか、本作を明示的な例外とするか。

## 規約7——封印型の使用（記録のみ）

結末「——賢くなったのは、職人だったのか、壁だったのか。／……千人だったのか、一人だったのか」は**主語入れ替えの問い、すなわち当面封印とされた型**である。ただし本作はその型の実例として README の表に載っている当の作品であり、封印の理由（全作がこの三行で終わるようになった）を作った側ではなく、作られた側である。v1 は確定版（改稿しない）につき、記録に留める。

frontmatter に `ending_type:` が無いことも付記する（他13作には全てある）。

## 規約5・規約8（適合）

- 規約5：試行→返事は五組（谷を出る→回らない／散る→食い違う／糸を張る→止まる／糸を切る→戻る／溶かして鋳る→細い線が灰になる）。README が模範として引用するとおり。
- 規約8：本文に太字ゼロ。これも README が模範として引く。

## 規約13違反（全数違反の一部）

`read_aloud_from:` / `read_alone_from:` の宣言なし。系列で唯一図版（絵本版）を持つ作品であり、規約13が言う「絵は下の年齢に、文は上の年齢に」の設計判断は本作で最初に必要になる。

## 結論

v1.md は確定版であり、違反（規約6の二つ・規約7の封印型・規約13）は記録に留める。**改稿を要するのは ehon-v1.html である**：①見開き五・六・七・十のキャプション削除（または絵で言い直す）、②ファイル名と奥付の版の不一致の解消。どちらも本文に触れない修正である。
