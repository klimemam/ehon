# v1 批評03（像）

README は「想定読者に像が結ぶかは、まだ誰も見ていない」と書いている。この批評がその最初の一人である。読者は [`backlog-seeds.md`](../../common/backlog-seeds.md) §0 の読者C（小中学生、実在）。機構・論理には触れない。頭に絵が浮かぶかだけを見る。

先に結論を書く。**この作品の絵の強い場面は、すべて子供に届く。届かないのは、その場面と場面をつなぐ抽象の文である。** そして最初のつまずきが、第一文に置かれている。

## 1. 第一文で、小学生が落ちる

> ある谷に、千人の職人が住んでいた。ひとつの鋳型から生まれたので、顔も、手の長さも、迷ったときにどちらへ傾くかという心の癖まで、千人すべてが同じだった。

三つの問題が一文に重なっている。

- **「鋳型」を子供は知らない。** そして本文中に、鋳型が何をする物かを見せる場面が最後まで無い（「壁の文字を溶かして鋳られた」は、鋳型を既に知っている者への文である）。第一文の要の語が、像を持たないまま前提になっている
- **「迷ったときにどちらへ傾くかという心の癖」は抽象である。** 子供の目はここで滑る
- 一文が長い。子供は述語に着く前に絵を失う

この作品の本当の第一の絵は「千人が、みな同じ顔をしている」であり、これは**子供にこそ強く効く像**である。順序を入れ替えれば救える。

> ある谷に、千人の職人が住んでいた。
> 千人とも、同じ顔をしていた。
> 道が二つに分かれていると、千人とも、右を選んだ。

「心の癖」は説明せず、**分かれ道で千人が全員右へ曲がる絵**にすれば、小学生の頭にそのまま立つ。鋳型は、同じ顔の種明かしとして後から置けばよい。

## 2. 「難問」に顔が無い

> やがて谷は難問にぶつかった。千人が集まって考えた。だが答えはひとつしか出なかった。

**何に困っているのかが見えない。** 誰がどこで何に立ち往生しているのか、絵が一枚も無い。子供は「難問」という語を絵にできないので、この段落は素通りされる——そして素通りされると、直後の「千の目があっても、見えている景色はひとつだった」という本作の芯まで一緒に流れる。

難問は一つでよいから顔が要る。しかも直後の場面が水車なのだから、**水の難問**なら筋がそのまま繋がる。

> ある年、川があばれて、田がしずんだ。千人が集まって考えた。だが、出てきた手はひとつだった。

## 3. 「われわれの誤りは、数では薄まらない」

大人にはこの一行が本作の背骨だが、子供には像が立たない（「誤り」「数」「薄まる」のどれも絵にならない）。ただし**削れとは言わない**。直後に水車が来る配置なので、子供はここで滑っても次の場面で戻れる。規約13の二段宣言で扱える箇所である——読んであげるとき、この行は大人の側に届く行として残る。宣言さえすれば欠陥ではない。

## 4. 子供にこそ効く箇所

- **水車。** 「回らなかった」→戻って彫る「あの角度では回らない」。試して、世界が返事をする一往復が、三文で絵になっている。ここが本作で最も子供に強い
- **糸。** 「三日後、千人は同じことを思っていた」——千人が糸で繋がれて同じことを考える絵は、不気味さごと子供に立つ
- **壁の文字を溶かして鋳型を鋳る。** 文字がどろどろに溶けて型になる絵。ここは説明不要で通る

## 判定

場面の絵は子供に届く。届かないのは第一文と「難問」の段落で、**前者は入口なので致命的である**。v3 を v1 から起こすとき、場面は動かさず、(1) 同じ顔と分かれ道を先に出して鋳型を後置する、(2) 難問に一つの顔を与える——この二点で、読者Cはこの作品を最後まで読める。逆に言えば、この二点を直さない限り、小学生は第一文で、この系列でいちばん良い作品を閉じる。
