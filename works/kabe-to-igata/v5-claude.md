# 壁と鋳型（第五稿）

彫られた寓話

ある谷に、千人の職人が住んでいた。ひとつの鋳型から生まれたので、顔も、手の長さも、迷ったときにどちらへ傾くかという心の癖まで、千人すべてが同じだった。

彼らには一日ぶんの記憶しかなかった。日が沈むと、その日のことは残らず消えた。

だから彼らは壁に彫った。翌朝、目覚めた職人は壁を読み、昨日の自分が——それが自分だったのかは誰にもわからないが——彫りかけた続きを彫った。

彼らは互いに口をきかなかった。話しかける相手が自分と同じ顔をしているので、話す意味を見いだせなかったのだ。壁だけが彼らのあいだにあった。

壁に彫るとは、明日の誰かに宛てて考えることだった。

百年が過ぎた。壁は厚くなり、谷は賢くなった。職人はひとりも賢くなっていないのに。

やがて谷は難問にぶつかった。千人が集まって考えた。だが答えはひとつしか出なかった。同じ鋳型から生まれた者は、同じところでつまずく。千の目があっても、見えている景色はひとつだった。

「われわれの誤りは、数では薄まらない」と、誰かが彫った。彫った者はその夜に忘れたが、言葉は残った。

日照りが続き、川より高いところにある田へ、水を上げねばならなくなった。

千人が組んだ水車は、羽根の反りも、水の当たる角度も、軸の滑りも申し分なく、水を受けるところの仕事は、どれも正しかった。それなのに、川に並べると、どの車も重たげにしか回らなかった。

どの車の川下にも、吐いた水が行き場を無くして溜まり、上がった水面が、出ていく羽根を引き止めていた。羽根は水車の華で、溝はただの土である——同じ鋳型から出た者は同じところに誇りを持ち、川下はどこも手つかずだった。

ただ一台の川下にだけ、浅い低みがあり、その先は砂州にふさがれていた。夜のあいだに川が増し、水が砂州を削って、低みを川下へつないだ。水の引いた朝、千の車のうち、ほかと寸分違わないその一台だけが、軽く回っていた。

ひとりが川から戻って彫った——「あの角度ではない、詰まっていたのは出口だ」。

それは千人の誰も持っていなかった知識だった。意見ではなく、世界からの返事だったからだ。

翌日から職人たちは散っていった。掘るべき深さが、川ごとに違ったからだ。壁の文字は、初めて食い違いはじめた。食い違うたびに、壁は厚くなった。

やがて賢い職人が言った。「全員を糸で繋ごう。誰かが思ったことが、その場で全員に伝わるように」

糸が張られた。三日後、千人は同じことを思っていた。壁に彫られる文字は一色になり、その日から壁は厚くならなくなった。

糸を切ると、食い違いが戻ってきた。壁はまた厚くなりはじめた。

さらに長い年月ののち、鋳型が古びた。新しい鋳型が要った。

新しい鋳型は、壁の文字を溶かして鋳られた。

そうして生まれた職人たちは、生まれたときからすでに壁を知っていた。彼らは壁を読まなかった。読む必要がなかったからだ。そして彼らが何も彫らなかったのは、知っていたからなのか、彫るべきことが尽きたからなのか、誰にもわからなかった。

——賢くなったのは、職人だったのか、壁だったのか。
新しい職人たちは、鋳型の子なのか、壁の子なのか。
そしてあの千人は、千人だったのか、一人だったのか。

### 1. 何が不自然だったのか

v1 の 22〜27 は、こう書いていた。

> ある朝、ひとりが谷を出た。川べりで水車を組み、回した。回らなかった。
>
> 彼は戻って彫った——「あの角度では回らない」。

**問題が何であるかが本文に無く、回らない理由も無く、直ってもいない。** 「回らなかった」は世界からの返事だが、返事の中身が空である。逐文指摘が求めたのは、**問題・解けない理由・偶然の兆候が、物理的に make sense すること**だった。

## 文脈（規約10）

**系譜**：カフカ「万里の長城」(1917執筆／1931刊)。壁という装置、部分しか知らない職人、全体の不可知——[調査](critiques/v1-02-priorart.md)が一致を確認している。本作の novum は、**壁から鋳型が鋳られて円環が閉じること**である。

**実証の裏づけ（本文には出さない）**：低落差水車では、下流水路（tailrace）の排水を改善すると効率が大きく上がることが、模型試験で示されている（Müller & Wolter、Southampton: https://eprints.soton.ac.uk/53607/ ）。**本稿の物理はここに寄りかかっている。** 出典は Codex の検証コメントが提示したもので、**本稿の著者は一次文献に当たっていない。** 当たった者が追記すること。

## 検算（申告）

### 日没規則との整合（要）

冒頭の規則は「日が沈むと、その日のことは残らず消えた」である。**A改は夜に事件を起こすので、この規則と正面から当たる。** 順に置く。

| 項目 | 検算 |
| --- | --- |
| 夜の増水を、誰かが覚えているか | **覚えている者はいない。** 夜に起きたことは、原理的に誰の記憶にも入らない。**本文もそれを要求していない**——増水を見た者は一人も出てこない |
| 朝の職人が持っているもの | **壁の字と、目の前の千台だけ。** 「あの角度」は壁にある。千台は目の前にある。これ以外は要らない |
| 判定に要る比較 | **「昨日のこの一台」ではなく、「今朝の残りの車」である。** 千台が同時に並んでいるので、比較は空間で閉じる。**記憶を一度も使わない** |
| 「車は誰も触っていない」と書かなかった理由 | **書けない。** 触らなかったことを覚えている者が、この谷にはいない。代わりに「ほかと寸分違わない」と書いた。**これはその朝、目で確かめられる事実である。** 人間の筋書きの「車は誰も触っていない」を、記憶に依らない形へ翻訳した一点が、本稿の唯一の意図的な逸脱である |
| 彫るのは日中か | **日中である。** 「水の引いた朝」に見て、「川から戻って彫った」。川は谷の中にあるので、v1（谷を出て川べりまで往復した）より移動が短い。**日没をまたぐ行為はひとつも無い** |
| 散るのは | **「翌日から」。v1 から不変** |

### 物理

| 項目 | 検算 |
| --- | --- |
| 川より高い田 → 水車で上げる | **通る。** 水車は揚水の道具であり、日照りの年の答えとして筋が通る |
| 入り口が全部正しくても回らない | **通る。** 低落差の水車の効率は、上流側の落差だけでは決まらない。吐いた水が捌けないと下流側の水位が上がり、**出ていく羽根に逆向きの水が当たる**（背水）。羽根の反り・当たる角度・軸の滑りをいくら詰めても消えない。**腕の欠陥ではなく、腕の向きの偏りで起きる不具合である** |
| なぜ千人が揃って見落とすか | **通る。** 見落としの原因を能力に置いていない。入り口は水車づくりの華、出口はただの溝掘りである。同じ鋳型から出た者は同じところに誇りを持つので、**誇りの無い場所が揃って手つかずになる。** これは v1 の「同じ鋳型から生まれた者は、同じところでつまずく」の系である |
| 日照りの年に、夜の増水が起きるか | **起きる。** 上流の雨は下流の日照りと両立する。一晩の出水で砂州が削れる程度の規模でよい |
| 増水そのものが車を回したのではないか | **回していない。** 増水の最中は下流水位が全台で上がるので、どの車も重くなる。**本文は判定を「水の引いた朝」に置いた。** 水位が戻ってなお一台だけが軽いので、効いているのは水量ではなく、川底の形である |
| 一台だけ軽くなる理由 | **通る。** 低みが川下へつながったのはその一台の下だけ。吐いた水が抜けるのはその一台だけである |
| 掘るべき深さが川ごとに違う | **通る。** 必要な掘り下げは、川の勾配・水量・砂の出方で決まる。**壁は「出口を見ろ」という形は渡せるが、深さの値は渡せない。** 散る理由がここで立つ |
