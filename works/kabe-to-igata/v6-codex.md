# 壁と鋳型（第六稿・Codex案）

彫られた寓話

ある谷に、千人の職人が住んでいた。ひとつの鋳型から生まれたので、顔も、手の長さも、迷ったときにどちらへ傾くかという心の癖まで、千人すべてが同じだった。

彼らには一日ぶんの記憶しかなかった。日が沈むと、その日のことは残らず消えた。

だから彼らは壁に彫った。翌朝、目覚めた職人は壁を読み、昨日の自分が——それが自分だったのかは誰にもわからないが——彫りかけた続きを彫った。

彼らは互いに口をきかなかった。話しかける相手が自分と同じ顔をしているので、話す意味を見いだせなかったのだ。壁だけが彼らのあいだにあった。

壁に彫るとは、明日の誰かに宛てて考えることだった。

百年が過ぎた。壁は厚くなり、谷は賢くなった。職人はひとりも賢くなっていないのに。

やがて谷は難問にぶつかった。千人が集まって考えた。だが答えはひとつしか出なかった。同じ鋳型から生まれた者は、同じところでつまずく。千の目があっても、見えている景色はひとつだった。

「われわれの誤りは、数では薄まらない」と、誰かが彫った。彫った者はその夜に忘れたが、言葉は残った。

ある朝、ひとりが谷を出た。

日照りで、川より高い田へ水を上げることが、谷の難問だった。彼は川べりで水車を組んだ。川から水を引く古い溝と、その水を川へ戻す溝が、そこにはすでにあった。車の縁には、水をくむ桶をつけた。

回らなかった。

水は羽根を押していた。軸にも、羽根にも、狂いはなかった。彼は、朝に壁で読んだとおり、水を受ける側だけを調べた。角度を変え、羽根の反りを削り直した。

回らなかった。

午後、遠い上流で降った雨が川を増した。夕方、水が引いた。

水車は回った。

車は、何も変わっていなかった。

彼は、初めて戻す溝の先まで歩いた。出口には、新しくえぐられた土の面が出ていた。水面は、出ていく羽根の下まで下がっていた。

彼は日が沈む前に谷へ戻って彫った——「車ではなく、この川の出口が浅かった」。

それは千人の誰も持っていなかった知識だった。意見ではなく、世界からの返事だったからだ。

翌日から職人たちは散っていった。この川の答えだけでは、ほかの川の出口を知れなかったからだ。それぞれ違う場所で、違うものを組み、違う壊し方をした。壁の文字は、初めて食い違いはじめた。食い違うたびに、壁は厚くなった。

やがて賢い職人が言った。「全員を糸で繋ごう。誰かが思ったことが、その場で全員に伝わるように」

糸が張られた。三日後、千人は同じことを思っていた。壁に彫られる文字は一色になり、その日から壁は厚くならなくなった。

糸を切ると、食い違いが戻ってきた。壁はまた厚くなりはじめた。

さらに長い年月ののち、鋳型が古びた。新しい鋳型が要った。

新しい鋳型は、壁の文字を溶かして鋳られた。

そうして生まれた職人たちは、生まれたときからすでに壁を知っていた。彼らは壁を読まなかった。読む必要がなかったからだ。そして彼らが何も彫らなかったのは、知っていたからなのか、彫るべきことが尽きたからなのか、誰にもわからなかった。

——賢くなったのは、職人だったのか、壁だったのか。
新しい職人たちは、鋳型の子なのか、壁の子なのか。
そしてあの千人は、千人だったのか、一人だったのか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 一日で消える記憶 | contextの揮発性 |
| 同じ鋳型 | 同一weight |

| **壁に彫るとは、明日の誰かに宛てて考えることだった** | stigmergy の定義そのもの。痕跡は伝言ではなく、**次の行為を誘導する環境の変形**である。宛先は個人ではなく、明日そこに立つ者 |
| 千の目でも景色はひとつ | 誤りの相関／命題4 |
| 壁で読んだとおり、水を受ける側だけを調べる | 同一weightと同じ外部記憶が共有する注視の偏り。技能が正しくても、設備境界の外は揃って見落とせる |
| 車を変えても回らない | 内部の改善が、環境側の制約を解かない |
| 車を変えないまま回り、その後で出口の変化を見る | 説明より先に届く、世界からの返事／命題5 |
| 「この川の出口が浅かった」 | 壁が渡すのは観測された条件つきの知識。別の川の値は、その川から返事を受けるまで分からない |
| 糸を張ると壁が止まる | 帯域の逆説／補題 |
| 壁を溶かして鋳る新しい鋳型 | 蒸留と順序の反転／帰結 |

## v5-codex からの変更点

- v5-codex は上書きせず、相互批評への一回の応答を別版として置いた。
- 下流側を、原因が不明な「水面が上がる」から、出口にたまった土で水面が下がらない状態へ直した。
- 「あふれた水」ではなく、増した川の流れが出口の土をさらう形へ直した。
- 職人が壁で読んだとおり水を受ける側だけを直して再び失敗する場面を置き、一人の癖ではなく、壁を介して共有された注視の偏りとして上演した。
- 水車が回るという世界の返事を、出口の説明より先に置いた。
- 彫る文を自己完結した局所観測へ変え、別の場所へ散る理由を本文で明示した。
- 規約13の二段年齢宣言と、新しい水車機構に対応する対応表を加えた。
