# v2 批評02：三つの正しい判断が、三つの注釈になっている

本作は現行作の中で『壁と鋳型』v1 に最も近い。名工を写すという一つの不可能、同じ柱、同じ崩れ方、残る古い一軒が、機構を物として見せる。しかし v2 は、その強い因果の途中に短期合理性の論証を三度挟んだ。

男が二番手に頼む場面は「男はまちがっていない」と採点され、寄合の場面は費用対効果を台詞で説明し、十人の試験は「むらが無い」という概念名を得る。それぞれの意味は明瞭だが、明瞭さの代わりに物語が停止する。

『壁と鋳型』v1 の糸も、一見よい提案が相関を強める場面である。ただし三日後に壁が一色になるだけで、なぜ提案者が正しかったか、なぜ危険かを説明しない。本作も、二番手の家が少し傾く、十本が同じになる、という像のところで止められる。

また「なぜ悪いほうに、わざわざ金を払うのか」に誰も答えられないことは、制度の難しさを正確にする一方、寄合を現代の政策討論へ寄せる。柱と手だけで進んでいた寓話に、論文の反論節が現れる。

結末の「あの一軒を建てた手は、もう無い」は「覚えていなかった」の像を説明し直している。二番手が自分の手を見るところで、喪失はすでに起きている。

## 改稿の方向

- 男、寄合、十人の試験のうち二つを統合し、一つの柱が選択と検査の両方を担うようにする。
- 「男はまちがっていない」「そのとき答えられる者はいなかった」を削り、決定の妥当性を結果の並びだけで示す。
- 寄合の抽象的な応酬を、柱の値札、傾き、待ち時間など同じ画面で比較できる物へ移す。
- 二番手が手を見る場面の後は、問いを一つだけ置く。喪失を言い換えない。

この作品に新しい事件は要らない。**すでにある風が吹くまで、説明で風を止めないこと**が必要である。
