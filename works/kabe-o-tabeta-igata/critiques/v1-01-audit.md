# 検算——壁を食べた鋳型 第一稿（新作）

新作なので前版との突き合わせはできない。`derives_from: ../kabe-to-igata/v1.md`（正典）と `consumes: kabe-to-igata/v3`（同日に出た相方）に照合した。

## 一　疑い

### 1（中〜重）分割の断面——「細い川で羽根を長くする」が、相方では失敗として記録されている

本作の中心事件は、灰から拾った欠片の一行である。

> 春の三日だけ、北の細い川では羽根を長くする。

そして結末の直前で、この行が世界に当たる。

> 職人は、羽根を長くした。
>
> 水車は回った。

**ところが `consumes` 先の `kabe-to-igata` v3 は、同じ川で同じ介入を試し、失敗を記録している。**

> 細い川では羽根を長くした。
> **止まった。**

**両作は同じ壁を共有している。** 本作は冒頭で「壁には、百年ぶんの仕事が彫られていた。回った水車。回らなかった水車。折れた軸。折れなかった軸。**北の川の角度。南の川の羽根。**」と、相方の出来事を要約して引いている。その壁を職人が探せば、出てくるのは「細い川で羽根を長くしたら止まった」である。

救えなくはない——本作の行は「**春の三日だけ**」という条件つきで、相方の試行が春の三日の外だったと読めば両立する。**だがその条件つきの成功例は、どちらの作にも書かれていない。** 相方が書いた唯一の結果は失敗であり、本作が要求するのは成功である。断面のここだけが接いでいない。

### 2（中）結末の数——「まだ一度しか起きていない春だった。」

春の三日は、本文の中で二度起きている。

| 回 | 本文 |
| --- | --- |
| 一度め | 「昔、その川で羽根を長くした者がいたはずだった」／その者が彫った行が「一度しか彫られなかった行」として壁にあった |
| 二度め | 「何年かして、春の三日が来た。／北の細い川だけ、水が浅くなった。」 |

**したがって二度である。** 最終行は本作の最終行であり、対応表の主張（「稀な成功を千本彫る｜頻度と世界での頻度が分離する」）が乗る唯一の数でもある。

弁護は立つ——いまの職人たちは新しい鋳型から生まれた世代で、彼らにとっては初めてである。だが本文の語り手は「昔、その川で羽根を長くした者がいた**はずだった**」と外から知っており、その視点で「まだ一度しか起きていない」と書いている。**語り手が知っている回数と、語り手が数えた回数が食い違う。**

### 3（軽微）一日ぶんの記憶が、本文に一行も無い

この世界の中心の設定である。本作は、その設定に乗る出来事を三つ持っている。

- 職人が「昔……者がいたはずだった」を思い出せず、壁を探す
- 職人が夜に壁へ彫る
- 壁が知識の唯一の入れ物である（だから鋳型の材料になる）

**にもかかわらず、記憶が一日で消えることを本文が一度も言わない**（実測：「記憶」「一日」ともに本文0件）。`consumes: kabe-to-igata/v3` が宣言されているので依存としては成立するが、**中心事件（灰から欠片を拾う）の必要条件が、丸ごと相方の側にある。**

同じ形で「千人」も無い。結末の「壁に同じ行が千本彫られた」の千は、相方の千人から来ている。

### 4（軽微）壁の長さと年数

本作は相方の**あと**に置かれている（壁に「北の川の角度。南の川の羽根」があり、それは相方の水車の段の産物である）。ところが壁の記述は相方の百年の時点と同じである。

| 作 | 記述 |
| --- | --- |
| `kabe-to-igata` v3 | 「百年たった。壁は、谷を一周するほど長くなった。」 |
| 本作 | 「職人は、谷を一周する壁を見た。壁には、**百年ぶん**の仕事が彫られていた。」 |

相方の百年のあとに、水車の段・糸の段・糸を切った段が入る。本作はそのすべてのあとなので、百年より長い。

### 5（軽微）規約7——同じ型が四作続く

`index.html` の新しい並びは、本作を相方の直後に置いた。

| 順 | 作 | ending_type |
| --- | --- | --- |
| 1 | 壁と鋳型 v3 | 事実を二つ並べて切る |
| 2 | **壁を食べた鋳型 v1** | **事実を二つ並べて切る** |

規約7は「**直前の作と同じ型を使わない**」と定めている。分作の二編は組で読まれる設計なので、ここは選べる。

### 6（軽微）帰属の欄

`derives_from: ../kabe-to-igata/v1.md` の正典は `author: 未記載` である。本作は `author: GPT-5.6 Sol` だけを持ち、`original_author` に当たる欄が無い。`lineage:` も無い（規約10）。

## 二　検算して通った項目

| 項目 | 結果 |
| --- | --- |
| 蒸留の順序（頻出行から入れる → 一度きりの行は後回し → 粉を鉄へ → 細い行は炉の風に飛ぶ） | **通る。** 因果が一本で、逆転なし |
| 「炉の風に飛んだ」と「炉の下の灰をふるった」 | **通る。** 飛んだ先が灰の中というのは物理として繋がる。半分だけ残った字（「春の三日だけ、北の……」）は、欠片が割れた読みで足りる |
| 自己還流の循環 | **通る。** 新しい職人の仕事 → 次の職人が見て彫る → 同じ行が増える → 次の鋳型にもっと入る。三段が本文の中で閉じている |
| 三つの頻出行の一貫性 | **通る。**「軸は太くする／羽根は短くする／石の川では低く組む」が、鋳型を作る段・生まれた職人の段・還流の段の三箇所で一字一句同一 |
| 春の三日の場面での介入の順 | **通る。** 短い羽根 → 回らない → 太い軸 → 回らない → 壁を探す → 灰 → 長い羽根 → 回った。頻出行を先に試し、両方とも効かないので稀な行を探す、という順序が機構と一致 |
| 規約6（現実に無い設定はひとつ） | **通る。**「鋳型から人が生まれ、鋳型に入れた物が生まれる者に載る」の一つ。壁の粉を混ぜるのはその設定の実装であって、二つめではない |
| `ending_type: 事実を二つ並べて切る` | **形としては一致。**「壁には、同じ行が千本増えた。／まだ一度しか起きていない春だった。」（ただし疑い2） |
| 規約8（本文の太字） | **0件**（実測） |
| 相方との重複 | **無い。** 相方 v3 の本文に「溶かして」「新しい鋳型」は0件。分けた機構は片側にしか無く、両方に残ってはいない |
