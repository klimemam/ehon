# 検算——次の字を当てる遊び 第五稿

## 一　新設の上限規則を、本文の全記述に当てる

v5 が足した規則は、限定節を持たない絶対形である。

> 机に載る長さしか、一度には読めなかったからである。

| 本文の紙・字数の記述 | 上限との関係 |
| --- | --- |
| 「本を開いて、**途中まで読む**。そこで手で隠して、次に来る字を当てる」 | **破る。** 隠す位置が机の長さを超えた地点なら、直前文脈を「一度に」保持できない。**作品の遊びそのものが上限の外にある** |
| 「子は、**一冊の本を、まるごと覚えて**しまった」「どこを隠されても当たる」 | **破る、または新設行と衝突する。** 一冊まるごと保持できる子が、新設行では直前に切り落とした紙片を「覚えていなかった」。重み（記憶）と文脈窓の区別を、本文も対応表も一度も置いていない |
| 「町じゅうの本を読んだ。読み終わると、隣の町へ行った」 | 同上 |
| 短い書き出しの紙（「むかしむかし、あるところに」「第一条 この町に住む者は」） | 破らない |
| 会話の紙 | 破らない（規則の適用対象そのもの） |
| 金の橋の紙と長い続き | 長さの記述なし |
| 「その言葉だけを、紙に書き足した」 | 長さの記述なし |

**上限規則は、説明したい会話の紙には効くが、作品の冒頭の設定（本・一冊の暗記・町じゅうの本）と正面から衝突する。** 限定（「会話の紙は」等）が一語も付いていないのが、機械的な破れである。

## 二　疑い

### 1（重）「も」→「だけ」が、既出の規則の反例になっている

既出の規則（無変更）：

> その人がまた何か言うと、子はそれ**も**紙に書き足した。

v5 の置換：

> 子は、その言葉**だけ**を、紙に書き足した。

この場面で、その者は**二度**言葉を発している。(1)「橋は、無かった。川を歩いて渡った。服が濡れた」(2)「おまえは、嘘を書いた」。「その言葉だけを」の「その」は近接から (2) を指し、**(1) を排除する。** ところが (1) も言った言葉であり、既出の規則では書き足されるはずのものである。もし「だけ」が袖との対比なら、袖は既に「字が無い」と処理済みなので「だけ」は仕事をせず、しかも語と物というカテゴリをまたいだ排他になる。**どちらの読みでも破れる。**

**前検算の確定事項の破壊。** v4 の検算節（v5 に無変更で残存）はこう書いている。

> 新しい場面が既出の機構の**反復**であることを確認した——「その人がまた何か言うと、子はそれも紙に書き足した」と**同じ振る舞い**の、三たびめの現れ

「も」を「だけ」に替えた時点で、申告された「同じ振る舞い」ではなくなっている。さらに同じ文書は本文をこう引用している——「子はその言葉**も**紙に書き足して」。**付属文書が引用している本文が、本文に存在しない。**

### 2（重）対応表の主張が、本文より強い

| 対応表（無変更） | v5 の本文 |
| --- | --- |
| 相手の言葉と自分の言葉の区別がない｜対話履歴は、**ぜんぶ同じ一本の文字列** | 「上のほうを**切り落とした**」「**残った紙の**ふたつの区別がなかった」——**ぜんぶではない** |
| 「嘘を書いた」と言われた言葉**も**、紙に書き足される｜非難も訂正も、**同じ一本**の文字列に足される | 「その言葉**だけ**を」 |
| **子は、一度も確かめない**｜真偽を判定する仕組みは、内側に無い | 「子は、**袖には書いてある字が無いので**、紙に書かなかった」——袖を検分し、基準を適用して不採用を決めている |

**v5 が本文に足した最大の機構（一度に読める長さの上限と切り落とし）に対応する行が、対応表に一行も無い。**

### 3（中）規約に照らして削ったはずの「作者の声」が、二つ戻っている

v4 の変更点節（v5 に残存）：

> **1. 結末直前の五行の作者解説を削除した**（力批評）……削って足りなくなるぶんは、説明ではなく場面で補った

同・採らなかった案：

> 力批評が「残してもよい」とした一行「確かめる遊びは、習っていなかった**のである**。」——**採らず。「のである」の作者の声が最終二行の直前に残ること自体が、種明かしの尾になる**

v5 が足した二文：

- 「机に載る長さしか、一度には読めなかった**からである**」
- 「子は、袖には書いてある字が無い**ので**、紙に書かなかった」

**後者は最終二行の六行前**——v4 が名指しで拒否した「種明かしの尾」の位置そのものである。**前版の確定した判断の破壊。**

### 4（中）半日歩いて帰った袖が濡れている

| 出来事 | 本文 |
| --- | --- |
| 往路 | 「**半日**、歩いた」 |
| 渡渉 | 「川を歩いて渡った」 |
| 復路 | 「濡れて帰ってきた」＝往路と同距離なら約半日 |

**復路半日を歩いたあとの袖が、他人に触らせて分かるほど濡れていること**は疑わしい。v4 は「濡れて帰ってきた」までで、濡れを触覚の証拠にしていなかった。v5 が濡れを**物理的な荷重のかかる事実**にした結果、乾く時間が検算対象になった。

加えて、**川を歩いて渡って濡れるのは裾であって袖ではない。** 袖まで濡れる深さなら「歩いて渡った」とは言いにくい。

### 5（軽微）「残った紙のふたつ」の指示

「ふたつ」の先行詞は「相手の言ったことと、自分の書いたこと」だが、あいだに新設の二文が挟まったことで距離が開き、「残った紙のふたつ」は「紙が二枚」とも読める。

### 6（軽微）検算節の申告範囲

「数・時間はひとつも変えていない（一年・三日・半日）」——**実測で三つとも無変更。** ただし v5 は**新しい量**（机に載る長さ）を足しており、この申告はその外側にある。
