# 規約検査（全14作）

規約は作品より新しい。古い作品が新しい規約を満たさないのは当然であり、以下は違反の**記録**である。改稿するかどうかの判断は著者がする。

## 0. 判定基準（先に明示する）

- **規約5**：「試行」＝登場人物が世界に対して意図的に行う働きかけ（実験・制度の導入・廃止を含む）。「返事」＝その結果として**世界が返す事実**。人物の意見・反論は返事に数えない。ただし「三月かけて決まらなかった」「証は無かった」のような、**議論の結果として成立した事実**は返事に数えた（境界事例として明記する）。三組以上で○。
- **規約6**：「現実に無い設定」＝物理的・生物学的に現実に存在しえない前提。**規模や確率の誇張、理想化（全員の腕が同じ等）は非現実と数えない**。この基準では「ひとつも置いていない」作品が出る。規約の題は「現実に無い設定を、ひとつ**置く**」であり、ゼロも違反として挙げる。
- **規約7**：判定は frontmatter の `ending_type` 宣言を出発点とし、**本文の実際の結末行が README の型定義に合致するか**を確かめる。合致しない場合は再分類の可能性を書く。規約の字義は「直前の作と同じ型を使わない」だが、**14作の系列順（どれが「直前の作」か）はどこにも宣言されていない**。よって隣接判定は不能とし、型の重複を全て挙げる。
- **規約8**：本文＝frontmatter の後から「作者による対応表」（tsugi-no-ji / aru-hi-wakatta は「# 巻末」）の直前まで。この範囲の `**` を機械的に数えた。
- **規約9**：図版が存在するのは kabe-to-igata の `ehon-v1.html` のみ。SVG 内の `<text>` 要素を全て列挙し、同じ見開きの地の文と突き合わせた。
- **規約13**：frontmatter に `read_aloud_from:` と `read_alone_from:` の両方があるか。機械検索（全 works 配下でヒットは README の規約文のみ）。

| 七 | **「食い違ったまま並ぶ」** | 「壁の上で食い違ったまま並んだ」 | **symmetrical** |
| 八 | 「回った」 | 「彼は彫った——『回った』」 | 作中の彫り文字（叙述内の物）。言い換えではない |
| 八 | 「これは彫られなかった」 | 「つっかえ棒のことは彫らなかった」 | 境界。絵に指示機能を与えているが、文の言い換えに近い |
| 九 | 「止」 | 「その一点だけ、厚くなるのをやめた」 | 弱い言い換え（ラベル） |
| 十 | **「文字は一色になった」** | 「壁に彫られる文字は一色になり」 | **symmetrical** |
| 十二 | 「灰」 | 「溶ける前に灰になった」 | 弱い言い換え（ラベル） |
| 十三 | 「細い道」「深い」 | 「細い道は知らなかった」「かわりに深くなった」 | 弱い言い換え（ラベル） |

**判定：図案そのものは enhancing 以上を達成している箇所が多い**（見開き一の「？」、見開き六の線の密度＝川の速さ、見開き十三の点線＝失われた幅）。**違反は図中キャプションに集中している。** 見開き五・六・七・十の四箇所は、地の文の一節をほぼそのまま図中に再掲しており、規約9が「最低の設計」と呼ぶ symmetrical に該当する。これらのキャプションを消しても絵は成立する——つまりキャプションは絵の一部ではなく、本文の言い換えとして働いている。
