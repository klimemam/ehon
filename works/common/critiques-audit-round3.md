# 検算表——第三回（新作三編・改稿六版）

Claude Fable 5 の九版を検算した。文学的評価はしていない。改稿六版はまず diff で変更箇所を機械的に特定し、申告（「それ以外は一字一句同一」等）を検証したうえで、変更が引き起こす帰結だけを見た。新作三編は前版を持たないので、本文・対応表・文脈・自己検算節を相互に突き合わせ、`consumes` 先の本文と照合した。

**改稿六版すべてで、変更範囲の申告は正確だった。** 井戸は本文九箇所（うち「温」の置換七箇所）、名工は本文五箇所、絵は本文四箇所、帳面は本文二行の追加、象は本文三箇所、穴は本文六箇所。diff と申告の食い違いはゼロである。新作三編の自己検算節も、数え上げの内訳（また頼む v2 の「v1 の検算1〜11」等）は正確だった。

**破れたのは、申告の正確さではなく、申告の範囲だった。** 今回の疑い八件のうち五件は、**直した行そのものではなく、直した行が支配する範囲**にある。帳面 v5 は「作る」を「売れる」に直したが、その数（百と十）が売れる話として通るかは見ていない。象 v5 は新設の場面が既存の記述と衝突しないかを検査したが、検査した問いが違った。名工 v6 は共有世界の装置を初めて本文に出したが、その装置の規則までは照合していない。

## 三　最重点1：tanomu-riyuu と mata-tanomu の依存は整合しているか

**一箇所で破れる。ほかは整合している。**

破れるのは**時間列の接続点**、それだけである。後編は前編のどこから始まるのか——後編は「畑の列＝手形が来た年」として十年を数え、前編は「畑の列＝およそ二年め」として書いている。**差は二年。** 修理は後編の側が安い（「屋根屋は、八年、瘦せた」）。前編の側を動かすと、値半分・五日の札・冬ごもり・春の市という四段の試しを列より後ろへ運ぶことになり、前編の筋が組み替わる。

依頼された照合点は、この一点を除いてすべて通った。

| 照合点 | 結果 |
| --- | --- |
| 後編は前編のいつから始まるか | **破れる。**「手形が来て十年」の原点は共有できるが、「屋根屋は、十年、瘦せた」の原点（畑の列）は共有できない |
| 前編で消えた職と、後編で戻る職の集合 | **整合。** 前編の残る払い（山・井戸・峠の関・畑）と、後編冒頭「銭が渡るのは、井戸の前と、峠の関と、山と畑の主の門前だけである」が集合として一致する。樵まで消える連鎖は資源の壁（木は、紙からは生えない）で正しく止まっている |
| 井戸の主の台詞と、後編での引用 | **整合。** 「頼むというのは、無いものを借りに行くことだ」は**一字一致**である |
| 手形の設定が両編で同じ規則で働くか | **整合。** 前編「紙に押しつけると手の癖ごと写る／当てた者の手が写されたとおりに動く」、後編「写した紙を手に当てれば、誰の手でも、同じに動く」。値の落ち方（写しから写しが取れる）も、後編の「手形は、ひと山いくらにしても、売れなかった」に素直に接続する |
| 「同じ年に葺いた屋根は同じ年に古びる」と、前編の複製の広がり方 | **整合。** 「あらかたの家」で受けた設定が十年めに「どの家の屋根も」になるのは、初年に葺かなかった家の屋根はそれ以前から古いので成立する。全数主張は破れていない（「いちどきに」だけがやや強い） |
| 畑の列の順序（屋根屋が借りそこねる） | **整合。** 前編「列のいちばん後ろに並んだ」／後編「塗師が並んだあとにも、列は伸びていた」 |
| 前編の結末の型（主語識別不能）と後編の型 | **整合。** 後編 v2 は描写の放棄に替えており、対で読んだとき同じ楽器にならない |

## 四　最重点2：hazure-no-fuda が utsuseru-meiko から引いた観測は、引用元と一致しているか

**一致している。** 六点を引用元の本文と一行ずつ突き合わせ、食い違いはゼロだった。

| 本作の記述 | 名工 v5／v6 の本文 |
| --- | --- |
| 写された名工の建てた家は、みな同じところから崩れた | 「町の家が、いっせいに、同じところから崩れた」 |
| 風の日に崩れなかった、ただ一軒 | 「崩れなかったのは、町の南の、指の幅ひとつ傾いた一軒だけだった」 |
| 南の外れの、指の幅ひとつ傾いた家 | 「町の南の」。「外れ」は本作の追加だが、位置と傾きは一致 |

| 建て直したのも写された名工。ほかに速く安い手は無い | 「町はよく建った。前より速く、前より安く建った」 |
| 大工の多様性はすでに失われている（違いの入れ物は、仕事の来る手だけ） | 「二番手は柱を組まなくなった……三番手は、早くにやめた」 |

**引かれた側で新しく起きたことがひとつある。** 本作が受け取った観測の核は「暗黙の差異は保存できない——蔵にも帳面にもしまえない」である。ところが同じ日に出た名工 v6 は、その差異を丸ごと写す装置として、共有世界の鋳型を本文に呼び込んだ（疑い7）。**受け手が正しく引いているのに、引用元のほうが、引用された前提を薄くする一行を足している。**

## 七　この回で見えた型

前回まで総括された三つの型のうち、**一つが再発した。**

1. **対応表・文脈・検算節の主張が、本文より強い**——**再発。** 帳面 v6 の対応表二行（八年／九年前）、名工 v6 の検算節（共有世界の範囲内）、頼む理由 v1 の検算5（影の解像度）。
2. **改稿者の申告が実態と一致しない**——**再発しなかった。** 六版とも変更範囲の申告は正確だった。ただし象 v5 では、申告した検査項目が**別の問い**を検査していた（語数が等しいかではなく、語数と言い当ての力が別かを検査した）。申告の正確さではなく、検査の照準の問題である。
3. **前版が置いていた限定節を消しながら、その反例を同じ稿で足した**——**再発しなかった。** むしろ穴 v3 は逆をやっている（新場面の反例になる人物を、場面ごと死後へ移した）。

**新しく出たのは四つめの型である。**

> **数を直した稿は、直した行を守ったが、直した数が支配する範囲を見ていない。**

帳面がその純粋な例である。v4 検算は三件の誤りを正しく直した。v5 はその三件を正しく実装した。v6 は「すべて無変更で保持」と正しく申告した。**それでも、直した数（千・十ずつ・九年）が出てくる別の三箇所（百売れた・八年もつ職人・対応表）は、v4 の数のまま残っている。** 守るべきものが「行」だと思われていて、「数」だとは思われていない。

**もうひとつ、依存の側で新しい型が出た。**

> **宣言だけの共有世界は照合できない。装置を本文に出した稿が、初めて照合対象になる。**

名工は v1 から `shares_world_with: kabe-to-igata` を宣言していたが、あの世界の装置を本文に出したのは v6 が初めてである。**照合できる形にした稿が、規則の差を負う。** これは装置を出したことの罰ではない——出さなければ、差はいつまでも見つからなかった。
