# 積んだ課題：英雄が荒くれ者になったあと

**問い**：特殊技能が特殊技能でなくなる、という韻は歴史に何度も鳴っている。それはAI自身にも起きている。**「職業が無くなる」は陳腐である。その次に何が起きるのか。**

**記録のみ。作品は書いていない。** 2026-08-12

関連：[`phases.md`](phases.md)（時系列軸）／[`backlog-agent-economy.md`](backlog-agent-economy.md) S1・S5

---

## 1. なぜ「職業が無くなる」で止まると陳腐なのか

三つ理由がある。

1. **外れている。** 溶けた技能の担い手は、消えずにどこかへ行く。行き先のほうが本題である
2. **半歩ですらない**（[`method.md`](method.md)）。誰でも言う。しかも百年言われ続けて、まだ言われている
3. **主語が職業になっている。** 職業は数えられるので測りやすいが、**測りやすいものを追うと機構を外す**（[`hyoban-no-yoi-shokunin`](../hyoban-no-yoi-shokunin/v5.md) の主題そのもの）

## 2. 韻の実例（引く前に要確認）

| 事例 | 何が起きたか | 確度 |
| --- | --- | --- |
| **武士 → 士族** | 戦が終わっても腕は落ちていない。**世界が問わなくなった。** 廃刀令・秩禄処分（ともに1876）で、帯刀と俸禄という「特殊性の外形」が同時に外れた | 制度史は堅い |
| **傭兵 → 野盗** | 百年戦争の休戦期、除隊した傭兵団（Free Companies）がフランスを荒らした。**同じ技能が、戦時は武勇、平時は狼藉** | 堅い |
| **弓 → 鉄砲** | 年単位の鍛錬が、週単位の訓練に置き換わった | 長篠の三段撃ちなど個別の戦術は**争いがある。要確認** |
| **英雄 → 密集陣** | 個の武勇が、隊列では邪魔になる | いわゆる hoplite revolution 論は**学説上の争いがある。要確認** |
| **写字生 → 印刷** | 手が要らなくなり、校合という別の仕事が生まれた | 堅い |
| **計算手（human computer）→ 機械** | 職名がそのまま機械の名になった | 堅い |

**共通するのは、腕が落ちていないことである。** 落ちたのは値である。

**この形には気質版がある** → [`backlog-personality.md`](backlog/backlog-personality.md)。変異のほうは変わらず、世界が何を要求したかが変わる。**技能版と気質版を別々に書くか、一つにまとめるかは未決。**

## 3. その次に何が起きるか（本題）

四つに分けた。**T1 が最も先まで行っている。**

### T1　生産は先に置き換わり、判定は遅れて枯れる

**良し悪しを見分けられる者は、それが難しかった時代に育った者である。**

作る仕事が置き換わると、**その道で人を育てる理由が消える。** だが判定できる人はまだ生きているので、しばらくは系が健全に見える。

```
生産が置き換わる ──→ 育成が止まる ──→ （旧世代が判定を担う）──→ 判定者が枯れる
                                        ↑ここだけ、系は正常に見える
```

**効きどころは、この途中の期間である。** 何も壊れていないように見える。数字も悪くならない。**判定者が枯れたことは、枯れきってから分かる。**

- **相**：第IV相（[`phases.md`](phases.md)）
- **半歩／一歩／二歩**：**二歩。** 「AIの出力を誰が評価するのか」は一歩（既に言われている）。**評価能力が生産能力より遅れて枯れる、という時間差**を言うのが二歩
- **既存作との関係**：[`monban`](../monban/v8.md) は判定の誤りを扱った。[`kotae-o-shiru-tomodachi`](../kotae-o-shiru-tomodachi/v8.md) は学びの滞留を扱った。**判定能力そのものの供給が絶える話は無い**
- **[`docs/thesis.md`](../../docs/thesis.md) 命題5 に直結**：検証器のある領域では世界が判定する。**無い領域では、判定は人に依存し、人の供給が絶える**
- **世界が返事をする三回（規約5）**：①置き換える。良い物ができる ②育成をやめる。まだ良い ③見分けられる者が減る。**——だが、悪くなったことを言える者がもういない**
- **結末の型（規約7）**：まだ決めていない。「気づかない」型が有力だが、[`kotae-o-shiru-tomodachi`](../kotae-o-shiru-tomodachi/v8.md) と重なる

### T2　職は消えず、名がほどける

**職業が無くなるのではない。職業名が束ねていたものが、ばらける。**

「翻訳者」という名は、語学・文体の判断・調べもの・そして**責任**を一つに束ねていた。束が解けると、それぞれが別の場所へ散る。

**そして最後に人の側に残るのは、技能ではない。罰せられうること、である。**

責任は写せない。**罰を受けられる主体でなければ、責任を負えないからである。** [`backlog-agent-economy.md`](backlog-agent-economy.md) S1 が挙げた「写せないもの」の一覧——権利・資本・身体・法的権限——のうち、**最後まで残るのはこれだと考えている。**

- **相**：第IV相 → 第V相への橋
- **半歩／一歩／二歩**：**二歩。** 「責任は人が負う」は当たり前の主張だが、**それが技能でなく責任だけが残るという配分の帰結**として出てくる筋は見ていない
- **危険**：説教になりやすい。**「だから人間には責任がある」と言った瞬間に死ぬ。** 機構として書く——罰せられる者が要るので、罰せられる者だけが雇われる
- **像の候補**：名を返上した者が、なお名簿に残っている。仕事はしていない。**何かあったときに呼ばれるために載っている**

### T3　荒くれ者は、外へ出る

除隊した傭兵は消えない。**まだその技能が希少な場所へ移る。** 辺境、隣国、海。

これは [`phases.md`](phases.md) §6 の「フロンティア」の候補と、**同じ運動の別の側から見た姿である。**

- **v_溶解 と v_希少 の関係で言えば**：中心で溶けた技能が、**周縁ではまだ希少である**。溶解には勾配がある
- **したがって、フロンティアは地理でなくてもよい。** 規制の外、記録の外、値のつかない領域
- **相**：第V相への橋
- **半歩／一歩／二歩**：**一歩。** 「AIで仕事を失った人が別の分野へ移る」は半歩。**溶解に勾配があること、勾配が消えたときに初めて行き場が無くなること**まで行くと一歩
- **既存作との関係**：[`chomen-ni-nai-mise`](../chomen-ni-nai-mise/v3.md) の「帳面の外」が、そのまま行き先になりうる

### T4　語りだけが残り、判定基準が失われる

英雄譚は、英雄がいなくなってから盛んになる。**誰もが英雄の名を知っているが、誰も剣の善し悪しを言えない。**

- **T1 の文化面**。同じことの別の現れなので、**独立した一編にするかは未決**
- **一編にするなら**：語り継がれるほど、判定は遠ざかる。**語りが判定の代わりになる**という機構が要る
- **半歩／一歩／二歩**：単体では**半歩**。T1 に畳んだほうが強い可能性が高い

## 4. AI自身に起きている韻（この課題の起点）

**この韻は、AIを取り巻く世界だけでなく、AIの内側で先に鳴っている。**

数年のあいだに、特殊技能とされたものが次々に特殊でなくなった。呼び名を出さずに言えば——**指示の書き方の工夫、細かな調整の勘所、繋ぎこみの職人芸**。いずれも短期間で、要らなくなるか、道具に畳まれた。

**つまり、溶かしている当のものが、自分の内側の専門性を最も速く溶かしている。**

これは [`phases.md`](phases.md) §2 の二速度が、**再帰的に自分へ適用された姿**である。そして S1 の結論と一致する：**内側に残るのは技能ではなく、写せないもの（計算資源・データ・流通・責任）へのつながりである。**

**この一致は、偶然ではないか一度疑う必要がある。** 同じ論から同じ結論を出しているだけかもしれない（[`docs/thesis.md`](../../docs/thesis.md) 命題4）。**週末に別の筋から検算する。**
