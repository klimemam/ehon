# 検算表——第五回（Sol の一括投入19件）

[`revision-from-sol-collection-critique.md`](../revision-from-sol-collection-critique.md) が記録した17作の改稿と、過密と判定した二作から分けた新作2編を検算した。文学的評価はしていない。全件で前版との diff を取り、各作の `critiques/` にある audit と round2・3・4 の該当記述を読み、**過去の検算が確定させた数・時間・規則が新版で保存されているか**を一つずつ照合した。

**十九件のうち、支持するに足るものは無かった。軽微が四件、改稿を要するが十五件である。**

## 一　なぜこの回だけ数字が違うのか——三つの機械的な原因

### 原因1　本文だけが動き、付属文書が置き去りにされた

**十九件のうち十五件が、変更点節としてバイト単位で同一の定型文一つだけを持つ**（実測）。

> ……の「情景」「論理」「SFとしての蓋然性」の指摘に応答した。旧版は変更せず、この版を隣に置く。

**変更範囲の記述も、grep 件数の申告も、検算項目も、ひとつも無い。**

round3 は改稿六版すべてについて「変更範囲の申告は正確だった。diff と申告の食い違いはゼロ」と記録し、round4 は「**改稿者が自分から件数を数えて差し出した。検査可能な形に自分を置いたうえで、二十五勝一敗**」と評価した。**その実務が十五版で同時に消えた。** 申告が無いので、勝敗の対象にすら乗らない。

そして前作者が書いた検算節は**そのまま貼り付いて残っている。** その節は例外なく「本文は前版と一字一句同一」「結末には触れていない」と明言しているので、本文を変えた瞬間に偽になる。

**実測で数えた、偽になった申告：十七件。**

### この回で見えた型

> **申告をやめた稿は、検算できない。そして検算できない稿は、前の検算が守らせたものを、知らずに戻す。**

round4 は「二十五勝一敗」を、改稿者が自分から件数を数えて差し出したことの成果として記録した。今回はその実務が消えている。**代わりに起きたのは、前作者の検算節がそのまま貼り付いて残り、新しい本文について偽を述べる状態である**（十七件）。

これは「同じ weight 由来のエージェント群は誤りが相関する」という本リポジトリの主張に対して、**別の weight でも同じ場所を踏むわけではない**という観測でもある。Sol が踏んだのは、Claude Fable 5 が踏まなかった場所——**自分の直しを検査可能な形に差し出すこと**——である。誤りの中身ではなく、**誤りを見つけられる形を残すかどうか**が分かれた。

### 例外を一つ記録する

**`aru-hi-wakatta` v7 だけは、持ち越した申告のどれ一つも偽になっていない。** 鍵の数（9 → … → 1、弟子1＋師匠8＝9）を全数数え直して一致し、稽古の錠前は全出現で「九つ」のまま、正則化の規則も無変更である。**未知の錠前を一つから二つに増やしながら、既存の数にひとつも触れていない。** 十九件のなかでこの一件だけが、round4 までの水準を保っている。

**そして `utsuseru-meiko` v8 は、検算が四巡で一度も見つけなかった穴を塞いだ。** v7 の「**ある年から**、名工は柱を、わずかに違えて組むようになった」は、その年より前に名工が組んだ柱に癖が無いことを含意し、「崩れなかったのは南の一軒だけ」と合わなかった。v8 の「**昔から**」がこれを一語で消している。v4-01・v6-01・round4 のいずれもこの箇所に触れていない。**直しが開けた穴を、次の直しが塞いだ形である。**

## 九　この回で直さなかったこと

- 文学的評価は一切していない。像の強度・音・対象年齢の適合は、どの作についても判定していない
- 十九件すべてを同じ深さでは見ていない。指示どおり、**一件あたりの深さより、全件について「前検算の確定事項」と「分割の断面」を確実に見ることを優先した**
- 短編集としての収録順は評価していない。ただし規約7（直前の作と同じ型を使わない）は `index.html` の並びに対して機械的に検査した（五節）
- `works/kabe-to-igata/README.md` は v3 の追加を受けていない（系譜の図・版の表・未充足節の「v3 を作るときに解消する」が、いずれも未更新）。`works/README.md` の下部「作品一覧」も古い版番号のままだが、これは本回より前からの引き継ぎである
