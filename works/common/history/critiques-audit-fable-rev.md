# 検算表——Fable 5 改稿七作

文学的評価は一切していない。前版と一行ずつ突き合わせ、**何が足され、何が消えたか**を特定したうえで、数・時間・物理・指示語・自作内矛盾・暗黙の帰結だけを見た。

各版末尾の「検算」節（著者の自己申告）は**独立と数えていない**。むしろ申告のある箇所を優先して疑った。結果として、**申告どおりでなかったものが三件**ある（chomen の三軒対応、bango の「町はそれを知らない」、aru-hi-wakatta の「数えていた者」の範囲）。

## 三　疑いが出なかった二作

**monban v9 は支持する。** 特に疑うよう指示された箇所を全部当たったが、破綻は無い。

- 十人×七年＝七十人。女はその七十人の一人。悪さ一人。七十−一＝六十九。すべて合う
- **v8 が慎重に直した率の向きは壊れていない。** 止めた群 1/70 ≒ 1.43%、通した群 1/100 = 1.0%。「ほぼ同じ」は保たれ、「門番の判じには情報が無かった」を支える
- **放火の男は七十人の外。** v9 は女を「くじの三年めの**春**」に当てたことで、くじの引きが春であることを本文に固定した。八年め**の春**の男は八年めの引きの者と読める。**v8 になかった曖昧さの塞ぎ方であり、改善である**
- 「その者があとで何をしたかを帳面につける」と「名のあとには、何も書かれなかった」は衝突しない。「あとで」は門を出たあとを指し、市の一日は「あと」ではない
- 「はじめて女の名が載った」も正しい。止めた者は記録されず、女は一度も通されていない
- 時間の前後（女の初登場→三月の決定→くじ一〜七年→八年めの春→その年のうちに廃止→なお毎朝→今）に逆転なし
- 累積で見れば廃止時点は 2/80 = 2.5% 対 1/100 = 1.0% になるが、本文が印字する率は七年め時点の値であり、n=70〜80 で有意でもない。**これは v8 から引き継いだ構造であり、v9 が壊したものではない**

**tsugi-no-ji v4 は支持する。** 疑いはゼロ。

- 数・時間は一つも動いていない（一年・三日・半日）
- 足した場面（「おまえは、嘘を書いた」→書き足す→いつもの遊び）は、既出の振る舞い（「その人がまた何か言うと、子はそれも紙に書き足した」）の三たびめであり、**子が真偽の概念を持たない設定と矛盾しない**。非難に応答するのではなく、続きを生成している
- 「濡れて帰ってきた者は、もう子に聞かない」と新場面（帰ってきて言う）は両立する。**言うこと**と**聞くこと**は別である。むしろ最終行の根拠が場面として立った
- 削除された五行（「子は、嘘をついたのではない」〜）が担っていた事実主張は、巻末二がすべて保持している。本文から消えて、どこにも無くなった主張は無い
- 巻末一の左列を「確かめる遊びは習っていない」→「子は、一度も確かめない」に付け替えた処理は、本文の削除と整合する

## 五　所見

1. **「場面を足すと誤りが生まれる」は今回も成り立った。** 九件の疑いのうち八件が、今回足した場面またはそれに伴って足した対応表の行から出ている。純粋に前版から引き継いだ誤りは一件も見つからなかった。
2. **ただし今回は、算術が壊れた作は無い。** 鍵九本、七十人、三万八千二百、枠三つ——数はすべて合う。過去三回の前科（井戸の季節、弟子の鍵、門番の九十八人）と同じ型の破綻は再発していない。
3. **代わりに、破綻の層が上がった。** 今回の疑いは (a) 対応表の主張が本文より強い、(b) 検算節の申告が本文と一致しない、(c) 前版が置いていた限定節を消しながら反例を足した——という**本文と付属文書のあいだ**、および**削除と追加の相互作用**に集中している。前版の修正を守ることと、その修正が何によって守られていたかを覚えていることは、別の仕事である。
4. **bango-o-utsu-mono v4 だけは本文の層で壊れている。** 冒頭を「現象だけ」に組み替えた判断そのものは正しいが、組み替えで新しく書いた二行（「割れる日が来ると、ひとりでに割れる」「これほど多く割れた日は、それまで、いちどもなかった」）が、結末で立てる法則と両立しない。
5. **monban v9 と tsugi-no-ji v4 は、場面を足して何も壊さなかった。** とくに monban は、女を七十人に入れるという最も危険な操作（率の分母を触る操作）をしながら、v8 の率の修正を守りきり、さらに「春」の一語で放火の男の所属という v8 に残っていた曖昧さを塞いだ。**今回の七作でいちばん危ない改稿が、いちばん綺麗に通っている。**
