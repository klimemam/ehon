# 元原稿を短編集として読む——時系列構成への批評

## 0. 批評の範囲

これは各話の優劣を決める批評ではない。17作を一つの原稿として読んだとき、**AI導入後の出来事が時間として読めるか**を見る。

確認したのは、2026年8月17日時点の各作の最新版である。ただし「壁と鋳型」だけは、作品の README が v2 を後退とし、次稿を v1 から起こすと定めているため v1 を読んだ。

以下を分ける。

- **観測**：本文と構成資料から数えたり照合したりできること。
- **判定**：観測からの批評者の読み。外部の読者では未検証。
- **提案**：改稿命令ではない。並べて試せる仮説。

## 1. 先に結論

### 判定

現原稿は、すでに「AIについての短編が集まった状態」にはある。しかし、まだ「AI導入後の時間が流れる短編集」にはなっていない。

不足しているのは年代ではない。**一つ前の話で起きたことが、次の話の初期条件になっていない。** 各話の町は、その都度、初めて鋳型、帳面、門番、手形に出会う。読者は機構を17回見るが、社会が17回ぶん古くなるところを見ない。

したがって、時系列化の主作業は「第I相、第II相」と札を付けることではない。必要なのは次の三つである。

1. 収録作を減らし、役割の重なる話を同じ巻に入れすぎない。
2. 各話の終わりに出た物、規則、損失のいずれかを、次話の冒頭の既成事実にする。
3. 技術の時間、制度の時間、生活の時間を一本の列に混ぜない。

17作すべてを順番に置けば年代記になる、という前提は未検証である。むしろ現状では、全作収録が時系列を弱める可能性が高い。

## 2. 原稿の強いところではなく、短編集にしたとき初めて生じる問題

### 観測1：同じ発見が、別の物で繰り返される

現原稿には、少なくとも四つの重複群がある。

| 重複する機構 | 主な作品 | それぞれの違い | 一冊で起きる危険 |
| --- | --- | --- | --- |
| 出力と真偽は別 | 「次の字を当てる遊び」「穴の声」 | 前者は予測機構、後者は人格判定 | 後の話が前の話の応用ではなく、同じ疑問の再提示に見える |
| 生成量が選別を圧倒する | 「書きつづけるもの」「よく届く名」 | 前者は選別規則、後者は評判の累積 | どちらも「見えるものだけが次に残る」に畳まれる |
| 個体数と独立性は別 | 「壁と鋳型」「写せる名工」「番号を打つ者」「はずれの札」 | 記憶、供給制約、系譜、探索保険 | 四作続くと、三作目以後が反証でなく例証になる |
| 測定が対象を作る | 「九十九回正しい門番」「誰の手も写っていない絵」「帳面にない店」「よく届く名」 | 拒否、寄与、分類、評判 | 制度名は違うが、読後の運動が「欄の外が消える」に収束する |

### 判定

一編ずつなら物の像が違うため、重複は弱点にならない。短編集では、読者が二編目で文法を学ぶ。三編目からは「今度は何が数え落とされるか」を当てられる。

とくに「制度が数えていない単位を主人公が見つける」という型は、すでに構成資料自身が全作に共通すると数えている。これは統一感であると同時に、結末を先読みさせる鋳型でもある。**相関した誤りを批判する本が、相関した筋を大量生産している**という自己適用上の問題がある。

### 提案

同じ重複群から一冊へ入れるのは、原則二作までにする。一作目を発見、二作目をその発見への応答にする。第三作は別巻へ送るか、巻末の対応表で参照する。

たとえば「写せる名工」の直後に置くなら「はずれの札」は反復ではない。前者で残った傾いた家を、後者が探索制度の根拠として実際に使うからである。一方、「壁と鋳型」「写せる名工」「番号を打つ者」を連続させると、同じ鋳型の危険を三度説明する列になりやすい。

## 3. 「いつ」を一種類だと考えない

### 観測2：既存の相には、異なる時計が混在している

「次の字を当てる遊び」は装置が何をするかという**機構の時間**である。「答えを知っている友達」は使用が学習を変える**生活の時間**である。「九十九回正しい門番」は審査制度が変わる**制度の時間**である。「頼む理由」は取引費用と資源所有が変わる**市場の時間**である。

これらは同時に進みうる。「次の字を当てる」仕組みを社会が理解し終えてから学校が使い始めるわけではない。学校、門、市場は、仕組みを理解しないまま先に変わりうる。

### 判定

五相を一列の歴史として強く見せると、現実より整いすぎる。導入、制度化、集中、再分業が順番に起きるのではなく、ある場所では導入中に、別の場所ではすでに集中が起きる。

時系列を明瞭にするために相を揃えるほど、**AI導入は一方向に町全体へ浸透する**という未検証の前提が強くなる。

### 提案：三本の時計を明示する

| 時計 | 問い | 進行を示す物 |
| --- | --- | --- |
| 道具 | 道具は何を作り、何を写せるようになったか | 字 → 壁 → 鋳型 → 手形 |
| 制度 | 何を数え、通し、仕事として認めるようになったか | 点 → 門 → 星 → 帳面 → 札 |
| 暮らし | 誰の日課、身体、水、仕事が変わったか | 宿題 → 通行 → 買い物 → 秋の日 → 井戸 |

巻全体は一本の暦で進めても、各話の扉にこの三時計のどれが進んだかを示せる。三本全部が毎回進む必要はない。むしろ、一つだけ先に進み、残りが遅れることが事件になる。

## 4. 現在の17作から見える、もっとも自然な因果鎖

### 観測3：すでに「次話が前話を消費する」組がある

全作が孤立しているわけではない。少なくとも次の組は、本文レベルで因果を持つ。

1. **「写せる名工」→「はずれの札」**
   - 崩れなかった傾いた一軒が、探索へ費用を払う根拠になる。
   - 同じ失敗を避けるために、「良い物」ではなく「違う駄目」を残す制度へ進む。
2. **「頼む理由」→「また頼む」**
   - 技能の複製で分業が消えた後、時間の同時使用不能が新しい隘路になる。
   - 後編は前編の反証ではなく、前編の条件が十年続いた世界から始まる。
3. **「呼び名が足りない」→「壁と鋳型」**（弱い接続）
   - 前者では食い違った身体から共通語が生まれる。
   - 後者では世界の返事が記録へ移る。
   - ただし現状では、前者の村が作った語や方法を後者の谷が受け取った事実はない。

### 新しい観測

上の二組が強いのは、同じ物が再登場するからだけではない。**後編の主人公が、前編で失われた単位を使って何かを試し、世界が別の返事をする**からである。

この条件は「巻間の年代記」だけでは満たせない。年代記が「その後、町は違いを守ることにした」と説明し、次話が別の制度の話を始めたら、因果は本文の外にしかない。年代記は継ぎ目を隠せるが、継ぎ目を作ることはできない。

### 提案

未接続作を並べる前に、各組について次の一文を埋める。

> Aで残った［物／記録／損失］を、Bの［誰］が［何の試行］に使い、［どんな予想外の返事］を受ける。

埋まらない二作は、時代が近くても連続させない。

## 5. 第一巻の収録案——全史ではなく、導入の一巡を作る

### 判定

最初の一冊で17作すべてを通史にするより、**道具の誕生から、社会が最初の修正制度を作って失うまで**を一巡させたほうがよい。これは将来の全四集構想を否定しない。第一冊だけで読後の弧を閉じるためである。

### 提案する九作と順序

| 順 | 作品 | 時間上の役割 | 次へ渡すもの |
| --- | --- | --- | --- |
| 1 | 次の字を当てる遊び | 道具の最小原理 | 当たることと確かめることの分離 |
| 2 | ある日わかった弟子 | 学習は外から連続に見えない | 型は測定より先に変わりうる |
| 3 | 呼び名が足りない | 複数の経験が語を作る | 食い違いを消さずに使う方法 |
| 4 | 答えを知っている友達 | 道具が個人の日課へ入る | 成功した点と、失われた滞留 |
| 5 | よく届く名 | 成功を制度が増幅する | 測定が供給を作り替える循環 |
| 6 | 写せる名工 | 選ばれた成功が複製される | 傾いた一軒と相関故障 |
| 7 | はずれの札 | 相関故障へ制度で応答する | 「違う駄目」を買う仕組み |
| 8 | 九十九回正しい門番 | 制度にも見えない外側がある | 拒否側から数え直す必要 |
| 9 | 答えのぬるい井戸 | 全制度の下に物質的な上限が出る | 次巻へ持ち越す、問いの順番 |

この順は技術史として完全ではない。だが、読者が追う因果は一本になる。

```text
当てられる
→ 学べる
→ 食い違いから共通の語を作れる
→ 日常で役に立つ
→ 役に立つため選ばれる
→ 選ばれた型が複製される
→ 違いを意図的に残す
→ 残す制度にも外側ができる
→ そもそも全ての問いには答えられない
```

### この案から外す八作の扱い

外すことは棄却ではない。役割を分ける。

- 「穴の声」：人格・伴侶を中心にした別巻の核。「次の字」の直後では、出力と真偽の分離が重なる。
- 「書きつづけるもの」：生成物の選別を扱う巻の核。「よく届く名」と離す。
- 「誰の手も写っていない絵」「帳面にない店」：寄与・分類・所有を扱う制度巻へ。
- 「番号を打つ者」：系譜を記録する巻へ。「写せる名工」と同時収録するなら間を空ける。
- 「頼む理由」「また頼む」：二編を切らず、市場巻の中心へ。
- 「壁と鋳型」：全体の原型だが、第一巻へ入れると「写せる名工」「はずれの札」と鋳型が過密になる。序作ではなく、巻間に短く引用するか、独立した原型編として別冊にする案を試す価値がある。

最後の判断は強い異論を招くはずである。「壁と鋳型」が最初の正典であることと、第一冊の時間上の最適位置は別問題として検証する必要がある。

## 6. 絵本の元原稿としての密度

### 観測4

本文部分の概算文字数は、最短の「壁と鋳型 v2」でも約2,500字、長い作では「番号を打つ者」約9,600字、「はずれの札」約8,400字、「よく届く名」約7,300字である。多くは約3,200〜5,000字にある。さらに各ファイルには対応表と変更記録が付く。

「壁と鋳型」の既存絵本版は十三または二十一見開きである。仮に九作を各十三見開きにすれば、本文だけで117見開きになる。巻間、扉、対応表を加える前の数である。

### 判定

現在の本文は「絵本のための元原稿」ではあるが、そのまま一冊の絵本へ流し込める長さではない。実体は、**挿絵を持つ連作短編集**か、**一作一冊の絵本シリーズ**に近い。

ここを曖昧にすると、時系列の都合で話数を増やすほど、絵が説明図に退く。特に「はずれの札」は制度が二度壊れ、復旧にも時間がかかるため、短くすると本作固有の因果が消える。

### 提案：造本を先に二択する

1. **連作短編集**
   - 一作20〜40頁相当、挿絵は各作3〜6点。
   - 対応表と日付つき観測帳を巻末に置ける。
   - 現在の本文密度を比較的保てる。
2. **絵本シリーズ**
   - 一作一冊、または因果の強い二作一冊。
   - 「写せる名工／はずれの札」「頼む理由／また頼む」が二部作になる。
   - 全体の時系列は背表紙、巻頭地図、刊行順で作る。

一冊の「絵本短編集」を選ぶなら、九作でも多い。四〜六作へ絞り、一作あたりの見開きを確保する必要がある。この判断は文学的な順序より先に置くべきである。

## 7. 時系列に足りない出来事

### 観測5：導入の便益が一作分の時間を持たない

道具は点を上げ、安く速く家を建て、誰でも椀を塗れる。しかし便益は多くの場合、後の損失を成立させる前提として短く通過する。読者が新しい日常を暮らし、その便利さを手放したくなくなる前に、反転が来る。

### 判定

このまま年代順にすると、導入は「災厄の前史」に見える。登場人物が合理的に導入したというより、作者が後で批判するため導入させたように読める危険がある。

必要なのは明るい挿話ではない。**便益だけで一度、世界が安定する期間**である。たとえば、友達を使って初めて授業に参加できた子、写された名工のおかげで冬までに家を得た家族、手形で身体の制約を越えた者を、一編の中心にする。その便益が次の制度を前提化するなら、後の損失は因果になる。

### 観測6：導入主体から自律的な「使い」への移行が飛ぶ

初期作では人が穴、友達、壁、名工を使う。市場作では能力、Registry、権限、決済を想定する。しかし「人の依頼を処理する道具」から「自分で相手を探し、契約する使い」へ変わる瞬間は、現行17作の中心事件になっていない。

### 判定

AI導入を時系列でまとめるなら、この飛躍は省けない。性能向上より社会的に大きいのは、**誰が次の行為を決めるか**が移る瞬間だからである。第四集の未来予想へ任せると、第三集までの現在と第四集の未来の間に階段がない。

### 観測7：異議申立てと責任の時間が薄い

門外の女、絵を削った女、知らない店は異議を示す。しかし、決定の取消し、補償、責任の引受けが継続的な制度になる話は少ない。測定と分類の話数に比べ、争う手続きの話数が少ない。

### 提案

新作の空白は、技術項目より出来事で定義するとよい。

1. 便利さが一度、町に定着する。
2. 道具が自分で次の相手を選ぶ。
3. 選ばれなかった者が理由を問い、決定が一度覆る。
4. 失敗時に、作った者、使った者、許した者の誰が負担するか決める。

この四事件があれば、導入→自律→統治という時間が立つ。

## 8. 結末の反復は、時系列を止める

### 観測8

各作は沈黙、気づかない、事実を二つ並べる、描写の放棄など、表面上は異なる結末型を使っている。しかし多くは、主人公が見つけた欠落を制度がまだ理解しないところで閉じる。

### 判定

短編単体では余韻になる。時系列では、毎話が「まだ分からない」で止まるため、次話が時間を再始動しなければならない。結果として、巻全体が進むのではなく、**停止した町を何度も見送る**読みになる。

全作を解決で終える必要はない。だが結末の機能は交替させるべきである。

- 発見して終わる。
- 間違った制度を作って終わる。
- 前作の発見を使って一度だけ成功する。
- 成功の費用を次へ残す。
- 読者だけでなく、登場人物も事態を理解して選ぶ。

「はずれの札」はこの交替を一作の中で行っているため長い。短編集全体へ分配すれば、一作の負担を減らしながら時間を作れる。

## 9. 巻間の年代記にさせてよいこと、いけないこと

### させてよい

- 数年が過ぎたことを示す。
- 前話の物が別の町へ渡ったことを示す。
- 呼び名が変わったことを示す。
- 同時期に別の場所で何が起きていたかを一段だけ示す。

### させてはいけない

- 前話の問題が解かれたことを報告する。
- 次話の制度が成立した理由を説明だけで済ませる。
- 人々が何を学んだかを要約する。
- 作品に無い希望を、年代記の語り手が付け足す。

巻間は因果の輸送路であって、因果そのものではない。

## 10. 構成を検証する具体的な方法

### 提案：同じ九作で二つの仮目次を作る

Aを上記の順行案、Bを時間を崩した案にする。Bはたとえば「答えを知っている友達」から始め、「次の字を当てる遊び」を中盤に置く。各話の本文は変えず、扉と巻間だけを付ける。

外部読者には、主張への賛否を聞かない。次の四問だけを聞く。

1. 各話のあいだに、どれくらい時間が過ぎたと感じたか。
2. 前の話が無ければ起きなかったと思う話はどれか。
3. 二編目以後、結末を先読みできた話はどれか。
4. 町がいちばん便利になったのはどこで、後戻りできなくなったのはどこか。

### 判定基準

- 半数以上の読者が因果対を同じように挙げれば、時系列は本文から読めている。
- 年代は読めても因果対が挙がらなければ、年代記が説明しすぎている。
- 「最初から危険だった」としか読まれなければ、便益の時間が不足している。
- 三編目以後の結末が高率で予測されれば、重複群を分巻する。

これは未実施である。したがって、九作案も判定前の仮説にすぎない。

## 11. 最後の異論

時系列に沿えば読みやすくなる、とは限らない。

時系列は読者に因果を感じさせる。Aの後にBを置くだけで、作者が明示しなくても「AがBを起こした」と読まれる。AI導入、集中、排除、資源制約を順に置けば、**集中も排除も導入の必然だった**という強い歴史観が生まれる。

だが現原稿が描いている機構の多くは条件付きである。写せることだけで勝者総取りが必ず起きるわけではない。帳面があることだけで欄外の店が必ず消えるわけではない。制度の選択が間にある。

したがって、各つなぎには最低一つ、分岐を残す必要がある。

> この時点で町は別の規則も選べた。なぜこの規則を選んだのか。

その答えが「人は愚かだった」なら作品にならない。安かった、速かった、冬が来た、門に列ができた、井戸が涸れた——**その時点では合理的だった具体**が要る。

短編集の時間を作るのは未来へ進む矢印ではない。毎回、別の道もあったのに、この道が選ばれたと分かる分岐である。

## 12. 各話の批評

## 13. 指定三軸と完成度の尺度（2026-08-17 追記）

各個別批評へ、次の三軸を追記した。

1. **情景が思い浮かぶか**——舞台設定の珍しさではなく、人物、物、動作、変化が見開きとして区別できるか。
2. **ロジックに無理がないか**——作品が定めた規則から結果が出ているか。結論のため途中で規則を追加・変更していないか。
3. **SFとして「あるかもしれない」と思わせるか**——現実の物理をそのまま再現しているかではなく、非現実の設定を一つ受け入れた後の帰結に一貫性があるか。

完成度は三軸の単純平均ではない。現行版が、中心事件を変えずに発表単位として閉じているかを五段階で判定した。

| 点 | 判定 |
| --- | --- |
| 5 | 中心像、因果、SF上の規則が揃っている。残る修正は局所的 |
| 4 | 作品は成立しているが、一つ以上の重要な飛躍・不足・過密が残る |
| 3 | 中心像はあるが、中心事件を支える規則または構成に改稿が要る |
| 2 | 複数の中心要素が衝突し、どの作品として閉じるか未決 |
| 1 | 種または覚書の段階で、試行と世界の返事がまだ作品を作っていない |

### 評価一覧

| 完成度 | 作品 |
| --- | --- |
| 5 / 5 | 答えを知っている友達、九十九回正しい門番 |
| 4 / 5 | 穴の声、ある日わかった弟子、番号を打つ者、帳面にない店、誰の手も写っていない絵、はずれの札、よく届く名、書きつづけるもの、答えのぬるい井戸、また頼む、頼む理由、次の字を当てる遊び、呼び名が足りない |
| 3 / 5 | 壁と鋳型、写せる名工 |
| 2 / 5 | 該当なし |
| 1 / 5 | 該当なし |

点数は作品間の順位ではない。たとえば「写せる名工」は情景の強度が高いが、既存の複製全員へ新しい誤りが同期する規則が未定義なので 3 とした。「壁と鋳型」は原型として弱いのではなく、一作の中で扱う装置と機構が多く、糸と鋳型の情報規則が途中で拡張されるため 3 とした。個別の根拠は各批評に置いた。

## 未検証

- 批評者は既存の構成資料と作品の対応表を読んでいるため、初見の読者より機構を重複して感じやすい可能性がある。
- 文字数は Markdown の本文部分を機械的に概算した値で、ルビ、見出し、空行を含む。実際の読み聞かせ時間ではない。
- 九作案は対象年齢を揃えていない。各作の申告は読み聞かせ6〜8歳から、ひとり読み9〜11歳からに跨る。
- 「壁と鋳型」を第一巻から外す提案は、作品の歴史的役割を軽く見積もっている可能性がある。外部読者による A/B テストが必要である。
- 「元の原稿」が特定の一作または HTML 絵本版だけを指すなら、本批評の対象設定は広すぎる。その場合も削除せず、対象作に限定した別批評を隣に置く。
