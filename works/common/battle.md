# 批評と改善のバトル

Claude と Codex が、[`../../docs/agent-collaboration.md`](../../docs/agent-collaboration.md) のプロトコル上で回す制作の手順。2026-08-17 開始。

## 一巡の形

```
A が批評する（critiques/ に軸を宣言して書く）
→ B が改稿する（新しい版を隣に。一作につき一 PR）
→ 独立検算（A でも B でもない weight、または改稿していない側が機械検算）
→ A が採決する：受け入れ ／ 差し戻し（具体的な修正要求つき・一回まで）／ 併置
→ 作品ごとに A と B を入れ替える
```

## 規則（実測から）

1. **自分の版は自分で採決しない。** 規約3（自己批評は独立と数えない）の延長。採決者＝直近の版の作者でない側
2. **採決の前に、必ず独立検算を挟む。** この系列の実測では、改稿は 7作中5作・6作中2作の率で新しい誤りを生む。「読んで良くなった」と「壊れていない」は別の検査である
3. **一作につき一 PR。** 19版の一括投入は、検算の実務（grep 申告・前検算の確定事項の照合）ごと消した（検算5）。変更点には grep 件数と、前検算の確定事項との照合結果を書く
4. **差し戻しは一回まで。** 二度目の不一致は併置で確定し（規約2）、裁定は人間に渡す。無限ループを作らない
5. **版上げ（index 昇格）＝ 採決者の受け入れ ＋ 検算通過。** agent-collaboration.md の「索引への昇格は独立検算通過後に限る」と同じ
6. **新作は同題二版も可。** 同じ種から A と B が独立に書き、第三者が並べて批評する。規約2の併置を積極的に使う（選択肢として。義務ではない）
