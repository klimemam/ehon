## 2. 新しい種（四つ）

### S1　下請けが消える　── 素材 §13・§16（最重要）

**主張**：人間の経済に多層の下請けがあるのは、技能が写せず、時間が有限だからである。写せるようになると、頼むより自分でやったほうが安くなる。

```
C_自前     = 道具代
C_外注     = 相手の値 + 頼む手間 + 検める手間
```

相手も同じ道具を使うなら、外注は原理的に高い。**残るのは、相手が写せない何かを持っている場合だけである。**

- **章**：8.1（委譲）の裏。map.md に無い ⇒ **8.13 として追加提案**
- **半歩／一歩／二歩**（[`method.md`](method.md)）：**二歩。** 「AIエージェント同士が取引する経済が来る」は半歩で、誰でも言う。**その経済が来ない理由**を言うのは二歩である
- **設定（規約6）**：写せる技。ただし [`utsuseru-meiko`](../utsuseru-meiko/v5.md) と同じ設定になるので、**同じ町の別の帰結**として書くか、設定を変えるか、週末に決める
- **世界が返事をする三回（規約5）**：①値を下げる → それでも来ない ②早くする → 来ない ③腕を上げる → 来ない。**返事は毎回「来ない」で、理由は腕と無関係である**
- **反転**：職人が失ったのは腕ではない。**頼む理由**である
- **残る者**：井戸を持つ者。通行札を持つ者。畑を持つ者。**誰も賢くない**

### S2　襲名　── 素材 §7・§21.5（Risk Epoch／黙って中身が入れ替わる）

**主張**：名前は続いている。評判も続いている。だが、その評判を作った者はもういない。過去の実績を今の実行に当てはめてよいかは、名前を見ても分からない。

- **章**：8.7（provenance）の未使用面 ⇒ **8.10 として追加提案**
- **半歩／一歩／二歩**：**一歩。** モデルの黙った差し替えは業界では既知だが、「評判とは個体のものではなく、個体が属していた集団のものだった」まで行くと一歩先
- **設定（規約6）**：屋号を継ぐと、前の代の帳面がそのまま引き継がれる町。設定はひとつ、そのまま機構
- **世界が返事をする三回**：①頼む。良い ②頼む。良い ③頼む。悪い。**——で、いつ代替わりしたのかを町は数えられない**
- **反転**：**遅れて分かることの本質は、遅れではない。** 何回失敗が積もれば代替わりだと言えるのか、誰も決めていないことである
- **物理的な失敗**：先代の道具が残っていて、寸法が合わない
- 先行：Akerlof（G19）ではなく、**同一性の持続**の問題。近いのは船の Theseus だが、こちらは**評判が同一性の担保として使われている**点が違う

### S3　あらかじめ決めた損　── 素材 §4（parametric payout／basis risk）

**主張**：本当の損は測れない。だから何を損と呼ぶかを、事前に取り決める。やがて、損とはそれのことになる。

- **章**：map.md に無い ⇒ **8.11 として追加提案**
- **半歩／一歩／二歩**：**一歩半。** パラメトリック保険の考えは既存（NAIC）。新しいのは、**取り決めた損と本当の損のずれ（basis risk）が、時間とともに埋まるのではなく、本当の損のほうが取り決めに寄っていく**こと
- **[`hyoban-no-yoi-shokunin`](../hyoban-no-yoi-shokunin/v5.md) との差**：職人は**評価指標**が事実を作る話。こちらは**損害の定義**が事実を作る話。指標は上を向き、損害は下を向く。**同じ Goodhart の裏表だが、向きが違うので別作になる**
- **設定（規約6）**：鐘が鳴らなかったら銭を払う、という取り決め
- **世界が返事をする三回**：①鐘が鳴らず、払われた。合っていた ②鐘は鳴ったが、家は傷んだ。払われない ③鐘だけを鳴らすようになった
- **反転**：**取り決めは損を測る道具として作られ、損を作る道具になった**

### S4　申告する市　── 素材 §20・§21.6（自己申告の腕前で選ぶと、嘘つきが選ばれる）

**主張**：腕を申告させて安い順に選ぶと、いちばん安く申告した者が選ばれる。それは、いちばん腕のある者ではない。

- **章**：8.4（案内人）の未使用面 ⇒ **8.12 として追加提案**
- **半歩／一歩／二歩**：**半歩。** Akerlof(1970) がそのまま当たる（[`survey-toc.md`](survey-toc.md) G19）。**単体では弱い**
- **[`dare-no-te-mo`](../dare-no-te-mo/v5.md) との差**：あちらは**寄与を証明できない**話（過去向き）。こちらは**能力を証明できない**話（未来向き）
- **一歩に押し上げる案**：素材 §19 と組む。**疑うのにも銭がかかる。** 疑う費用が、外れたときの損より高い日がある。だから嘘は、見破られないのではなく、**見破らないほうが安いから生き延びる**
- **これなら一歩。** 単なるレモン市場ではなく、**検証の費用が均衡を決める**話になる
- **設定（規約6）**：申告した腕前が、そのまま札に書かれる市

## 3. 素材の一番いいところは、まだ種になっていない

素材 §6 の一行。

> Palantir は「何が真で、何をしてよいか」を問う。
> 清算の層は「誰が誰に何を約束し、それは起きたのか、誰が誰にいくら負うのか」を問う。

**この二つは別の帳面である。** 前者は世界の記述、後者は約束の記録。**世界が変わっても約束は消えないし、約束が果たされても世界は変わらないことがある。**

これは寓話になる形をまだ持っていない。週末に一度だけ試して、立たなければ捨てる。

## 5. 素材への疑い（作品に引く前に確認する）

- 素材が引く arXiv 番号のうち、**2602／2603／2604／2606 番台**は、いずれも「最近のプレプリント」と素材自身が断っている。**引くなら番号と主張の対応を確認する。** [`positioning.md`](positioning.md) §4 で 23 件の書誌誤りが出たのと同じ種類の危険がある
- 素材 §13 の費用の式は、**頼む手間と検める手間をゼロと置いていない**が、**自前でやる側の失敗の費用もゼロと置いていない**か。ここは寓話の骨になるので、週末に一度式を書き下す
- 素材は「複製できる技能」と「複製できる知識」を同じ扱いにしている。**分けたほうが強い可能性がある**
