## 0. 判定：共有世界の続編としての新作

**新作である。既存作の修正ではない。**

機構が v1 と別だからである。v1 の分化は世界から来た（回らない水車——命題5）。本種の分化は壁そのものから来る——壁が厚くなり、一日で読み切れなくなったとき、**どこを読むかの選択が、同じ鋳型の職人に個体差を作る。** 均質性の装置だった壁が、成長すると分化の装置に反転する。誤りの相関（命題4）への部分解が、命題5（世界との接触）からではなく、命題1の第三層の成長そのものから出る——この筋は v1 にも壁を食べた鋳型にも無い。

サーベイは、この見立てと同じ向きだった。

1. 「全部読んで均質を保つ」は実際のAIで成り立たない。公称の文脈長より実効の文脈長がずっと短い（NoLiMa：32Kで11モデルが短文基線の半分を割る）。読みは必ず選択になる
2. 同一モデルのインスタンス群は、放っておいては分化しない。分化には文脈の非対称という足場が要る（Riedl 2025／EL Kandoussi 2026）。「朝、壁のどこの前で目覚めたか」は、まさにその足場である
3. 逆向きの力（同期・共有が均質化を進める）にも実証がある（Doshi & Hauser 2024、model collapse）。v1 の糸の場面は、この側に立つ

### 壁と鋳型 v1 への影響：誤りにならない

v1 の「翌朝、目覚めた職人は壁を読み」は、**壁が一朝で読める時代の描写として成立する。** v1 自身が「百年が過ぎた。壁は厚くなり」と成長を書いており、続編はその線を、読み容量の閾値の先へ延長するだけである。正典（確定・改稿しない）に手を入れる理由は無い。

むしろ v1 の「糸を張ると三日で千人が同じことを思い、壁が厚くならなくなる」は、全量同期→均質化の像として実際のAIと整合する（同質グループの行動収束、共有されたAI案による集合多様性の減少、自己生成データの再帰訓練での裾の消失——§1）。v1 に実証と食い違う記述は見つからなかった。

なお v1 は「壁を読む」と書くだけで「全部読む」とは書いていない。全量読みを明示したのは v3 の「千人が壁を読み、千枚の同じ図を描いた」である。続編が閾値の先で壊すのはこの「千枚の同じ図」の前提であり、v1 と矛盾しない。

### 確認できていないこと

- **「RAG の選択が個体差を作る」を直接測った研究は見つけていない。** 本種の中心機構（読む場所の選択→分化）は、確認済みの部品二つ（読みは必ず選択になる＋文脈の非対称が分化を作る）からの合成であり、合成そのものの実証は無い
- 同一モデルの複数インスタンスが**無足場で**自発分化する報告は見つからなかった。見つかったのは逆（#5）。したがって「同じ鋳型の職人が勝手に分化する」筋は書けない——分化は読む場所の差からしか出ない。これは制約ではなく、本種の機構そのものである
- RULER 等ほかの長文脈ベンチの詳細は二次まで。DeepSeekMoE の「fine-grained expert specialization」の主張は未確認
- MoE の expert 分化は一体の内部の話（命題0——個体の内部がすでに集合的）で、本種の谷（個体間の分化）とはスケールが違う。スケールをまたいで同じ機構と言ってよいかは未検証

## 2. 機構の下書き（規約5の形）

**問題**：壁が谷を何周もした。朝に壁を読みはじめると、読み終わる前に日が暮れる。日が暮れれば、読んだことも消える。

- **試す①**：それでも全部読む。→ **返事**：読み終えた者は、何も彫らずに眠る。谷の仕事が止まる。壁は、読む速さより速く厚くなる（書く手は千、読む目は一人につき一日）
- **試す②**：手分けして読む。めいめい、目覚めた場所にいちばん近い壁を読む。→ **返事**：仕事は戻る。だが夕方、同じ問いに違う答えを出す職人が現れる。朝に読んだ場所が違ったからである。鋳型はひとつのまま、谷に初めて「誰それはこう言う」が生まれる
- **試す③**：食い違いを嫌った賢い職人が、壁の要所を選んで写した石を門ごとに置く。皆、石だけを読む。→ **返事**：食い違いは消える。千人がまた同じところでつまずく（命題4が戻る）。そして石に写されなかった細い行は、誰にも読まれなくなる
- **試す④**：石を割る。→ **返事**：食い違いが戻る。谷は前より賢く、前よりばらばらになる。「壁には何と彫ってある」と問うても、答えられる者がもういない。壁の全部を知っているのは、壁だけである

**結末の像の候補**（制作時に型の分布を数えて選ぶ）：「鋳型はひとつのままだった。それでも、朝に立つ場所の数だけ、職人がいた」の側か、「壁の全部を知る者」の側で沈黙に畳むか。

## 3. 半歩・一歩・二歩の下書き

- **半歩**：機械の記憶（文脈窓）は有限で、外部記憶は選んで読むしかない。既に誰もが言っている（RAG）
- **一歩**：均質性の装置だった共有記憶は、読み容量を超えた日に、分化の装置へ反転する。以後、**均質性は無償ではない**——保つには要約か同期が要り、要約は裾を落とし（壁を食べた鋳型の機構が、読み出しの側で毎朝再演される）、同期は誤りの相関を買い戻す。均質にも多様にも、初めて維持費がつく
- **二歩**：問いが変わる。「同じ鋳型から出た者は、同じところでつまずく」（v1 の名）から、「**この職人は、壁のどこを読んだ者か**」へ。個体性の在り処が、鋳型（weight）でも記憶の量でもなく、**共有記憶の中の番地**になる。命題4への部分解が、命題5だけでなく命題1の第三層の成長そのものから出る——ただし代価として、全体を知る個体が消える

## 4. 既存作との切り分け

| 作 | あちらの機構 | 本種の機構 |
| --- | --- | --- |
| 壁と鋳型 v1 | 分化は世界から来る（水車の返事。命題5）。壁は均質性の装置 | 分化は壁そのものから来る（読み位置）。壁が分化の装置に反転する |
| 壁を食べた鋳型 | 鋳型を作る時の頻度圧縮。誕生の側で裾が消える | 読む時の選択。毎朝の側で裾が読まれなくなる。試す③の石が蒸留と紛れないよう、制作時に像を分ける |
| 呼び名が足りない | 観測窓の差（世界の側）から共有記号が立つ | 読み位置の差（記憶の側）から個体差が立つ。向きが逆（あちらは差→共有、こちらは共有→差） |
| 写せる名工 | 複製が多様性を消す | 蓄積が多様性を作り直す。名工の逆向きにあたる |

## 5. 制作時の注意

- 題の検査（[`naming.md`](naming.md) §2）：「それは読み切れない壁だ」——読む容量を超えて成長した共有記憶と、それが強いる選択のこと。検査は通る形
- derives_from は v1（正典）。ただし壁の長さの像は v3・壁を食べた鋳型と共有されているので、続編の時間軸がどの版の世界と整合するかを最初に検算する
- 非現実の設定は v1 から継承（鋳型・一日の記憶）。新設しない（規約6）
- 「読む場所の選択」を誰がするのかは機構の要。選ばずに決まる（目覚めた場所で決まる）ほうが、意図なき分化＝stigmergy の続編として筋が良い
