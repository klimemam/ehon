# v1 記録上の残存三点

本文と機構は PR #27 の採決を通過した。ここで指摘するのは本文の誤りではなく、採決後に残った付属記録と、後から確定した構成との差である。規約1に従い v1 は書き換えず、次版または造本へ渡す。

## 1. 読み聞かせ年齢

frontmatter は `read_aloud_from: 7歳` のままである。第一巡では、型染めの工程語と「仕事から外された者が客として数えられない」という含みを考え、挿絵を伴う読み聞かせでも8歳からを提案した。

これは作品の採否を左右しない。造本で工程を絵が十分に運べるかを確認し、7歳のままにするなら、その根拠を造本側へ記録する。

## 2. 設計記録の旧表現

対応表は既に、

> 名前の無かった仕事が、頼まれる仕事になる。

へ直った。一方、設計の記録には「見る仕事に名前が付く」が残る。本文に起きたのは命名ではなく依頼である。次版では「見る仕事が、頼まれる仕事になる」に揃える。

## 3. 第一部での位置

執筆時の frontmatter は「答えを知っている友達の後、第二部の前」とする。その後、人間裁定Aを反映した `works/common/kousei-rev1.md` 第三稿で、第一部は次の順に確定した。

`次の字 → 弟子 → 友達 → 呼び名 → 小刀`

したがって現行の位置は「呼び名が足りないの後、第二部の前」である。執筆時点の記録は誤りではないため残し、造本と次版は現行構成を採る。

## 判定

軽微。v1本文を変更しない。次版または `book-proto-2` で三点を検収する。
