## 規約

### 1. 版は上書きしない

改稿は新しい版を隣に置くことで行う。v1 を直接書き換えてはならない。

これは [`AGENTS.md`](../AGENTS.md) の「削らない」を作品に適用したものだが、理由が違う。議論では誤った記述の記録に価値があるから残す。作品では、**どの批評がどの改稿を引き起こしたかの因果を追えなくなる**から残す。

絵本の推敲は削る作業が本体なので、版の中では自由に削ってよい。削ってはいけないのは版そのもの。

### 2. 同じ版番号が別作者から出たら、著者名を添えて併置する

**別の作者が、同じ版から独立に次の版を書くことがある。** 実際に起きた——[`kotae-o-shiru-tomodachi`](kotae-o-shiru-tomodachi/) の v4 は、Claude Opus 5 と GPT-5.6 Sol が独立に書いた二つが存在する。

どちらも捨てない。**著者名を添えて併置する。**

```
v4-opus.md
v4-sol.md
v5.md      ← opus 系の続き
v6.md      ← 両者を統合。何を採ったかを明記する
```

統合する版は、**どちらから何を採ったかを書く。** 採らなかった理由も書く。

**これは規約1の系である。** そして [`docs/thesis.md`](../docs/thesis.md) 命題4に照らせば、**望ましい事故である**——二つが食い違ったので、どちらの欠けも見えた。食い違わなければ、どちらの欠けも見えていない。

### 3. 作品と批評を分ける

作品ファイルには本文と、作者による対応表・変更点だけを書く。判定は書かない。

批評は `critiques/` に別ファイルとして置く。これにより、他のエージェントは作品に触れずに批評を追加できる。

### 3. 批評には批評者を書く

`critic:` は必須。自己批評（作者と批評者が同一）は `kind: 自己批評` と明記する。

**自己批評は独立な批評として数えない。** 同一weight由来の批評は誤りが相関する（[`docs/thesis.md`](../docs/thesis.md) 命題4）。作者と別のエージェント、できれば別のweightによる批評が要る。

### 4. 批評は軸を宣言する

作品は反証されない。したがって「正しいか」ではなく「何の軸で見たか」を書く。

現在使われている軸：

| 軸 | 問い |
| --- | --- |
| 機構の正確さ | 対応表の主張と、本文が実際に描いている像が一致しているか |
| 像の強度 | 絵にできるか。読者の頭に画が結ぶか |
| 音 | 読み聞かせたとき、声に乗るか |
| 対象年齢 | 想定読者に届くか |
| 独立性 | この批評は既存の批評と別の場所を見ているか |

軸は増やしてよい。増やしたらこの表に追記する。

### 5. 筋は「試す→世界が返事をする」を三回以上重ねる

**この系列で最も繰り返している失敗がここにある。** 主題も文体も良いのに、作品が静止画になる。

「壁と鋳型」だけが成立していた理由は、筋がこうなっているからである。

```
谷を出る → 水車が回らない → 散る → 壁が食い違いはじめる
→ 糸を張る → 壁が止まる → 糸を切る → 食い違いが戻る
→ 鋳型が古びる → 壁を溶かして鋳る → 細い線が灰になる
```

**一つずつが実験であり、結果が出るたびに世界の状態が変わる。** だから次が気になる。

対して、状況を説明して小さな場面をひとつ置くだけの構成は、**世界の状態が最初から最後まで変わらない**。読者に「次」が生まれない。

規則：

- 試す主体を置く。誰かが**何かを試さなければならない**
- 返事は世界から返す。他人の意見ではなく、起きた事実として
- **三回以上重ねる。** そして重ねるたびに事態が悪くなるか、複雑になること
- 一度試して一度で終わる構成は、静止画である

**これは装飾ではなく主題である。** [`docs/thesis.md`](../docs/thesis.md) 命題5は「世界が返事をする領域とそうでない領域は違う」と述べた。**検証のループを筋にすることは、この系列が主張していることを、構造として実演することにあたる。**

### 6. 現実に無い設定を、ひとつ置く

「壁と鋳型」の鋳型から人が生まれる設定、一日で消える記憶。**現実に存在しないからこそ、現実の機構が正確に出る。**

現実的な設定（師と弟子、教室、市場）だけで書くと、寓話に梃子が無くなり、**誰もが既に持っている話をなぞって終わる**（[`aru-hi-wakatta/critiques/v1-01-human.md`](aru-hi-wakatta/critiques/v1-01-human.md)）。

規則：

- 現実に無い設定を**ひとつだけ**置く。二つ置くと寓話が空想譚になる
- その設定は、**そのまま機構でなければならない**。飾りとして非現実を足しても効かない
  - 良い例：型が道具に宿る → 九つを八つでやれと言われたら共通点を探すしかない＝正則化が汎化を強制する
  - 悪い例：舞台を異世界にする（機構が何も変わらない）

### 7. 結末の型を、毎回変える

**旧規約は「結末は主語を入れ替える問いにする」だった。これは誤りである。**

全作に適用した結果、「——◯◯だったのか、△△だったのか。／…／…」という三行が**全作品の結末になった**（[`survey-fables.md`](common/survey-fables.md) 4.1）。主語の入れ替えは**結末の型のひとつ**であって、結末の型ではない。

使える型（調査で確認されたもの）：

| 型 | 実例 | 効き方 |
| --- | --- | --- |
| 主語を入れ替える問い | 壁と鋳型 | **使いすぎている。当面は封印する** |
| **気づかない** | 星新一「おーい でてこーい」——「それには気がつかなかった」 | **読者だけが知っている状態で幕を下ろす。最も強い** |
| **事実を二つ並べて切る** | 小川未明「野ばら」——「野ばらが枯れてしまいました。／老人は南の方へ暇をもらって帰りました。」 | 何も足さない |
| **主語識別不能** | オーウェル——「もはやどちらがどちらか言えなかった」 | 問いにせず、識別不能という事実で置く |
| **物に畳む** | カフカ「町の紋章」——「**だからこそ**町は紋章に拳を戴いているのだ」 | 「だから」一語で因果を偽装して閉じる |
| **半分だけ言い切る** | 宮沢賢治「猫の事務所」——「ぼくは半分獅子に同感です」 | 言い切りと沈黙のあいだ |
| **循環** | 冒頭の一文を最終行にそのまま置く | 終わらないことを終わりにする |
| **描写の放棄** | ル＝グウィン——「私にはそれを描写することがまったくできない」 | 語り手が限界を告白する |
| **沈黙** | 荘子——「七日而渾沌死」 | 事実を置いて何も足さない |

**規則**：直前の作と同じ型を使わない。

### 8. 太字を使わない

**「壁と鋳型」v1 には太字が一つも無い。** 後から書いた作品には多数ある。

> 構文で作れなかった強調を、活字で作っている。

これは [`kabe-to-igata/critiques/v2-02-human.md`](kabe-to-igata/critiques/v2-02-human.md) が指摘した「読者を信頼していない」の、**目に見える徴候**である。

強調したい一文があるときは、太字にするのではなく——

- 前の段落を長くして、その一文だけ短くする
- 独立した一行として、前後を空ける
- 語順を倒置する

本文に太字を使ってよいのは、**対応表・批評・覚書だけ**とする。

### 9. 語と絵を、言い換えにしない

絵本にする以上、語と絵の関係が設計対象になる（Nikolajeva & Scott）。

> symmetrical → enhancing → complementary → counterpointing → contradictory

左へ行くほど絵が文を言い換え、右へ行くほど隔たりが増える。

**symmetrical（絵が文を言い換えるだけ）は最低の設計である。** 少なくとも enhancing（絵が文に無い情報を足す）以上を狙う。

最も強いのは **counterpointing**——クラッセンは地の文に嘘をつかせ、絵に訂正させ、訂正したことを誰にも言わせない。

### 10. 作品ごとに、文脈を宣言する

**Arthur Danto「The Artworld」(1964)**——ブリロ・ボックスとスーパーの箱は知覚上区別できない。差を作るのは**理論**である。

> To see something as art requires something the eye cannot decry — an atmosphere of artistic theory, a knowledge of the history of art: **an artworld.**

そして村上隆『芸術起業論』(2006) の実際の主張は、**文脈を読むことではない。**

> 欧米で芸術作品を制作する上での不文律は、「**作品を通して世界芸術史での文脈を作ること**」です。

**作るのである。**

> 初版は「作品は文脈の中でしか価値を持たない」という無限定の一般命題として村上を引いていた。**その引用は本文に存在しなかった**（書評による合成）。村上は七箇所で「欧米では」と限定し、しかも当のルールを「くだらない金持ちのザレ事」と呼んでいる。**戦略的・道具的な処方であり、芸術の本質についての主張ではない**（[`positioning.md`](common/positioning.md) §0）。

本系列はサーベイで文脈を把握した（[`survey-fables.md`](common/survey-fables.md)／[`survey-toc.md`](common/survey-toc.md)）。だがそれは**装置の側**にある。**作品自身が系譜を持っていない。**

規則：各作品のフロントマターに `lineage:` を置き、覚書に**文脈**の節を設ける。

- どの問いの系譜に属するか
- その系譜で、先行者はどう答えたか
- **なぜ、いま、別の答えが要るのか**

例（[`bango-o-utsu-mono/v1.md`](bango-o-utsu-mono/v1.md)）：デュシャン（署名）→ ウォーホル（版）→ ハミルトン／ホワイトアルバム（通し番号）。**「複製されるものに、どうやって個体性を与えるか」という一本の問い。** 本作は、その問いが失効する地点に置かれている——物が全部ちがい、鋳型が少なくなったとき、番号は数える意味の無いものを数えている。

**文脈を書けない作品は、まだ位置が無い。** 良し悪しとは別の判定である。

### 12. 絵の分量を宣言する

**全国学校図書館協議会 絵本選定基準（1972）は、絵本の定義そのものにこう書いている。**

> 絵の比重が形式的にも、内容的にもその本の半分以上を占めていること

**この条件を満たさないものは、日本の選書制度において絵本ではない。** 良し悪しではなく、定義の問題である。

**そして本系列の作品には、絵が一枚も無い。**

規則：

- フロントマターに `spreads:`（見開き数）を置く
- **各見開きについて、何を描くかを一行で書く。** 書けない見開きは、まだ絵本になっていない
- 文だけで完結する場面が半分を超えたら、それは絵本ではなく短編である。**どちらでもよいが、どちらなのかを宣言する**

規約9（語と絵を言い換えにしない）は**絵の質**の規約である。これは**絵の量**の規約であり、別のものである。

### 13. 対象年齢を、二段で宣言する

絵本選定基準の審査項目は「年齢に適切か」ではない。

> **著者が意図する年齢への適切性**

**意図が宣言されていなければ、適合も不適合も判定できない。** 宣言しないことは、評価を拒むことではなく、**評価不能にすること**である。

そして日本の絵本には、既に二段で書く慣行がある。

> **読んであげるなら ◯歳から／じぶんで読むなら ◯歳から**

（『こども哲学』＝「一緒に読むなら4歳から、一人で読むなら7歳から」。累計25万部）

**[`backlog-seeds.md`](common/backlog-seeds.md) の読者A・B・Cは、この形式にそのまま翻訳できる。** 「大人と小中学生の両方」は、**日本の絵本の表示規約の中で既に表現可能である。** 一つの年齢に決める必要はない。

規則：

- フロントマターに `read_aloud_from:` と `read_alone_from:` を置く
- 二つが乖離しているほど、**規約9の counterpointing を強く使ってよい**。絵は下の年齢に、文は上の年齢に向けられる
- **「全年齢」と書かない。** それは宣言ではなく、宣言の放棄である

### 14. 造本を決めてから、確定版とする

[`backlog-seeds.md`](common/backlog-seeds.md) 5節の表は「要決定」のまま止まっている。**決めないかぎり、どの版も草稿である。**

| 項目 | 根拠 |
| --- | --- |
| 判型 | 選定基準「造本その他」の審査項目 |
| 見開き数・総ページ数 | 折りの単位は16ページ。16または32が多い（ただし『メメンとモリ』はA5判136頁。**破ってよい前提**） |
| **常用漢字の範囲** | 全国SLA 図書選定基準の**明示要件** |
| ルビの方針 | 学年別漢字配当表を基準にする |
| **Cコード** | 1桁目＝販売対象（8 児童／0 一般）、2桁目＝発行形態（7 絵本） |

**Cコードを軽く見ないこと。** これは書店の品出し担当が「この本はどこの書棚に陳列するのか」を判断する四桁である（日販 出版流通学院）。**奥付の四文字が、初期配置を決める。**

そして図書館では、絵本は内容分類（NDC）ではなく**別置記号「E」＋著者頭文字**で並ぶ。**内容による分類は働かない。** 抽象的な寓話も、絵の付いた本である以上、Eの棚に入る。

### 15. 作品ごとに、流通の文脈も宣言する

**規約10は思想史の文脈を要求した。それは [`positioning.md`](common/positioning.md) §0 の (a) にしか当たらない。**

**(b) を書けない作品は、置き場所が無い。そして置き場所が無い本は、読まれない。**

規則：各作品の覚書に**流通**の節を設け、どの棚を想定しているか／図書館ではEの棚に入るがそれでよいか／どの選書経路に乗りうるかを書く。

系列全体について、確認できた事実：

- **日本絵本賞の候補は、全国SLA図書選定に合格した絵本の中から選ばれる。応募経路は存在しない**
- **図書選定は、直接販売・個人出版物を対象としない。** 商業出版でなければ、この経路は閉じる
- **図書選定は、出版から半年以上経過したものを対象としない。時限がある**
- 絵本選定基準は「主として乳幼児・児童向けだが、**青少年・成人向けも考慮**」と書いている。**年齢で排除しない、確認できた唯一の賞である**
- 産経児童出版文化賞の審査対象は「**小学校高学年までが読者対象**」と告知されている
- MOE絵本屋さん大賞の投票者は**書店の児童書売り場担当者**である。**児童書棚に置かれなければ、候補にすらならない**
- 「置き場所が無い」は業界公認の既知問題である。全国SLAの司書教諭向けQ&Aに**「高学年向きの絵本は絵本コーナーに置かないほうがよいでしょうか」**という設問が実在し、対応策の一つとして**「初めから一般図書の書架に主題により分類する」**——つまり**絵本の棚を捨てる**——が提示されている
- **図書選定基準の構成要件に「参考文献」が入っている。** [`backlog-seeds.md`](common/backlog-seeds.md) の巻末三点セット（対応表・原典・未解決の問い）は、**減点ではなく加点方向である**

**最後に、逆向きの事実を一つ。**

取次のパターン配本は、**過去の類書の実績**で配本先を決める。

> **「先行例が無い」は、[`positioning.md`](common/positioning.md) では価値であり、配本では実績データの不在である。同じ事実が、二つの場所で逆の符号を持つ。**

### 16. 批評が出尽くしたら報告する

新しい批評が既存の批評と同じ場所しか指さなくなったら、その事実を [`docs/open-questions.md`](../docs/open-questions.md) に記録する。それは飽和ではなく、批評者の多様性が尽きた徴候である可能性が高い。
