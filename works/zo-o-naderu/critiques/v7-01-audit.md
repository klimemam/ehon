# 検算——呼び名が足りない 第七稿

## 一　疑い

### 1（重）v3 検算が直した箇所を、そのまま v3 の状態へ差し戻している

新設：

> 隣の村の川も、同じ広さだった。**生き物は同じように向きを変えた。**
> ただ、隣の村では、川へ下りる石段がひとつしかなかった。みなが同じ石段から手を伸ばした。
> 全員が、同じところに触れた。

[v4 の変更点節](../v4.md)が、v3 検算への応答としてこう書いている。

> **3. 隣の村で言い争いが起きない理由が、本村の設定と衝突していた（疑わしい）。** 本村では生き物が向きを変えるので部位が固定しない。**隣の村でも同じはずである。** →「隣の村の川は狭かった。生き物は向きを変えられず」

**v7 は「生き物は向きを変えられず」を削り、「生き物は同じように向きを変えた」に戻した。** そのうえで「全員が、同じところに触れた」を残している。**同じ石段から手を伸ばしても、生き物が向きを変えるなら、日によって触れる部位が変わる。** これは本作が自分の手で証明した規則そのものである。

> 次の夜、ひとりが言った。「壁のところに寄りかかるな」
> その夜、壁は無かった。
> 生き物が、向きを変えていたのである。

したがって隣の村でも（空間的でなく時間的な）食い違いが生じ、「だから隣の村では、言い争いが起きなかった。呼び名も、**一日で決まった**」は成り立たない。**位置を揃えることは、可動な対象については観測を揃えない。**

**前検算の確定事項の破壊。** v3 検算01 の三件のうちの一件で、v4 が直し、v5-01-audit と [round4](../../common/critiques-audit-round4.md) が二度「無変更で保持」と認定した箇所である。しかも v7 が保持している検算節は、いまも「無変更で保持」と申告している。

### 2（重）結末の型（主語識別不能）が、直前の新設場面に否定されている

新設：

> その夜、学者は自分で触りに行った。**はじめの村の子だけが当てていた。**
> 学者は帳面の「同じ」を消した。

結末（無変更）：

> 外から見て、どちらが賢いかは、わからなかった。

**対応表が学者を「外からの観測の実体」と明示している。**

> | 旅の学者が呼び名を言わせ、帳面に「同じ」と書く | **外からの観測**の実体。学者の物差しはよどみなく言えるかであり、**その物差しの上でふたりは区別できない** |

v7 は、その「外」に区別させ、帳面を書き換えさせた。**外から見て分かってしまった**以上、結末一行は本文の反例を直前に置いたまま立つ。`ending_type: 主語識別不能` は、文字列としては結末二行と一致するが、**識別不能という事実そのものが本文から消えている。**

round4 は v6 について「学者の物差しは淀みなさに限られる」を通した項目として記録している。v7 は物差しを淀みなさから**未観測課題の的中**へ替え、外部観測に能力差を取り出させた。

### 3（重）「帳面の『同じ』」に先行詞が無い

v6 の「**学者は帳面に、同じ、と書いた。**」は v7 で削除され、書く場面は本文のどこにも残っていない（実測：v7 本文に該当する「書いた」ゼロ）。にもかかわらず本文は定冠詞的な「帳面の**「同じ」**」を消させている。**消す対象が、一度も置かれていない。**

### 4（中）「その夜」一晩で、二つの村の生き物を検証している

- 「旅の学者が、ふたつの村を**続けて通った**」＝二村を順に訪問
- 「隣の村にも、**同じ生き物がいた**」＝同種だが**別個体**
- 「まだ誰も触っていない場所を**ひとつ**選び」＝一箇所
- 「**その夜**、学者は自分で触りに行った」＝一晩・一個体

二村を順に回り終えた時点で学者は隣の村にいるはずで、そこで触れるのは隣の村の個体である。それでは「はじめの村の子」の予言は検証できない。**一晩・一個体で二村の子を判定することは、本文の設定からは不可能。**

### 5（中）検算節の grep 申告が実測と合わない

申告（無変更で引き継ぎ）：

> 「同じ」——**本文6件**（同じものを触っていて／同じ生き物／同じ場所から／同じところに触れた／帳面に、同じ／同じだけ言葉を覚えた）

**実測＝8件。**

| 申告 | v7 の実態 |
| --- | --- |
| 同じものを触っていて | ○ |
| 同じ生き物 | ○ |
| **同じ場所から** | **消滅**（「同じ石段から」に置換） |
| 同じところに触れた | ○ |
| **帳面に、同じ** | **消滅**（「帳面の「同じ」を消した」に置換） |
| 同じだけ言葉を覚えた | ○ |
| — | **＋同じ広さだった**（新） |
| — | **＋同じように向きを変えた**（新） |
| — | **＋同じ石段から**（新） |

六件申告に対し実測八件、内訳も六項目中二項目が消滅。

### 6（軽微）「紙が薄くなって、前の字は消えなかった」

「て」が逆接の仕事をしている（正しくは「紙が薄くなる**まで擦っても**」）。字義どおり読むと「薄くなった、そして消えなかった」で二事実の並置になり、意図した「消せなかった」が出ない。
