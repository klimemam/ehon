# 検算——頼む理由 第三稿

diff で入ったのは本文三箇所（新設二段落と「塗師は、三年待った。」）だけである。**だがこの三箇所が、前編・後編を貫く年表と、本作の中心機構の両方を壊している。**

## 一　疑い

### 1（重）三年の挿入が、round4 が確定させた年表を二年ずらす

[round4 §五](../../common/critiques-audit-round4.md)が確定させた導出：

> 手形到来＝〇年めの秋 → 値半分・五日の札 → 山の小屋でひと冬 → 春の市＝二年めの春（＋一年半、翌々年） → 同年夏の日照り → 畑の列＝二年め。現在＝十年め。**十 − 二 ＝ 八**

v3 は、この列の**先頭に三年ぶんの塊を差し込んだ。**

> はじめの冬、ひとりが塗る場所を借り、漆と炭を買い、一月かけて四つ作った。
> それでも次の冬には、近所と道具を一組だけ買い、八つを一緒に塗った。**三年めには、塗師へ払うより安くなった。**
> **塗師は、三年待った。**

書き直した年表（原点＝秋は保存されている。「はじめの冬」は秋の市の直後の冬として読め、秋起点とはむしろ整合する）：

| 年 | v2（round4 確定） | v3 |
| --- | --- | --- |
| 〇年めの秋 | 手形売り（原点） | 同（無変更） |
| 〇年めの冬 | ——（値半分・五日の札が初年） | **はじめの冬。ひとりが四つ。塗師に頼むより高い** |
| 一年めの冬 | 山の小屋でひと冬 | **次の冬。近所と道具一組、八つ** |
| 二年めの冬 | —— | **三つめの冬＝「三年め」。内製が塗師より安くなる／「三年待った」が明ける** |
| 二年めの春 | **春の市（＋一年半）** | ——（まだ値半分もしていない） |
| 三年め | —— | 値を半分にする → 誰も来ない → 五日の札 |
| 三年めの冬 | —— | 山の小屋でひと冬 |
| 四年めの春 | —— | **春の市** |
| 四年めの夏 | 二年めの夏＝日照り・井戸の主 | **日照り・井戸の主** |
| **畑の列** | **二年め** | **四年め** |
| 現在（後編） | 十年め | 十年め |
| **差** | **十 − 二 ＝ 八** | **十 − 四 ＝ 六** |

「三年め」を最も早く（二年めの冬）に取り、値半分・五日の札・冬ごもりを最大限に詰めても、畑の列は**三年め＝七年**が下限で、素直に読めば**六年**である。**どの読みでも八にはならない。** 後編 v4 の「屋根屋は、八年、瘦せた」および新設の「八年、屋根へ上っていなかった」は、前編 v3 と組むと**二年ぶん過大**になる。

**さらに、v3 が保持している自分の検算節が、この事実と正面から食い違う。**

> 疑い1（重・時間列の接続）は後編の側で直した。……**本作の時間列（値半分 → 五日の札 → ひと冬 → 春の市 → 同年夏の日照り → 畑の列）は無変更のまま接続する。**
> ……**本作の一年半は**手形が椀ひとつの値を下回る時点であり

時間列は無変更ではない。先頭に三年が入った。「一年半」は最短でも「三年半」になっている。

**新規／前検算の確定事項の破壊。**

### 2（重）値半分と五日の札が、内製に勝ってしまう

新設の二段落は、内製費用に**塗師の値を基準にした水準**を与えた。

- 内製費は、はじめの冬 ＞ P（＝塗師に頼む値）。「塗師に頼むより銭はかかった」
- 三年めに、内製費 c が初めて P を下回る。「三年めには、塗師へ払うより安くなった」＝**c は P のすぐ下**である

その直後に本文はこう続く（無変更）。

> 塗師は、三年待った。／それから、値を半分にした。／**誰も来なかった。**

**c ＜ P/2 でなければ「誰も来なかった」は成立しない。** ところが本文が与えた情報は c ＜ P（それも三年めにようやく到達）だけである。c ≒ P なら **P/2 ＜ c** となり、値半分の瞬間に町じゅうが塗師へ戻る。旧版では内製費が実質ゼロ（手形と道具代のみ）だったので半値でも負けたが、v3 は内製費を P の近傍に固定したうえで、その帰結を書き替えていない。

**同じ破れが時間の側にもある。**

- 内製：一月（三十日）で四つ ＝ **7.5日／椀**
- 塗師：十日／椀 → 夜なべで覚えて **五日／椀**

つまり五日の札を下げた時点で、**塗師のほうが 2.5 日速い。** ところが対応表は無変更のまま、こう主張している。

> | 袖から紙がのぞく男 | 返事②。待ち時間そのものが消えた。**頼んで五日待つより、今日始めるほうが早い** |

本文が与えた数（三十日で四つ）が、この対応表の主張を否定する。**値でも時間でも塗師が勝っている状態で「戸を叩く者は、いなかった」が置かれている。** 本作の中心機構（C_外注 ＞ C_自前）が、少なくとも一年めから三年めまでの三年間、成り立っていない。

### 3（重）共同の道具一組と、結末の「どの家でも」が同時に立たない

新設段落は、道具を**一組だけ**買って共同で使う制度を置いた。結末（無変更）はこうである。

> 塗りものは、**どの家でも**、冬の夜なべ仕事になった。
> 冬の宵、通りを行けば、**どの障子にも**、椀を塗る手の影が映っている。
> 影は、どれも、同じ形に見える。
> どれが塗師の影なのか、道から言い当てられる者は、いない。

結末の画は、**冬の同じ宵に、通り沿いの全戸が同時に塗っている**ことを要求する。全戸が同時に塗るには全戸に道具が要る。ところが新設段落は「道具を一組だけ」共同で買い、「八つを一緒に塗った」——つまり**道具は希少で、作業は一箇所に集約される**、と書いた。共同購入から全戸個別所有への転換は本文のどこにも無い。しかも対応表は「**C_自前 ＝ 道具代**」と書いており、道具代は消えない費目である。

**結末の型（主語識別不能）は、障子の数だけ影があることに乗っている。** 影が一箇所にしか無ければ、識別不能そのものが立たない。

### 4（中）「残る払いの集合」が増えている

[v1-01-audit](v1-01-audit.md) は、これを**完全一致**として確定させた。

> | 残る払いの集合 | 通る。山・井戸・峠の関・畑。後編冒頭「井戸の前と、峠の関と、山と畑の主の門前だけ」と**完全に一致** |

v3 は本文に **場所代・漆代・炭代・道具代** を足した。漆・炭・道具の材は山へ還元できるが、**町なかの「塗る場所」の借り賃は、山でも畑でも井戸でも関でもない。** 後編 v4 の冒頭（無変更）はこう書く。

> 銭が渡るのは、井戸の前と、峠の関と、山と畑の主の門前**だけである**。

全称の「だけ」が、前編の新しい一文で破れる。

### 5（中）「〜ようになった」の直後に「ひとりが」が来る

新設段落は、**町全体が既に自作へ移行し終えた文の後ろに**、一人めの事例を置いている。「町の者は、手すきの折に紙を当てて……するようになった」（完了・全体）→「はじめの冬、ひとりが」（開始・単独）で、普及の順序が逆に読める。挿話として読む余地はあるが、「それでも次の冬には」が普及の進行を語る接続なので、単独の例示ではなく系列の一段めとして働く。

### 6（軽微）「三年待った」の三年、塗師は何で食べたか

客が絶えてから三年、値も下げず、腕も上げず、収入の記述が無い。旧版は「客が絶える → すぐ値半分」だったので生じなかった空白である。

### 7（軽微）内製の費目に、本作が唯一「消えない」と宣言したものが無い

本作が「写せないもの」として立てた唯一の払いは木である（「最後に残ったのは、山の主への払いだった。木は、紙からは生えない。」）。「自分の椀を自分で**挽き**」と書く以上、内製には木地の材が要る。新設の費目は「塗る場所・漆・炭・道具」で、**本作が唯一「消えない」と宣言した費目だけが抜けている。**
