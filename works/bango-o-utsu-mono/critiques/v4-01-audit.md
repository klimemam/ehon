# 番号を打つ者 v4 検算

v3 と全行を突き合わせた。**冒頭の組み替え（法則を伏せる）が、法則そのものと衝突している。**

数は全部合う。三万八千二百・鋳型三つ・一万をこえる割れ・百日・年寄りの年齢——**算術の破綻はゼロである。** 壊れているのは、伏せるために新しく書いた二行のほうである。

---

## 疑い1（重い）：「これほど多く割れた日は、それまで、いちどもなかった」

**該当箇所**

> これほど多く割れた日は、それまで、いちどもなかった。

および冒頭：

> この町では、壺は、割れる日が来ると、ひとりでに割れる。
>
> どの壺の日がいつなのかは、割れてみるまで、誰にも分からない。昔からそうだった。

**合わないこと**

結末で町が立てる法則はこうである。

> 一万をこえる壺が、二度、割れた。鋳型は、三つ。
>
> 同じ鋳型から出た壺が、同じ日に、割れていたのである。

この二つを並べると、次の帰結が出る。

- 同じ鋳型から出た壺は、**同じ日に**割れる（例外は書かれていない）
- 鋳型は**三つ**しかない（町が数えた。対応表も「三万八千二百の個体に、三つの鋳型」と書いている）
- ゆえに、この町の壺が割れる日は、**歴史上ぜんぶで三日しかない**
- そのうち二日は本作の二つの事件である。三日めはまだ来ていない

したがって、**一度目の事件より前に、壺が割れた日は一日も存在しえない。**

ところが本文は二箇所で、それ以前にも割れがあったことを前提にしている。

1. 「これほど多く割れた日は、それまで、いちどもなかった」——「これほど多く」は比較である。比較の相手（もっと少なく割れた日）が要る。相手が一日も無いなら、この文は「壺が割れた日は、それまで一日もなかった」と書くべきものである
2. 「壺は、割れる日が来ると、ひとりでに割れる」「昔からそうだった」——町に古くからある知識として置かれている。しかし法則どおりなら、この知識が生まれる機会（＝過去の割れ）が存在しない

**逃げ道と、それが塞がっている理由**

「昔はもっと多くの鋳型があり、その壺が小さく割れていた」と読むことはできる。だが本作はその道を自分で塞いでいる。

- 「鋳型は、蔵にあった。番号は、打たれていなかった」——三つは古くからある道具として描かれる
- 町の推論は「二度の割れ ÷ 三つの鋳型」で成立している。過去に多数の鋳型があったなら、この推論は成り立たない
- 対応表は三つを**全個体に対する実効独立サンプル数**として読ませている。隠れた鋳型があるなら、この読みが崩れる

**新規／引き継ぎ**：**新規。**
v3 の冒頭は「この町では、同じ鋳型から出た物は、同じ日に割れる。いつからそうなのかは、誰も知らない。昔からそうだった」だった。**v3 は法則を最初に置いていたので、「壺は個々に、いつとも知れず割れる」という別の前提が入る余地が無かった。** v4 は法則を伏せるために現象だけを書き、その現象の書き方が法則より広くなった。「これほど多く割れた日は、それまで、いちどもなかった」の一行も v4 で新設されたものである。

**なお、v4 の改稿方針そのものは正しい。** 読者を町と同じ側に置くために法則を伏せる、という判断に異議は無い。問題は、伏せるために書いた現象記述が、伏せた法則と両立していないことだけである。

## 疑い2（中）：「それがどの鋳型から出たかは、どこにも書かれていない」

**該当箇所**

> 町のいちばんの宝は、いまも、一と打たれた壺である。
>
> それがどの鋳型から出たかは、どこにも書かれていない。

**合わないこと**

その二行前で、町自身がこう結論している。

> 同じ鋳型から出た壺が、同じ日に、割れていたのである。

この結論を持った町は、次の三段で一の壺の鋳型を確定できる。

1. 一の壺は、番号を打ちはじめた最初の年からある古い壺である
2. 一つめの鋳型の壺は一度目の日に、二つめの鋳型の壺は二度目の日に、全部割れた
3. 一の壺は両方を越えて残っている。**ゆえに三つめの鋳型から出た**

帳面には書かれていない。だが**帳面を見なくても分かる。** 結末の力は「知りようがない」ことにかかっているのに、直前に置いた結論が、知る道を一本開けてしまっている。

著者の検算節はこう書いている。

> 残ったのは三つめの鋳型の組だからである。町はそれを知らない

**この「町はそれを知らない」が成り立たない。** 町は、それを知るのに必要な命題を、たった今、自分で言葉にしたところである。

**新規／引き継ぎ**：**引き継ぎ。ただし v4 で顕在化した。**
結末の二行は v3 と同じ（「一番の番号が打たれた壺」→「一と打たれた壺」の音の変更のみ）。v3 では法則が冒頭にあり、結末との距離が全篇だった。v4 は「同じ鋳型から出た壺が、同じ日に、割れていたのである」を**結末の二行前に新設した**ため、推論の距離が二行に縮んだ。読者が消去法に気づく確率が、v3 とは桁で違う。

## 疑い3（軽微）：「冗談を言った年寄り」が誰か決まらない

**該当箇所**

> 冗談を言った年寄りは、壺を見て笑ったのである。鋳型を見て笑ったのではない。

**合わないこと**

本文は、番号を打った人物を二人に分けている。

> それを面白がって、**ひとり**が端から番号を打った。
> 一、二、三。
> **見た者は笑った。**
>
> **笑った者**が、次の年も、番号を打った。

- 最初に打った者（＝冗談を言った者）は「面白がって」打った。**笑ってはいない**
- 笑ったのは見た者であり、**次の年から打ったのはその笑った者のほうである**

「冗談を言った年寄り」は前者を指すはずだが、「壺を見て笑った」という述語は後者に付いている。二人のうちどちらとも読める。

v4 はここに「はじめの一を打った者は、もう年寄りになっていた」を新設したので、「年寄り」という語が二人に同時に掛かる状態になった（打ちつづけた者も、四十年後には年寄りである）。

対応表は「**何を数えるかは、最初の冗談が決めていた**」と書く。**最初の**冗談である以上、指すべきは前者に固定されていなければならない。

**新規／引き継ぎ**：語の混線自体は v3 にもあった（v3「冗談を言った者は、壺を見て笑ったのである」）。**「年寄り」を足して前者と同定しようとしたのが v4 であり、述語（笑った）を直さなかったために、同定が半分だけ進んで止まっている。**

## 通した項目（誤りなし）

| 項目 | 計算 | 結果 |
| --- | --- | --- |
| 鋳型あたりの個数 | 38,200 ÷ 3 ≈ 12,733 | 「一万をこえる」×2 と整合 |
| 二度目の規模 | 三年ぶんの追加生産（年千個なら +1,000 前後が二つめの鋳型ぶん）を足しても一万超 | 整合 |
| 三つめの鋳型の残り | 約 12,700 | 「いまも宝」と整合 |
| 書き出しの速さ | 10,000 件 ÷ 100 日 ＝ 日に百件あまり | 複数人で可能 |
| 一を打った者の年齢 | 約四十年で 38,200＝年に約千個 | 「年寄りになっていた」と整合 |
| 日と名 | 改良後の三年間に作られた壺だけが持つ → 「日はばらばら」（三年幅） | 整合 |
| 古い壺に日も名も無い | 打ちはじめる前に作られた | 整合 |
| 蔵の宝 | 最初の百に三つの鋳型が混ざる → 二度の割れで一部が割れ、一は残る | 整合。個数を書かない処理も正しい |
| 時間の前後 | 冗談 → 毎年 → 三万八千二百 → 一度目 → 百日 → 細かくする → 三年後 → 鋳型を数える → いま | 逆転なし |

**「一つめの鋳型の日より後にその鋳型から作られた壺」を本文に出さなかった処理**も確認した。時制の罠は踏んでいない。ただし、一度目のあと三年間、町は一万個超を作り直しているはずで、**その補充がどの鋳型から出たのかは書かれていない。** 疑い1を直す際に、ここも同時に決めることになる。

## まとめ

**数は一つも壊れていない。** 壊れているのは、法則を伏せるために書き足した現象記述と、法則を明示するために書き足した結論の一行——**伏せる操作と明かす操作の、両端**である。

疑い1 は本文の書き換えを要する。疑い2 は結末を守るなら、結論の一行の置き方（誰がどこまで言うか）を動かす必要がある。疑い3 は述語一つで済む。
