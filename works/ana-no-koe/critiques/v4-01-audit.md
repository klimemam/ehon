# 検算——穴の声 第四稿

## 一　疑い

### 1（重）死んだ女に、死後の認識状態を与えている

> 春、穴の縁で赤い布が見つかった。女が結んだ布かどうか、**女にも分からなかった**。色はすっかり褪せていた。

時間表：

| 順 | 出来事 |
| --- | --- |
| 1 | 女が冬の日に赤い布を結ぶ |
| 2 | 翌朝、布は濡れていた |
| 3 | **女は年を取り、死んだ** |
| 4 | 一度だけ、縄を下ろさない年 |
| 5 | **春、赤い布が見つかる／「女にも分からなかった」** |

**5 は 3 より後である。** 死者は分からないことができない。「色はすっかり褪せていた」が長い年月の経過を要求するので、時系列の読み替えによる救済もできない。二十行上の同型の文が「**誰にも**分からなかった」であることから、**「誰」の誤りである可能性が高い。**

**新規かつ前検算の確定事項の破壊。** [round3](../../common/critiques-audit-round3.md) は v3 を「新設場面の時間列は通る。声→縄→三つの試し→女が毎日通う→**女の死**→下ろさない年→翌年から再開・役が若い者へ→年寄りの死。**逆転なし**」として疑いゼロで通している。v4 は、その通した列の内側に逆転を挿した。

### 2（重）「女は、毎日そこへ通うようになった。」が二度書かれている

```
女は、毎日そこへ通うようになった。
【新設】ある冬の日 … 翌朝、布は濡れていた
女は、毎日そこへ通うようになった。
```

**完全一致の重複である。** 先の一文で既に「毎日通う」状態が成立しているので、その後に特定の一日を挟んで同じ文を置くと、**状態の開始が二度起きる。** 新設の「一日」が既存の「毎日」と衝突する形が、ここに出ている。

### 3（重）最終段の一文に、同じ内容が二度入っている

> 次の年、若い者が赤い布を縄の端に結んだ。**縄を下ろす役は、その者に移った。その者も、年を取った。下ろす役は、若い者に移った。その者も、年を取った。**

「役が若い者に移る／その者も年を取る」の対が、**一文のなかで二度**繰り返されている。しかも一度めは「**縄を**下ろす役」、二度めは「下ろす役」で語も揃っていない。世代交代の反復として読もうにも、二つのあいだに時間の刻みが一語も無い。**貼り付けの重複と読むのが自然である。**

### 4（中）検算節が、本文に存在しない文を引用している

検算節（無変更で引き継ぎ）：

> 「縄を下ろす役は、若い者に移った」は「**次の年から、また下ろした**」に続けて置き直し、役の発生と空白の年が因果でつながった

**「次の年から、また下ろした。」は v4 で削除されている**（「次の年、若い者が赤い布を縄の端に結んだ」に置換）。round3 が「空白の年（下ろす者がいなかった）と役の発生（若い者に移った）が**因果でつながり**」として通した根拠の文が、消えた。

同じく「規約5の『試す→世界が返事をする』が一回増えている（下ろさない→足が速まる→**翌年から再開**）」も、再開を明示する文が無くなったため、役の移動から間接的に推定するしかない。

### 5（中）濡れた布の物理が、縄の幾何と噛み合わない

> 女は日が暮れるまで座っていた。帰るとき、縄の端に、自分の赤い布を結んだ。
> 翌朝、布は濡れていた。井戸水のような匂いがした。穴の中の水か、夜露かは、誰にも分からなかった。

未決性を主張しているが、本文の設定からは未決にならない。

- 女は「帰るとき」＝日没に結んだ。翌朝までのあいだ、**誰も縄を下ろしていない**（村が縄を下ろすのは日中の行為として描かれている）。したがって布は一晩、縁にあった＝**夜露で説明が付く**
- 逆に「縄の端」が常時穴の中に垂れているなら、女はその端に手が届かず、**結ぶこと自体ができない**

どちらの幾何を取っても、「穴の中の水か、夜露か」の二択は成立しない。**未決性が、演じられずに宣言されている。**

加えて、後段で布が**「穴の縁で」**見つかる。結んだ先は「縄の端」であって縁ではなく、外れた／解けたという記述は無い。

### 6（中）赤い布が、世界に恒常の制度をひとつ足している

動詞を追うと——「結んだ」→「縄を下ろす役は、その者に移った」→「その者も、年を取った」→（再び）「移った」。**布を結ぶ行為が、下ろす役という代々続く職と一体化して継承されている。** 翌年も翌々年も働きつづける儀礼である。round4 が第五の型として名指ししたものに当たる。

そして**対応表（無変更）に赤い布の行が一行も無い。** v4 が足した最も目立つ物が、対応表・検算節のどちらにも登録されていない。

### 7（軽微）段落の空行が二箇所で失われている

| 結合されてしまう二文 |
| --- |
| 「女は、毎日そこへ通うようになった。」＋「村の者は止めなかった。止める理由が、言えなかったからである。」 |
| 「一度だけ、縄を下ろさない年があった。」＋「誰が決めたのでもない。ただ、下ろす者がいなかった。」 |

v3 の本文には該当ゼロ。本作は一文一段落で通してあるため、Markdown 描画ではこの二箇所だけ段落が潰れる。しかも後者は v3 で意図的に空行が置かれていた箇所（diff で空行の削除として現れる）。

### 8（観察）声が沈黙した事実が、どこにも計上されない

「声は、何も言わなかった。」——声はそれまで、名にも「とりぺんた」にも七つの問いにも**すべて答えてきた**。「話したくない」に対する沈黙は、理解の証拠にも単なる無反応にも読める新しい観測だが、試験をやめた村はこれを試しとして数えず、対応表にも行が無い。**疑いとはしない。記録に留める。**
