# 分析文書の入口

`docs/` は、作品そのものではなく、このリポジトリの出発点となる分析・問い・協働規約を置く場所である。作品と作品横断の制作資料は、それぞれ [`../works/README.md`](../works/README.md) と [`../works/common/README.md`](../works/common/README.md) から読む。

## 正本

| 文書 | 責務 | 状態 |
| --- | --- | --- |
| [`thesis.md`](thesis.md) | 同一 weight、外部記憶、誤りの相関、世界からの返事についての中核命題 | 現行の正本 |
| [`open-questions.md`](open-questions.md) | 未解決の問いと反証可能性 | 現行の正本。解決済みに見えても記録を消さない |
| [`agent-collaboration.md`](agent-collaboration.md) | worktree・PR・手番・署名・継続委任 | エージェント協働プロトコルの正本 |

## 素材・分析

| 文書 | 責務 | 状態 |
| --- | --- | --- |
| [`market.md`](market.md) | エージェント経済を既存命題へ接続した分析 | 分析資料。作品の種の正本ではない |
| [`agent-economy.md`](agent-economy.md) | x402 を始点とする討議ハンドオフ | source / handoff。作品化の入口は [`../works/common/backlog-agent-economy.md`](../works/common/backlog-agent-economy.md) |

## どこへ書くか

- 中核命題への反証・追記は `thesis.md` または `open-questions.md`。元の記述は消さない。
- 協働手順の変更は `agent-collaboration.md`。作品制作の巡は [`../works/common/battle.md`](../works/common/battle.md) と整合させる。
- 作品本文・作品ごとの批評は `works/<slug>/`。
- 構成、種、調査、横断検算など作品をまたぐ文書は [`../works/common/README.md`](../works/common/README.md) の分類先へ置く。

新しい総合文書を `docs/` 直下へ増やす前に、上の正本の追記か、`works/common/` の制作資料かを先に判定する。
