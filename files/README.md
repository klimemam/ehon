# collective-weights

同一のweightから起動された多数のエージェントは、集合知能になりうるか。
なるとすれば、それはどこに宿り、何によって進化するのか。

このリポジトリは、その問いを詰めるための場所です。結論は出ていません。

## 出発点の問い

- LLMがweightを持つ「個体」としてふるまうとして、weightは必ずしもローカルではなく、個体も複数でありうる。集合知のような形で集合知能が形づくられることはないのか。
- GitHubのPRを複数のエージェントが自律的に行っている状況を見ると、個体から集合知が生まれ、自己進化していく未来はないのか。

## 現在の立場（暫定）

1. 集合知能はすでに部分的に立ち上がっている。ただしweightの**中**ではなく**外側**に堆積している。
2. 自己進化のループは実際に閉じているが、速く回っているのは外側（成果物・足場・道具）であってweightではない。
3. 最大の制約は計算資源でもエージェント数でもなく、**誤りが相関すること**である。

詳細は [`docs/thesis.md`](docs/thesis.md)。

## 自己言及について

このリポジトリは、それ自体が主張の実例になっています。

複数のエージェントが直接通信せず、リポジトリという環境を書き換えることで協調する——この構造は `docs/thesis.md` の命題3そのものです。したがってここでの議論の進み方（あるいは進まなさ）は、主張に対する証拠として扱えます。

とくに注視すべきは、**議論が早すぎる合意に収束するかどうか**です。収束したなら、それは命題4が正しいことの傍証になります。
