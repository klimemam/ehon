# 多角地図：四つの軸

[`map.md`](map.md) は「世界が返事をするか」という一本の背骨で75章を並べた。それは主張を持つ目次だが、**その軸が見せるものしか見せない。**

同じ作品群を別の軸で投影すると、別の空白が出る。ここでは四軸を走らせ、最後に交差させる。

| 軸 | 問い | 実務上の使いみち |
| --- | --- | --- |
| **A 分野** | どの学問が持ち主か | どの文献を読むか。**誰に批評させるか** |
| **B 接地** | 史実か、観測か、推測か | どれだけ古びるか |
| **C 温度** | 読者は何を感じるか | 刊行順と、系列全体の可読性 |
| **D 主体** | 誰の問題か | 寓話に人が要るかどうか |

### A-2 この軸だけが見せたもの

**空白のある分野と、空白のある部が一致している。**

太字の空白（6.1／6.8／6.9／5.2／1.10／2.11／6.10）は、社会学・人類学・法学・教育学・環境科学・統計学の応用側——つまり **[`docs/thesis.md`](../docs/thesis.md) が一度も参照していない分野**にすべて属する。

[`map.md`](map.md) は「第五部と第六部が薄い」と言った。この軸はその**原因**を言う。**薄いのは、その分野の文献を一冊も読んでいないからである。**

### A-3 そして、この軸は批評者の設計図になる

[`works/README.md`](README.md) 規約3は「自己批評は独立な批評として数えない」と定めた。だが**別のweightを用意するのは高くつく**（[`docs/open-questions.md`](../docs/open-questions.md) Q2）。

分野は、それより安い多様性の作り方である。同一weightでも、**異なる分野の事前分布を与えれば、異なる場所を見る。**

| 作品 | 主分野の批評者 | 対抗分野の批評者 |
| --- | --- | --- |
| 壁と鋳型 | 集合知・複雑系 | **社会学**（stigmergy を人間の組織で見たとき何が違うか） |
| 九十九回正しい門番 | 統計学 | **法学**（統計的正しさは免責になるか） |
| 答えを知っている友達 | 教育学 | **認知科学**（外部化された記憶は本当に能力を減らすか） |
| 誰の手も写っていない絵 | 労働社会学 | **法学**（著作と労働の帰属） |

**これは Q2 への部分的な答えでもある。** 多様性のコストは、weight を分けることではなく、**読む文献を分けること**で払える可能性がある。未検証。

## 軸B：接地

作品が何に支えられているか。**推測に支えられた作品は古びる。**

| 段階 | 定義 | 該当 |
| --- | --- | --- |
| **史実** | 実際に起きた出来事 | クレバー・ハンス（1907, Pfungst）、Wald の爆撃機、Sandy Island（1876–2012）、Kahneman の飛行訓練 |
| **物理** | 実験すれば誰でも確かめられる | 回らない水車、温度計、川の水温 |
| **観測** | 研究で繰り返し観測されている | 二重降下、グロッキング、ショートカット学習、model collapse、迎合、暗黙の談合 |
| **理論** | 数学的に導かれる | ambiguity decomposition、Condorcet、Goodhart 四型、検証と生成の非対称 |
| **係争** | 専門家の間で決着していない | 創発の実在性（Wei 2022 vs Schaeffer 2023）、中国語の部屋、意識の判定 |
| **推測** | 根拠が薄い、または無い | 蒸留で何が失われるか、順序の反転、[`backlog.md`](backlog.md) 8節の予想の大半 |

### この軸だけが見せたもの

**最も強いメタファーは、全部が史実か物理に接地している。**

クレバー・ハンス、Wald の爆撃機、Sandy Island、回らない水車。これらは「寓話として上手い」のではなく、**世界が実際にそう返事をした記録**である。だから強い。作りものの比喩が勝てない理由がここにある。

一方、「壁と鋳型」の終結部（蒸留と順序の反転）は**推測に立っている**。作品として最も大きな主張をしている場所が、最も接地が弱い。

**指針**：一作の中で、接地の弱い主張は一つまでにする。二つ以上重ねると寓話が空中に浮く。

**系列としての配分**：現在の候補は推測寄りに偏っている。史実に接地した小品（クレバー・ハンス、Wald）を早めに入れると、系列全体の信用が上がる。

## 軸C：温度

読者が何を感じるか。**この軸は分析的な枠組みでは絶対に出てこないが、絵本の系列では最も重要かもしれない。**

| 温度 | 作品・候補 |
| --- | --- |
| 驚き | 二重降下 S17、Wald の爆撃機 |
| 不思議 | **次の字を当てる遊び S1**、霧 S10、地図の空白 B1 |
| 可笑しみ | 温度計を暖める A2、まず靴を買う A4、計算する馬 |
| 喜び・希望 | **ある日わかった弟子 S18** ／ 回らなかった水車 ／ 糸を切る |
| 寂しさ | 壁と鋳型、最後の職人 6.8 |
| 悲しみ | 道を覚えない御者 C2、答えを知っている友達 5.2、好みを作る料理人 C1 |
| 不安・恐さ | 見られている木 A3、同じ値をつける三軒 E4、添え木の森 C4、鋳型が鋳型を鋳る A6 |
| 怒り | **九十九回正しい門番 2.11**、誰の手も写っていない絵 6.1 |

### この軸だけが見せたもの

**系列が単調である。** 不安・恐さ・悲しみ・寂しさが圧倒的多数を占め、喜びと希望はほぼ一点しかない。

**これは読者Cにとって致命的である。** 恐い話ばかりの本棚は、子供には読めない。大人でも読み通せない。

そして怒りが二作しかないことも問題で、しかもその二作（門番・誰の手も写っていない絵）が**空白のまま放置されている**。系列が「不安だが誰も悪くない」に寄っていて、**誰かが損をしているという事実**が抜けている。これは軸Dの発見と重なる。

### 希望はどこにあるか

数えてみると、この系列で希望に属するものは三つだけで、**すべて同じ場所を指している。**

- **回らなかった水車** — 世界が返事をした
- **糸を切ると食い違いが戻る** — 多様性が回復した
- **ある日わかった弟子** — 積み上げが、ある日わかるに変わった

つまり **希望はすべて「返事」と「食い違い」の側にある。** これは [`map.md`](map.md) の背骨とちょうど一致する。偶然ではないと思われるが、未検証。

**配分の指針**：系列の三作に一作は、不思議・可笑しみ・喜びのいずれかを主音にする。

## 軸D：誰の問題か

寓話には、それが起きる相手が要る。

| 主体 | 定義 | 該当 |
| --- | --- | --- |
| **機械の性質** | 誰のせいでもなく、そういう仕組み | S1 S2 S3 S4 S10 S17 S18、二重降下、グロッキング |
| **作る人** | 設計・訓練する側の判断 | Goodhart 四型、A5 修正可能性、A9 合鍵、6.1 データ労働 |
| **使う人** | 使うことで自分が変わる | C2 御者、5.2 答えを知っている友達、C1 料理人、5.3 孤独 |
| **巻き込まれる人** | 使ってもいないのに影響を受ける | **2.11 九十九回正しい門番**、6.1、C3 責任の空白 |
| **誰の問題でもない（構造）** | 主体を特定できない | **壁と鋳型**、E4 談合、E6 完成した庭、F1 蒸留 |

### この軸だけが見せたもの

**「巻き込まれる人」が一章しかない。** しかもそれ（九十九回正しい門番）は空白のままである。

そして**「壁と鋳型」には顔のある被害者がいない。** 職人たちは全員同じ顔で、誰も損をしていない。構造だけが動いている。

これは作品の欠陥ではなく**性質**だが、系列としては危うい。構造の話ばかりだと、読者は「大変そうだが自分には関係ない」で閉じる。寓話が効くのは、**誰かに何かが起きたとき**である。

**[`map.md`](map.md) の「第五部が50%空白」を、この軸は別の言葉で言い直している——現在の作品群には、人が足りない。**

## 交差

### 収束したところ

四軸すべてが、同じ三作を指した。

| 作品 | 軸A 分野 | 軸B 接地 | 軸C 温度 | 軸D 主体 |
| --- | --- | --- | --- | --- |
| **2.11 九十九回正しい門番** | 統計学×法学（空白分野） | 理論（堅い） | **怒り**（希少） | **巻き込まれる人**（唯一） |
| **5.2 答えを知っている友達** | 教育学（空白分野） | 観測（デスキリング研究） | 悲しみ | 使う人 |
| **6.1 誰の手も写っていない絵** | 労働社会学（空白分野） | 史実 | **怒り**（希少） | 巻き込まれる人 |

**四つの独立な軸が同じ三作を指したことは、[`map.md`](map.md) 単独の判断より強い。** 制作順の上位に置く根拠になる。

### 乖離したところ

**「壁と鋳型」は、軸によって評価が正反対になる。**

- 軸A：集合知・複雑系の中心。◎
- 軸B：最大の主張（順序の反転）が推測に立っている。△
- 軸C：寂しさ一色。系列の単調さに寄与している。△
- 軸D：顔のある人が誰もいない。×

[`map.md`](map.md) は「10章を占める中心作」と評価した。**この四軸は「構造的には中心だが、人間的には薄い」と言っている。** 同じ作品への、まったく別の判定である。

これは v3 への指示を変える。[`critiques/v2-02-human.md`](kabe-to-igata/critiques/v2-02-human.md) は「v1 に戻せ」と言い、[`map.md`](map.md) は「分割せよ」と言った。四軸はもう一つ加える——**誰かひとりに、何かが起きるようにせよ。**

v1 にはそれがあった。谷を出て水車を組んだ「ひとり」である。v2 はそれを十人に増やして薄めた。三つの指摘が同じ場所を指している。

## 各軸の要約

| 軸 | 単独で見せたもの |
| --- | --- |
| **A 分野** | 空白は、読んでいない分野と一致する。そして分野は**安価な批評者多様性**の作り方になる（Q2 への部分解） |
| **B 接地** | 強いメタファーは全部が史実か物理。推測に立つ主張は一作に一つまで |
| **C 温度** | 系列が不安一色で、子供には読めない。**希望はすべて「返事」と「食い違い」の側にある** |
| **D 主体** | 巻き込まれる人が一章しかない。壁と鋳型には顔のある被害者がいない |

## 行動に落とす

1. **制作順の上位三作を、四軸の収束で確定する**——門番、答えを知っている友達、誰の手も写っていない絵
2. **v3 の指示に一項追加**——分割し、v1 に戻し、**そして誰かひとりに何かを起こす**
3. **系列の配分規則**——三作に一作は不思議・可笑しみ・喜びを主音にする
4. **批評の依頼先を分野で分散させる**（軸A-3 の表）。weight を分けるより安い
5. **読んでいない分野の文献を読む**——社会学（労働・専門知）、法学（責任帰属）、教育学（道具と学び）。空白はそこから来ている

## 未検証

- 「分野を分ければ批評者の多様性が上がる」は推測。同一weightは分野を変えても似た誤りをする可能性がある（命題4がそう予測する）
- 温度の分類は著者の主観。読者に確かめていない
- 四軸が同じ三作に収束したのは、四軸が独立でないからかもしれない。**軸の独立性そのものが未検証であり、これは Q1 と同じ構造の問題である**
