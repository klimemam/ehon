# 九十九回正しい門番

町に門がひとつあり、門番がひとりいた。

門番の仕事は、入れてよい者と、いけない者を見分けることだった。

門番はよく当てた。百人のうち、九十九人までは正しく見分けた。

前の門番は、八十人しか当てられなかった。だから町の人々は今の門番を誇った。「九十九人だ」と言うとき、みな少し胸を張った。

門番は年ごとに上手くなった。九十九人が、九十九人と半分になった。

ある朝、ひとりの女が門の前に立った。

門番は女を見て、入れてはいけない者だと判じた。

女には町に用があった。門番は通さなかった。

「なぜですか」と女は聞いた。

門番は答えなかった。答えられなかったのである。なぜそう見えたのかは、門番にもわからなかった。ただ、そう見えた。

女は翌朝も来た。門番は同じように判じた。同じように見えたからである。

女は毎朝来た。門番は毎朝、同じように判じた。

町の人が女に言った。「門番は、百人のうち九十九人まで正しいのだ。あなたのことは気の毒だが」

女は言った。

「わたしには、百人のうち百人が間違っている」

やがて役人が来て、門番の帳面を調べた。

帳面には、通した者の数と、通さなかった者の数が書いてあった。役人は数え、うなずいた。「九十九人と半分。よくやっている」

役人は帰った。

女の名は、帳面になかった。通さなかった者の数には入っていた。だが数には、名がない。

門番は今も門に立っている。前より上手くなっている。

女はもう来ない。

——門番は、何人を間違えたのか。
それとも、何人が、間違えられたのか。
このふたつは、同じ数を数えているのだろうか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 百人のうち九十九人 | 統計的な正しさ。集計された精度 |
| 「わたしには百人のうち百人が間違っている」 | 個別の被害。**率は個人には適用されない** |
| 門番が理由を答えられない | 説明可能性の欠如。[`map.md`](../map/map.md) 2.7 |
| 毎朝同じように判じる | 決定論的な誤り。同じ入力に同じ誤り。再挑戦が救済にならない |
| 年ごとに上手くなる | 改善は同じ盲目の単位で測られる。上手くなっても女は通れない |
| 帳面に名がない | **指標は個人を構造的に見られない。** 誤りの数は数えられるが、誰かは数えられない |
| 役人がうなずいて帰る | 監査が集計の上でしか行われない。[`docs/open-questions.md`](../../docs/open-questions.md) Q3 |
