# 答えを知っている友達

寺子屋に、なんでも知っている子がいた。

その子は、聞けば必ず答えた。まちがえることもあったが、めったになかった。そして聞かれるのを嫌がらなかった。何度聞いても、はじめと同じようにやさしく答えた。

はじめ、みんなは遠慮していた。

だんだん、遠慮しなくなった。

試験の日、席は隣どうしだった。先生は何も言わなかった。答えを写すのはむかしから禁じられていたが、聞くことは禁じられていなかったからである。

みんなの点は上がった。

そのころから、わからない字があっても、しばらく見つめるということをしなくなった。見つめてもわからないものは、聞けばわかる。

見つめている時間は、なくなった。

何年かが過ぎた。

ある朝、その子の席が空いていた。

みんなは筆を持った。そして、持ったまま座っていた。

紙は白いままだった。

ひとりが言った。「習ったはずだ」

たしかに習っていた。全部習っていた。

**習ったことは、ぜんぶ、聞いたことでもあった。**

夕方になって、ひとりの子が、字をひとつ書いた。

まちがえた字だった。

その子は、それを消さなかった。

まちがえたその字が、その日いちばん長く見つめた字だったからである。

——あの子がいた年、みんなは何を覚えたのか。
覚えたことと、聞けたことは、同じものだったのか。
そして、白い紙の前に座っていたあの一日は、失われた一日だったのか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| なんでも知っている子 | 常に隣にある道具 |
| 聞くことは禁じられていない | 規則が追いついていない領域 |
| 点は上がった | 短期の成果は実際に向上する。**ここを否定すると寓話が嘘になる** |
| 見つめている時間がなくなった | 失われるのは知識ではなく、わからないまま留まる時間 |
| 席が空いた日 | 道具が無い状況。技能の喪失が露呈する |
| まちがえた字を消さなかった | **いちばん長く見つめた字。学びは正解ではなく滞留に宿る** |
