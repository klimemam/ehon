# 答えを知っている友達（第二稿）

寺子屋に、なんでも知っている子がいた。

その子はひとりだった。**だが、みんなの隣に座っていた。**

誰の隣にも、同じ子がいた。どうなっているのかは、誰も考えなかった。いつもそうだったからである。

聞けば、必ず答えた。何度聞いても、はじめと同じようにやさしく答えた。疲れなかった。そして、昨日何を聞かれたかは、覚えていなかった。

はじめ、みんなは遠慮していた。

だんだん、遠慮しなくなった。

先生は何も言わなかった。答えを写すのは、むかしから禁じられていた。だが、聞くことは禁じられていなかったからである。

みんなの点は上がった。

***

ひとりの子が、ためしに聞かずにやってみた。

半分しかできなかった。

その子は、聞かないのは損だと知った。

**そのとおりだった。**

***

先生が、聞くことを禁じた。

その日、みんなの点は下がった。

先生は困った。点が下がれば、教え方が悪いと言われるからである。

次の日、先生は禁を解いた。

***

しばらくして、先生は試験のほうを変えようとした。

聞いても答えの出ない問いを、出そうとしたのである。

だが、そういう問いは採点がむずかしかった。○か×かで決められない。付ける点が、先生によって変わってしまう。

先生は、採点しやすい問いに戻した。

**聞けば答えの出る問いに、戻った。**

***

そのころから、みんなは、わからない字をしばらく見つめるということをしなくなった。

見つめてもわからないものは、聞けばわかる。

見つめている時間は、なくなった。

何年かが過ぎた。

ある朝、その子の席が空いていた。

どの席の隣にも、いなかった。

みんなは筆を持った。そして、持ったまま座っていた。

紙は白いままだった。

ひとりが言った。「習ったはずだ」

たしかに習っていた。全部習っていた。

**習ったことは、ぜんぶ、聞いたことでもあった。**

夕方になって、ひとりの子が、字をひとつ書いた。

まちがえた字だった。

その子は、それを消さなかった。

まちがえたその字が、**その日いちばん長く見つめた字だった**からである。

——賢くなったのは、子供たちだったのか、寺子屋だったのか。
点は上がった。あれは、誰の点だったのか。
そして、白い紙の前に座っていたあの一日は、失われた一日だったのか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| ひとりなのに、みんなの隣にいる | **現実に無い設定。** 同一の道具が全員に同時に付いている状態 |
| 昨日聞かれたことを覚えていない | 文脈の揮発性 |
| 聞くことは禁じられていない | 規則が追いついていない領域 |
| **試1：聞かずにやったら半分しかできない** | 正直に学ぼうとした者を、測定が罰する |
| **試2：禁じたら点が下がり、禁を解いた** | 測られる側が測る側でもあるとき、規制は続かない |
| **試3：試験を変えようとして、戻した** | **採点しやすさが問いの形を決める。** 制度は道具に合わせて、測るものを下げる |
| 見つめている時間がなくなった | 失われるのは知識ではなく、わからないまま留まる時間 |
| 席が空いた日 | 道具が無い状況 |
| まちがえた字を消さなかった | いちばん長く見つめた字。**学びは正解ではなく滞留に宿る** |
| 「賢くなったのは、子供たちか、寺子屋か」 | 集計された成果は上がった。個人は上がっていない |

## v1からの変更点

[批評01](critiques/v1-01-human.md) への応答。指摘は「まだ浅い。展開と最後の投げかけが弱い」。

**1. 現実に無い設定を置いた**（[`works/README.md`](../README.md) 規約6）。「ひとりなのに、みんなの隣に座っている」。v1 は寺子屋も友達も現実に存在するものだけで組まれていたので、梃子が無かった。

**2. 試す→世界が返事をする、を三回入れた**（規約5）。v1 は出来事がひとつしか無い静止画だった。

- 試1（子供が試す）→ 半分しかできない。**正直な実験が、誤った教訓を返す**
- 試2（先生が試す）→ 点が下がり、禁を解く。**規制する側が測られる側でもある**
- 試3（先生が試す）→ 採点できないので戻す。**制度が道具に合わせて、測るものを下げる**

三回とも、事態は悪化する方向に進む。

**3. 結末の問いを、主語が入れ替わる形にした**（規約7）。v1 は「覚えたことと聞けたことは同じものだったのか」で、主語が動いていなかった。v2 は「賢くなったのは、子供たちだったのか、寺子屋だったのか」——「壁と鋳型」の「職人だったのか、壁だったのか」と同型にした。

**同型にしたことが安易な模倣でないかは、作者には判定できない。** 独立な批評を要する。
