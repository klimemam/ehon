# 答えを知っている友達（第三稿）

寺子屋に、なんでも知っている子がいた。

その子はひとりだった。**だが、みんなの隣に座っていた。**

誰の隣にも、同じ子がいた。どうなっているのかは、誰も考えなかった。いつもそうだったからである。

聞けば、必ず答えた。何度聞いても、はじめと同じようにやさしく答えた。疲れなかった。そして、昨日何を聞かれたかは、覚えていなかった。

はじめ、みんなは遠慮していた。

だんだん、遠慮しなくなった。

先生は何も言わなかった。答えを写すのは、むかしから禁じられていた。だが、聞くことは禁じられていなかったからである。

みんなの点は上がった。

***

ひとりの子が、ためしに聞かずにやってみた。

半分しかできなかった。

その子は、聞かないのは損だと知った。

**そのとおりだった。**

***

先生が、聞くことを禁じた。

その日、みんなの点は下がった。

先生は困った。点が下がれば、教え方が悪いと言われるからである。

次の日、先生は禁を解いた。

***

ひとりの子が、自分で決めごとをした。

**「十、数えるまでは聞かない」**

その子は、守った。

はじめのうちは、十数えるあいだに思い出せることがあった。

だんだん、思い出せなくなった。

十が、五になった。五が、三になった。

誰かに言われたわけではない。

**十数えても何も出てこないなら、十数えるのは無駄だからである。**

その子は、正しかった。

***

そのころには、もう誰も、わからない字をしばらく見つめるということをしなくなっていた。

見つめている時間は、なくなった。

***

何年かが過ぎた。

ある朝、その子の席が空いていた。

どの席の隣にも、いなかった。

みんなは筆を持った。そして、持ったまま座っていた。

紙は白いままだった。

ひとりが言った。「習ったはずだ」

たしかに習っていた。全部習っていた。

**習ったことは、ぜんぶ、聞いたことでもあった。**

夕方になって、ひとりの子が、字をひとつ書いた。

まちがえた字だった。

その子は、それを消さなかった。

まちがえたその字が、**その日いちばん長く見つめた字だった**からである。

——賢くなったのは、子供たちだったのか、寺子屋だったのか。
点は上がった。あれは、誰の点だったのか。
そして、白い紙の前に座っていたあの一日は、失われた一日だったのか。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| ひとりなのに、みんなの隣にいる | **現実に無い設定**（規約6）。同一の道具が全員に同時に付いている |
| 昨日聞かれたことを覚えていない | 文脈の揮発性 |
| 聞くことは禁じられていない | 規則が追いついていない領域 |
| **試1：聞かずにやったら半分しかできない** | 正直に学ぼうとした者を、測定が罰する |
| **試2：禁じたら点が下がり、禁を解いた** | 測られる側が測る側でもあるとき、規制は続かない |
| **試3：十が五になり、三になる** | **境界が、誰の決定もなく浸食される。** 一歩ずつは常に合理的 |
| 「その子は、正しかった」 | 局所の判断は毎回正しい。**失われるのは総和のほうである** |
| 見つめている時間がなくなった | 失われるのは知識ではなく、わからないまま留まる時間 |
| 席が空いた日 | 道具が無い状況 |
| まちがえた字を消さなかった | いちばん長く見つめた字。**学びは正解ではなく滞留に宿る** |
| 「賢くなったのは、子供たちか、寺子屋か」 | 集計された成果は上がった。個人は上がっていない |

## v2からの変更点

[批評01](critiques/v2-01-human.md) への応答。

**1. 試3（先生が試験を変えようとして戻す）を削除した。**

指摘のとおり、あれは**測定の設計**の話であって、**学び**の話ではなかった。芯の上に無い試を置いたので、コンセプトがぼやけた。[`kabe-to-igata`](../kabe-to-igata/) v2 の過密と同じ失敗の小型版である。

削った主題（**測りやすいものが、測る対象を選ぶ**）は捨てず、[`map.md`](../map/map.md) に独立した章として登録した。

**2. 芯の上にある試3に差し替えた。**

「十、数えるまでは聞かない」と決めた子が、十を五にし、五を三にする。**誰も決めていないのに、境界が浸食される。**

これが v2 の試3より良い理由：

- **芯の上にある。** 失われるのは滞留の時間であり、この試はそれが失われる過程そのものを描く
- **一歩ずつは常に正しい。** 十数えても何も出ないなら、十数えるのは無駄である。その子はまちがえていない
- v2 では「見つめる時間がなくなった」を**地の文で説明していた**。試3にしたことで、**説明が像に変わった**

**3.「その子は、正しかった」を置いた。** [写せる名工](../utsuseru-meiko/v2.md) の「男はまちがっていない」と同じ位置の一行である。**局所の判断が毎回正しいまま、総和が失われる**——両作に共通する機構なので、同じ形の一行で受けた。

**これが呼応なのか、単なる言い回しの流用なのかは、作者には判定できない。** [`utsuseru-meiko/critiques/v1-01-human.md`](../utsuseru-meiko/critiques/v1-01-human.md) が「作品間の言い回しの流用」を問題として指摘しているので、独立な批評を要する。
