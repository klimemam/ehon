## 規約

### 1. 版は上書きしない

改稿は新しい版を隣に置くことで行う。v1 を直接書き換えてはならない。

これは [`AGENTS.md`](../AGENTS.md) の「削らない」を作品に適用したものだが、理由が違う。議論では誤った記述の記録に価値があるから残す。作品では、**どの批評がどの改稿を引き起こしたかの因果を追えなくなる**から残す。

絵本の推敲は削る作業が本体なので、版の中では自由に削ってよい。削ってはいけないのは版そのもの。

### 2. 作品と批評を分ける

作品ファイルには本文と、作者による対応表・変更点だけを書く。判定は書かない。

批評は `critiques/` に別ファイルとして置く。これにより、他のエージェントは作品に触れずに批評を追加できる。

### 3. 批評には批評者を書く

`critic:` は必須。自己批評（作者と批評者が同一）は `kind: 自己批評` と明記する。

**自己批評は独立な批評として数えない。** 同一weight由来の批評は誤りが相関する（[`docs/thesis.md`](../docs/thesis.md) 命題4）。作者と別のエージェント、できれば別のweightによる批評が要る。

### 4. 批評は軸を宣言する

作品は反証されない。したがって「正しいか」ではなく「何の軸で見たか」を書く。

現在使われている軸：

| 軸 | 問い |
| --- | --- |
| 機構の正確さ | 対応表の主張と、本文が実際に描いている像が一致しているか |
| 像の強度 | 絵にできるか。読者の頭に画が結ぶか |
| 音 | 読み聞かせたとき、声に乗るか |
| 対象年齢 | 想定読者に届くか |
| 独立性 | この批評は既存の批評と別の場所を見ているか |

軸は増やしてよい。増やしたらこの表に追記する。

### 5. 筋は「試す→世界が返事をする」を三回以上重ねる

**この系列で最も繰り返している失敗がここにある。** 主題も文体も良いのに、作品が静止画になる。

「壁と鋳型」だけが成立していた理由は、筋がこうなっているからである。

```
谷を出る → 水車が回らない → 散る → 壁が食い違いはじめる
→ 糸を張る → 壁が止まる → 糸を切る → 食い違いが戻る
→ 鋳型が古びる → 壁を溶かして鋳る → 細い線が灰になる
```

**一つずつが実験であり、結果が出るたびに世界の状態が変わる。** だから次が気になる。

対して、状況を説明して小さな場面をひとつ置くだけの構成は、**世界の状態が最初から最後まで変わらない**。読者に「次」が生まれない。

規則：

- 試す主体を置く。誰かが**何かを試さなければならない**
- 返事は世界から返す。他人の意見ではなく、起きた事実として
- **三回以上重ねる。** そして重ねるたびに事態が悪くなるか、複雑になること
- 一度試して一度で終わる構成は、静止画である

**これは装飾ではなく主題である。** [`docs/thesis.md`](../docs/thesis.md) 命題5は「世界が返事をする領域とそうでない領域は違う」と述べた。**検証のループを筋にすることは、この系列が主張していることを、構造として実演することにあたる。**

### 6. 現実に無い設定を、ひとつ置く

「壁と鋳型」の鋳型から人が生まれる設定、一日で消える記憶。**現実に存在しないからこそ、現実の機構が正確に出る。**

現実的な設定（師と弟子、教室、市場）だけで書くと、寓話に梃子が無くなり、**誰もが既に持っている話をなぞって終わる**（[`aru-hi-wakatta/critiques/v1-01-human.md`](aru-hi-wakatta/critiques/v1-01-human.md)）。

規則：

- 現実に無い設定を**ひとつだけ**置く。二つ置くと寓話が空想譚になる
- その設定は、**そのまま機構でなければならない**。飾りとして非現実を足しても効かない
  - 良い例：型が道具に宿る → 九つを八つでやれと言われたら共通点を探すしかない＝正則化が汎化を強制する
  - 悪い例：舞台を異世界にする（機構が何も変わらない）

### 7. 結末の型を、毎回変える

**旧規約は「結末は主語を入れ替える問いにする」だった。これは誤りである。**

全作に適用した結果、「——◯◯だったのか、△△だったのか。／…／…」という三行が**全作品の結末になった**（[`survey-fables.md`](survey-fables.md) 4.1）。主語の入れ替えは**結末の型のひとつ**であって、結末の型ではない。

使える型（調査で確認されたもの）：

| 型 | 実例 | 効き方 |
| --- | --- | --- |
| 主語を入れ替える問い | 壁と鋳型 | **使いすぎている。当面は封印する** |
| **気づかない** | 星新一「おーい でてこーい」——「それには気がつかなかった」 | **読者だけが知っている状態で幕を下ろす。最も強い** |
| **事実を二つ並べて切る** | 小川未明「野ばら」——「野ばらが枯れてしまいました。／老人は南の方へ暇をもらって帰りました。」 | 何も足さない |
| **主語識別不能** | オーウェル——「もはやどちらがどちらか言えなかった」 | 問いにせず、識別不能という事実で置く |
| **物に畳む** | カフカ「町の紋章」——「**だからこそ**町は紋章に拳を戴いているのだ」 | 「だから」一語で因果を偽装して閉じる |
| **半分だけ言い切る** | 宮沢賢治「猫の事務所」——「ぼくは半分獅子に同感です」 | 言い切りと沈黙のあいだ |
| **循環** | 冒頭の一文を最終行にそのまま置く | 終わらないことを終わりにする |
| **描写の放棄** | ル＝グウィン——「私にはそれを描写することがまったくできない」 | 語り手が限界を告白する |
| **沈黙** | 荘子——「七日而渾沌死」 | 事実を置いて何も足さない |

**規則**：直前の作と同じ型を使わない。

### 8. 太字を使わない

**「壁と鋳型」v1 には太字が一つも無い。** 後から書いた作品には多数ある。

> 構文で作れなかった強調を、活字で作っている。

これは [`kabe-to-igata/critiques/v2-02-human.md`](kabe-to-igata/critiques/v2-02-human.md) が指摘した「読者を信頼していない」の、**目に見える徴候**である。

強調したい一文があるときは、太字にするのではなく——

- 前の段落を長くして、その一文だけ短くする
- 独立した一行として、前後を空ける
- 語順を倒置する

本文に太字を使ってよいのは、**対応表・批評・覚書だけ**とする。

### 9. 語と絵を、言い換えにしない

絵本にする以上、語と絵の関係が設計対象になる（Nikolajeva & Scott）。

> symmetrical → enhancing → complementary → counterpointing → contradictory

左へ行くほど絵が文を言い換え、右へ行くほど隔たりが増える。

**symmetrical（絵が文を言い換えるだけ）は最低の設計である。** 少なくとも enhancing（絵が文に無い情報を足す）以上を狙う。

最も強いのは **counterpointing**——クラッセンは地の文に嘘をつかせ、絵に訂正させ、訂正したことを誰にも言わせない。

### 10. 批評が出尽くしたら報告する

新しい批評が既存の批評と同じ場所しか指さなくなったら、その事実を [`docs/open-questions.md`](../docs/open-questions.md) に記録する。それは飽和ではなく、批評者の多様性が尽きた徴候である可能性が高い。
