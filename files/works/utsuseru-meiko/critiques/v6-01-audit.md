# 検算——写せる名工 第六稿

**変更範囲の申告は正確だった。** diff の結果、本文の変更は五箇所（鋳型の一行の新設／「値は、」／「めったに」→「ほとんど」／「からである」一つ削り／鉋のルビ）で、結末・筋・場面の順序には触れていない。

## 一　疑い

### 1（中）新設した鋳型の一行が、共有世界の鋳型の規則と合わない

足したのはこの一行である。

> 鋳型《いがた》に入って、ひと晩たつと、隣にもうひとりの名工が立っている。

検算節は「**鋳型が身についたものごと人を写すのは、共有世界の既存の機構の範囲内**である」と申告する。`shares_world_with` 先の [`kabe-to-igata/v2`](../../kabe-to-igata/v2.md) を読むと、**鋳型は三点で違う働きをしている。**

| kabe-to-igata の鋳型 | 本作が要求する鋳型 |
| --- | --- |
| 「ある谷に、鋳型が**ひとつ**あった」 | ふたり→四人→何百人の倍々。二晩めには**二つ**、三晩めには**四つ**の鋳型が要る |
| 「毎朝、そこから千人の職人が起きた。毎夜、千人は溶けて鋳型に戻った」——**出入りは等数で、増えない** | 入った本人が出てきて、隣にもうひとり増える（**＋1**） |
| 鋳型が運ぶのは同じ型の体と癖。知識が載るのは、**壁の文字を溶かして鋳た**新しい鋳型だけであり、そのとき「一度しか彫られなかった細い線は、溶ける前に灰になった」——**書かれなかったものは、鋳型に載らない** | 名工の**書けない**手つきが、そっくり載る |

三つめが一番重い。**本作の芯は「暗黙知は書けない」である。** 「違えようとして違えたのでは、なかった」「帳面に書いておけるか／組んだ本人に言えないものを、書ける者はいない」（`hazure-no-fuda` が本作から受け取った観測でもある）。**共有世界の鋳型は、書かれなかったものを灰にする装置である。** 本作は、その装置に、書けないものだけを完全に運ばせている。

疑いは**足した一行の是非**であって、本作の機構ではない。直しは一行で足りる。

- 鋳型を名指さず、写す動作だけを一枚見せる（隣に立つ、という絵は残せる）
- または「もうひとり」を鋳型の外の何かから出す

なお本作は `shares_world_with: kabe-to-igata` を v5 以前から宣言しているが、**装置を本文に出したのは v6 が初めてである。** 宣言だけのあいだは照合の対象が無かった。**照合できる形にしたことで、規則の差が現れた。**

### 2（軽微）`hazure-no-fuda` からの参照が v5 を指している

同日付の新作 [`hazure-no-fuda/v1`](../../hazure-no-fuda/v1.md) は `consumes: utsuseru-meiko/v5`、文脈節のリンクも `../utsuseru-meiko/v5.md` である。**引いている六点の内容は v5 と v6 で同一なので、齟齬は無い。** 参照先の更新だけの問題である。
