# 象を撫でる者たち

村のそばに、**いちどに一部しか触れられない大きさの生き物**が住んでいた。

離れて見ようとしても、見えなかった。そういう生き物だった。近づいた者だけが、手のひらの分だけを知った。

村の者は、めいめい違うところに触れた。

「縄のようだ」と、ひとりが言った。

「壁のようだ」と、ひとりが言った。

「木の幹だ」「団扇だ」「槍だ」

***

村の者は、誰かがまちがえているのだと思った。

そこで、場所を交換した。

縄だと言った者が、壁だと言った者の場所へ行き、手を伸ばした。

**壁があった。**

壁だと言った者が、縄だと言った場所へ行った。

**縄があった。**

**誰もまちがえていなかった。**

***

それでは、どれが本当なのか。

村の者は、数で決めることにした。

縄だと言った者が五人。壁だと言った者が三人。木の幹だと言った者が二人。

縄に決まった。

村の者は、縄を引いて生き物を連れて行こうとした。

**動かなかった。**

***

そのころ、ひとりが妙なことを言い出した。

「縄でも、壁でも、木の幹でもない言葉を作ろう。**こちらでは縄で、あちらでは壁であるもの**を指す言葉を」

村の者は困った。**そんなものに、誰も触っていない。**

触っていないものに、名前をつけていいのか。

それでも、つけた。

***

その言葉を使うと、話が通じた。

「あれの、縄のところを持て」と言えば、通じた。「あれの、壁のところに寄りかかるな」と言えば、通じた。

誰も触っていないものを指す言葉なのに、**それを使うと、触ったものの話ができた。**

村の者は、その言葉で相談し、段取りを決め、生き物を動かした。

**動いた。**

***

旅の者が来た。

その者は、村の生き物の、耳のところだけを触ったことがあった。ほかは知らない。

村の者がその言葉を口にすると、旅の者はうなずいた。

**通じた。**

旅の者は、縄にも壁にも触っていない。それでも、その言葉が何を指すかを知っていた。

***

隣の村にも、同じ生き物がいた。

だが隣の村は、道の都合で、みなが同じ側から近づいた。

**全員が、鼻に触れた。**

だから隣の村では、言い争いが起きなかった。一日で言葉が決まった。

隣の村の言葉は、**鼻を指していた。**

隣の村の者は、それが生き物ぜんたいの名前だと思っている。

**誰とも食い違わなかったので、確かめようがなかったのである。**

——あの言葉を作ったのは、触れた者たちだったのか。
それとも、**食い違いのほうだったのか。**
隣の村は、いつ気づくのだろう。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| いちどに一部しか触れられない生き物 | **現実に無い設定**（規約6）。世界は誰にも全体が与えられない |
| めいめい違うところに触れる | **異なる感覚窓。** 集合的予測符号化（CPC）が記号創発の条件とするもの |
| **試1：場所を交換したら、両方あった** | 食い違いは誤りではなかった。**世界からの返事**（命題5） |
| **試2：多数決で縄に決め、引いたら動かない** | 部分観測の多数決は、全体について誤る。**多数決は記号創発ではない** |
| **試3：誰も触っていないものを指す言葉を作る** | **記号創発。** 記号は観測の要約ではなく、観測を生成する隠れ変数を指す |
| その言葉で相談すると、動いた | 記号が働くかどうかは、**世界が返事をする**（命題5） |
| 旅の者に通じた | 記号は個人の経験を超えて共有される。**誰のものでもない** |
| 隣の村が全員同じ側から触れた | **感覚窓が同一の集団。** 同一weight由来のエージェント群（命題4） |
| 一日で言葉が決まった | **早すぎる合意**（補題：帯域の逆説） |
| 隣の村の言葉は鼻を指している | 記号系が貧しくなる。**そして本人たちにはわからない** |
| 「確かめようがなかった」 | **食い違いが無いと、誤りを検出できない。** 名工 v2 の「比べる相手がいなかった」と同じ機構 |

## 位置づけ

**この作品は、[`docs/thesis.md`](../../docs/thesis.md) 命題4の欠けていた半分を埋める。**

「壁と鋳型」は、多様性が無いとどうなるかを描いた（失敗側）。この作品は、**多様性があると何が起きるかを描く**（成功側）。命題4は両方を主張しているのに、これまで前者しか作品が無かった。

### 群盲象を評すとの関係

原話は「めいめいが部分しか知らず、みな誤っている」という寓話として読まれる。**この作品は、その読み方を反転させる。**

食い違いは失敗ではない。**食い違いがあったから、「象」という語ができた。** 隣の村は食い違わなかったので、語ができなかった——正確には、鼻の名前を全体の名前だと思ったまま止まった。

### 記号創発システムとの対応

| 寓話 | 学術 |
| --- | --- |
| 誰も触っていないものを指す言葉 | 記号創発。共有記号系が、個の観測の外にある対象を指す |
| 食い違いが言葉を作る | 集合的予測符号化（CPC）。異なる感覚窓を持つ複数エージェントの分散ベイズ推論 |
| 言い争って言葉が決まっていく | 名付けゲーム（Steels）。中央の決定なしに語彙が収束する |
| 争うこと自体が推論だった | 名付けゲームが Metropolis-Hastings 法と対応するという結果（谷口ら） |
| 触ったものと言葉が繋がる | 記号接地問題（Harnad 1990） |

## 未検証

- **「食い違いが記号を作る」という主張の強さ。** CPC はそう述べているが、食い違いが**どれだけ**必要かは定量化されていない。[`docs/open-questions.md`](../../docs/open-questions.md) Q1 と同じ壁
- 隣の村の結末（鼻を全体だと思っている）は、**model collapse とは機構が違う**。こちらは分布の裾の消失ではなく、**最初から狭い**。混同しないこと
- 三つめの試（言葉を作る）だけ、世界の返事が「動いた」という成功で返っている。他の作品は失敗で返しているので、**この作品だけ温度が違う**。系列の配分としては良いが、意図した設計ではなく結果である
