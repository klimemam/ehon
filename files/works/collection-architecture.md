# 短編集の構成案

## 結論

短編集を主題別の棚として並べるより、**知能が世界へ入ってきた結果、次の制度を一つずつ必要にする時系列**として構成したほうがよい。

ただし、全作品を文字どおり同じ町の年代記にはしない。鋳型、壁、紙、帳面、門、井戸といった物を反復させる、**弱い共有世界**にする。

読者が追う時系列は年号ではない。

> 当てるものが生まれる
> → 外に記憶を持つ
> → 人の隣に置かれる
> → 制度がそれを前提に変わる
> → 写され、市場へ集中する
> → 使いが自分で買い始める
> → 帳面と案内人が市場を統治する
> → 電力・水・権限・責任が最後の希少性になる

この順序なら、各短編集は独立して読める一方、全巻を通すと一つの社会が立ち上がる。

---

## 1. 世界観は設定集ではなく、六つの法則にする

共有すべきなのは地名や登場人物ではない。作品をまたいで破られない法則である。

### 法則1：賢さは個体の中だけにない

職人が忘れても壁が残り、子が続きを当て、食い違いから言葉が生まれる。知能は、個体、道具、記録、制度のあいだに分配される。

### 法則2：答えには必ず外側がある

次の字を当てる子には真偽の判定がなく、門番には門外の結果が見えず、帳面には欄のない仕事が載らない。どの装置も、見ていない側を持つ。

### 法則3：役に立つものほど世界を作り替える

友達は点を上げ、名工は家を安く建て、評判は本当に能力を作る。短編集は「便利だが危険」と言うのではなく、**便利だったから次の制度がそれを前提にした**と描く。

### 法則4：複製は数を増やすが、違いを増やさない

同じ鋳型、写された名工、同じ側から象に触れる村。人数、店名、製品名は、多様性の証拠にならない。

### 法則5：見えるものが、次に残るものを決める

点、星、帳面、門番の記録。測定は後から世界を写すだけでなく、仕事、能力、存在の形を先に作る。

### 法則6：情報にも物質と権限が要る

答えは場所を取り、熱を出し、誰かの水や電力を使う。汎用AIが技能を吸収しても、データ、鍵、身体、土地、責任までは自動的に所有しない。

この六法則を先に決めれば、新作が同じ世界に属するかを判定できる。固有名詞を共有する必要はない。

---

## 2. 三つの時間を分ける

一冊の中で寓話、歴史、予測を混ぜると、作品が説明文になる。三つの時間を別の器へ入れる。

| 層 | 役割 | 文体 | 更新 |
| --- | --- | --- | --- |
| **寓話本文** | 時代を越えて残る機構 | 年号・製品名を出さない | 批評による新版のみ |
| **巻間の年代記** | 前作の変化が次の制度を必要にした因果 | 「壁の後に門が増えた」程度の短文 | 巻の構成時に固定 |
| **日付つき観測帳** | 現在と、外れうる将来予測 | 実名・日付・外れの条件を持つ | 半年ごとに追記 |

[`now-and-next.md`](now-and-next.md) は三層目としてすでにある。これを各巻末へ分冊して載せる。予測が外れても寓話本文は死なず、外れた記録だけが増える。

---

## 3. 全体を四つの短編集にする

### 第一集『まだ、道具だったころ』

#### この巻が作る前提

AIは人格や検索箱ではなく、予測し、学習時に形を変え、使用時には外界を直接確かめない道具である。

#### 収録順

1. **次の字を当てる遊び v2**
   - 最初に置く。読者が以後の全作品を読むための最小の種。
2. **ある日わかった弟子 v2**
   - 学習と汎化。測れる変化より前に内部が変わりうる。
3. **象を撫でる者たち v1**
   - 一体から集団へ。異なる観測窓が共有語を作る。
4. **壁と鋳型 v1**
   - 巻の終点。個体、記録、集合、蒸留を一つの世界へまとめる。

#### 巻内の時系列

```text
続きを当てる → 型を掴む → 観測を持ち寄る → 記憶が壁へ移る
```

#### 読後に成立している世界

知能は「賢い一人」ではなく、予測器、異なる経験、外部記憶の組み合わせになった。ここで初めて次巻の「社会がこの道具を使う」が可能になる。

#### 不足

『象』の記号創発が一行で済まされているため、第一集の橋が弱い。場所を交換する、多数決に失敗する、新しい語を作り直すという過程を、壁へ至る前の中心事件として強める必要がある。

---

### 第二集『町が答えを前提にした日』

#### この巻の時間

道具は珍しい物ではなくなり、教育、審査、労働が道具込みで組み直される。

#### 収録順

1. **答えを知っている友達 v3**
   - 個人が使い始める。点は本当に上がる。
2. **九十九回正しい門番 v3**
   - 個人利用から制度判断へ。見えない側が固定される。
3. **誰の手も写っていない絵 v2**
   - 判断だけでなく、作るための過去の労働が制度の外へ落ちる。
4. **道具によって初めて届いた仕事**（未作）
   - 道具なしでは参加できなかった者が、町の仕事へ参加する。便益を反転の前座にしない。

#### 巻内の時系列

```text
使う → 測る → 見えない者が出る → 別の者には入口が開く
```

#### この巻の主音

「AIが間違える」ではない。**AIを使う側の学校、門、囲い、星が変わる**。道具の性能より、制度が何を成功として数えるかが前景化する。

#### 不足

現行の三作は悲しみ・怒りへ寄る。最後の一作は、道具で初めてできた仕事や、以前は届かなかった人へ届く小品でなければならない。便益を一作分独立させないと、巻全体が結論ありきの告発に見える。

---

### 第三集『写せる者たちの市場』

#### この巻の時間

道具は製品になり、複製され、順位づけされる。人がAIを使う市場から、AIが能力を選ぶ市場へ移る直前までを描く。

#### 収録順

1. **写せる名工 v2**
   - 供給制約が消え、合理的な選択が多様性を失わせる。
2. **評判のよい職人 v1**
   - 第一位が仕事を得るだけでなく、仕事によって本当に強くなる。
3. **三軒の店は同じ井戸から水を汲んでいた**（8.7、未作）
   - 看板の数と基盤の数を分ける。
4. **百人に一人は知らない店へ行かせる**（8.8、未作）
   - 多様性を保つ探索には、現在の最適を捨てる費用がある。

#### 巻内の時系列

```text
複製する → 集中する → 系譜が見えなくなる → 探索を制度化する
```

#### 巻の結末

探索枠を決める者が、次に仕事と金の流れを支配する。ここで第四集の使い、帳面、案内人が必要になる。

#### 不足

現行作は『写せる名工』一作しか十分に立っていない。第三集は刊行を急がず、系譜と探索を別の物語として成立させてから組む。

---

### 第四集『使いたちが買い始めた町』

#### この巻の位置

ここから先は現在の説明ではなく、**条件付きの未来予想**である。作品ごとに「この前提が外れたら、この話も外れる」を巻末へ付ける。

#### 二つの未来へ分岐する

##### A：専門能力が市場へ外部化される

汎用AIより、専門サービスを発見・契約するほうが安い世界。

1. **財布を持った使い**（8.1）
2. **名乗らずに買える市**（8.2）
3. **帳面にない店**（8.3）
4. **辻の案内人**（8.4）
5. **買い手が先に叫ぶ市**（8.5）

時系列は、裁量の委譲、即時決済、発見、配分、逆オークションである。

##### B：汎用AIが技能を内部化する

特殊スキルがすぐ取り込まれ、能力を売る専門店が長く残らない世界。

1. **何でもできる使いと、開かない戸**（未作）
   - 使いは技能を持つが、送金、署名、内部データ、現場へ入る権限がない。
2. **鍵の帳面**（8.3の別案）
   - 能力ではなく、誰が何へアクセスし、誰が責任を負うかを記録する。
3. **責任を売る店**（未作）
   - 答えを作る者と、失敗時に補償する者が分かれる。
4. **最後まで別の水を飲む店**（8.7・8.8の統合候補）
   - 技能ではなく、独立した失敗を保険として買う。

#### 分岐を一冊にする理由

どちらが来るかを作者が先に決めないためである。第四集をAだけで組むと、エージェント経済の成立を前提にしてしまう。AとBを対にすると、読者は「市場がどうなるか」より先に、**何が一体の内側へ入り、何が外に残るか**を見る。

#### 巻末の判定項目

- 専門エージェントの優位は、基盤モデルへ吸収されるまで何か月残るか。
- エージェント間の支払いは、多数の能力供給者へ分散するか、少数の基盤と資源保有者へ集中するか。
- Registryの主要項目はskillか、permission・provenance・liability・resourceか。
- 外部サービスを呼ぶ理由は「自分にできない」からか、「自分にしてよい権限がない」からか。

---

## 4. 『答えのぬるい井戸』を置くなら

この作品は一つの制度段階ではなく、全巻を貫く**物質の底**である。第四集の最後に置くのが最も効く。

財布、帳面、案内人がどれほど洗練されても、答えは計算資源、電力、冷却、立地を使う。市場が能力をうまく配っても、井戸の水は温くなる。

第四集の最後に置けば、問いが次のように深くなる。

```text
誰へ頼むか → 何を帳面に載せるか → 誰に権限を渡すか
→ そもそも、どの問いへ物質を使うか
```

ただし、`planing`の現時点には本文がないため、これは配置予約に留める。

## 5. 巻間の年代記

各巻の間に二ページだけ、次の制度が必要になった理由を書く。説明ではなく、前巻の物が次巻へ運ばれる場面にする。

### 第一集 → 第二集

> 谷の壁を写した紙が、町へ運ばれた。先生は教材にし、役人は判定表にし、商人は値札にした。同じ紙だったが、三人は別のものを数えた。

### 第二集 → 第三集

> 星の多い職人へ仕事が集まった。職人は忙しくなった。そこで町は、職人を写した。待つ者はいなくなった。

### 第三集 → 第四集

> 店が増えすぎて、誰も全部を試せなくなった。町は使いに財布を渡し、店の帳面を持たせた。使いは人より速く買った。帳面を閉じて歩くことはなかった。

この短い連結だけで、別々の寓話が制度の時系列になる。

## 6. 各巻末の「未来予想」

未来予想は教訓ではなく、作品から導いた観測項目にする。

| 巻 | 予想 | 外れの条件 |
| --- | --- | --- |
| 第一集 | エージェント数より、モデル・データ・検証器の独立性が製品価値になる | 体数だけで品質が安定し、独立性を測る需要が生じない |
| 第二集 | 教育・採用は道具込み／道具なし／過程説明の評価へ分かれる | 成果物だけの評価が維持され、過程や対面評価が増えない |
| 第三集 | 表面上異なるサービスの共通基盤が、相関故障として問題になる | 基盤が十分に分散し、共通故障が主要リスクにならない |
| 第四集A | skill Registry・Router・即時決済がエージェント市場の標準になる | 汎用AIが専門能力を内部化し、外部取引が増えない |
| 第四集B | 市場の中心がskillから権限・データ・資源・責任へ移る | 権限や責任も汎用系の内部で一体化し、外部主体を必要としない |

予測には日付を付け、半年ごとに追記する。作品の並びは、この観測結果によって将来組み替えてよい。外れた予測を作品本文へ戻して辻褄を合わせてはいけない。

---

## 7. 制作順

刊行順と制作順は違う。いま書くべき順は次のとおり。

1. **第一集の橋を直す**——『象を撫でる者たち』の名付けが生まれる過程。
2. **第二集に明るい一作を足す**——道具による実益を、後の反転のためでなく一作として成立させる。
3. **第三集の空白を埋める**——系譜と探索。これが無いと市場は集中の話一色になる。
4. **第四集をA/Bに分岐させて二本ずつ書く**——未来を一方向へ決め打ちしない。
5. **最後に巻間の年代記を書く**——先に書くと、作品が年代記の穴埋めになる。

## 8. この構成の危険

### 世界観が説明装置になる

同じ語を使うだけで作品が繋がったように見える危険がある。壁や帳面は、各作で実際に別の結果を返さなければならない。

### 時系列が進歩史観になる

後の制度が前より賢いとは限らない。各巻は問題を解いて次へ進むのではなく、前の解決が次の問題を作る。

### 将来予想が作品を古くする

予測は巻末へ隔離する。寓話本文にx402、Registry、モデル名を出さない。

### 四巻すべてが暗くなる

各巻に最低一作、驚き、可笑しみ、喜びを置く。特に第三・第四集では、市場や使いが実際に人を助ける場面が必要である。

---

## 最終像

この構成で全巻を読んだとき、読者が見るのは「AIが賢くなる歴史」ではない。

```text
予測する道具
→ 記憶する壁
→ 道具を前提にした制度
→ 複製と集中の市場
→ 自分で買う使い
→ 存在を決める帳面
→ 開けられる範囲を決める鍵
→ どの問いへ水を使うかという政治
```

賢くなっているのは一体のAIではない。**AIを置いた結果として、世界の側が次の形へ変わり続ける。**

短編集を時系列にするなら、これを背骨にするのがよい。
