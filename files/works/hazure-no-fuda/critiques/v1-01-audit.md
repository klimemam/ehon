## 一　疑い

### 1（中）「裏の書きようが写しと同じ店は、知らない店に数えない」が、七年めの観測に対して発動していない

本文は、七年めに二つのことを同じ段で書いている。

> 星の多い、知らない屋根屋の屋根も、同じ軒の裏から漏った。

> 裏の書きようが写しと同じ店は、知らない店に数えない。裏の白い店と、写しと違う駄目の書いてある店に、印の客を回す。

**この屋根屋の裏の書きよう（同じ軒の裏から漏る）は、写しの店の欄と同じである。** 規則をそのまま当てると、七年めに、知らない店の母数は十から九へ落ちる。落ちた店には印の客が回らない。

ところが本文は、そのあと二箇所で、母数が十のままだったかのように動く。

1. **数**——「十あった知らない店は、やっつになった」。自己検算も「十 − 閉みっつ ＝ ななつ。染物屋がひとつ戻って、やっつ」と書く。**七年めの規則による除外が、どちらの勘定にも入っていない。**
2. **閉店の理由**——「月にみっつよっつの客は、店を立たせはしない。ただ、手を止めさせずにいた。**その客が絶えたのである。**」十五年めの箱の撤去を、三軒の閉店の原因に置いている。だがこの屋根屋の印の客は、規則の側で七年めに絶えているはずである。十六年めに閉まった屋根屋がこの店なら、原因は箱の撤去ではない。

**逃げ道はひとつある。** 知らない屋根屋が二軒以上いれば、規則で落ちたのと閉まったのを別の店にできる。本文は一軒とも二軒とも書いていない（「知らない屋根屋」は一年めと七年めに定冠詞的に二度出るだけである）。**書けば消える疑いである。**

なお本作は「良さで選ぶな、駄目の出方の違いで選べ」を機構の芯に置いている。その芯の規則が、本文の中で一度も**除外の側**に働かないことは、機構の上演としても穴になっている。

### 2（軽微）染物屋の「二年留めた手」

時間列を本文から復元すると、

| 年 | 出来事 |
| --- | --- |
| 一年め春 | 決めごと（風の翌春） |
| 三年め | 蒸し暑い夏／秋に甕 |
| 四年め | 北の外れの麹が別の月に酸える |
| 五年め | 目利き |
| 七年め | 長い雨／帳面を裏から |
| 八〜十四年め | 静かな七年 |
| 十五年め春 | 箱を下げる。その年のうちに染物屋が閉まる |
| 十六年め | 桶屋・屋根屋 |
| 十七年め春 | 「三年めの春の寄り合い」で三軒を数え、箱が戻る |
| 十八年め春 | 染物屋が「次の春」に藍を建てる |

閉店（十五年めの春以降）から再開（十八年め春）までは二年三月〜三年である。「二年留めた手」は、**丸年で数える読み（十六・十七年めの二年）**なら成立する。成立するが、他の年数がすべて起点からの序数で書かれている中で、ここだけ数え方が違う。

## 二　検算して通った項目

| 項目 | 結果 |
| --- | --- |
| 週ふた度 × 百枚に一枚 ＝ 年にひと度 | 通る。52×2＝104 引き、1/100 で年 1.04 度 |
| 四百軒 × 年百度 ÷100 ÷十店 ＝ 月みっつよっつ | 通る。416÷10＝41.6／年 → 3.5／月 |
| 札を箱へ戻す | 通る。復元抽出なので百分の一が保たれ、同日に複数人が印を引くことも許される |
| 店数 10 − 3 + 1 ＝ 8 | 本文の「みっつ」「染物屋がひとつ戻る」とは合う（ただし疑い1） |
| 「百にひとつほど」の甕 | **条件つきで通る。** 四百軒の百分の一＝四軒。麹屋の印客は年およそ四十だから、そのうち味噌の仕込みに使われる買い物が十分の一ほど（＝各家が麹を年に十度ばかり買い、そのうち一度が甕ぶん）でなければならない。この前提は本文に書かれていないが、麹屋という設定と矛盾はしない。自己検算の言い方（「麹の買い物のうち印の分はおよそ百にひとつ」）は、一店あたり年四十という本文の数と直結していない |
| 十七年の時間線 | 上表のとおり通る。逆転なし |
| 「静かな年が七つ」＝八〜十四年め | 通る |
| 「幾人か」が麹屋を支える／婆の「半分は、当たり」 | 通る。酸えなかった甕は四軒ほどで、「幾人か」と桁が合う |
