## 三　最重点：bango-o-utsu-mono v5 の解決策は成立しているか

**成立している。** 申告された解決策（「三つ」は鋳型の総数ではなく**蔵にある鋳型の数**である）を疑ってかかり、依頼された八問を一つずつ潰した。全文は [v5-01-audit](../bango-o-utsu-mono/critiques/v5-01-audit.md)。要点：

| 問 | 結果 |
| --- | --- |
| 1. 数えられていない鋳型の日は来たのか、まだか | **通る。** 一の壺の鋳型の日はまだ来ていない。「なぜ何十年も来ないのか」への答えは作中前例——三つめの鋳型自身が四十年以上使われて日が来ていない。日の分布に上限を課す記述は無い |
| 2. 古い壺の鋳型は捨てられている→日は過ぎたのでは | **通る。** 捨てられることと日が過ぎることは独立。三十の組がその実証（鋳型はとうに無く、日はいま来た） |
| 3. 三十しか残らない理由 | **書かれていない**（疑い2）。改稿者も認めている |
| 4. 「店と蔵に打った」の一行と既存記述 | **衝突しない。** 三万八千二百・連番性・二度目の書き出しのすべてと整合。副産物として三十の組の「番号のないもの」に根拠が立った |
| 5. 算術 | **合う。** 38,200−数百 ≈ 37,900÷3 ≈ 12,633 →「一万をこえる」×2。残存＞一万。百日＝日に百件あまり |
| 6. 年寄りの年齢 | **合う。** 打ちはじめから約四十五年、現在六十代半ば。子どものころ（約五十五年前）＞打ちはじめ（約四十五年前） |

## 四　他の四作——申告の検証と、小さな変更が壊したものの有無

### aru-hi-wakatta v6：支持する

- 変更は申告どおり本文一文（「そして、**見に来た者のなかに、**鍵の数を数えていた者は、ひとりもいなかった」）と巻末の対応行のみ。diff で確認
- **弟子と師匠は本当に除外されるか**——される。「見に来た者」は同じ節の冒頭「ときどき、町の者が見に来た」で定義済み。弟子（「これ以上取られたら」と数を口にする）も師匠（延べ九本取り、一本返す）も見に来た者ではない。v5 の反例は消えた
- **文として自然か**——「〜のなかに、〜者は、ひとりもいなかった」は読点が一つ増えるが一意に読める。不自然さはない
- 後段で錠前を持ってくる町の者は、この文の時制（それまでの来訪期）の外にあり、数える描写も無い。反例にならない
- 巻末の新しい右列「数えていたのは、取る側と取られる側だけである」も全数照合した——数えている者は師匠と弟子の二人だけであり、「だけ」は成り立つ
- 鍵の総数・推移（9→…→1、弟子1＋師匠8＝9）は一字も触れられておらず不変

## 六　所見

1. **「修正が新しい誤りを生む」は、今回は大きくは成り立たなかった。** 前提（今回も入っている）で見たが、五作中三作は新しい疑いゼロで通った。小さく直した四作のうち三作（弟子・帳面・書きつづけるもの）は、変更の波及先を全部当たっても壊れたものが見つからない。
2. **新しい疑い二件は、どちらも「本文より強い付属文書」または「新場面の暗黙の帰結」であり、算術・時間・指示語の層は五作とも無傷である。** 前回と同じく、破綻の層は本文の下ではなく付属文書と本文のあいだにある。
3. **bango v5 の疑い1 だけは型が違う。** これは新しい誤りではなく、**前回検算が「直すときに同時に決めよ」と明示した未決事項を決めずに、その上に新しい場面を建てた**ものである。v4 では「書かないこと」が有効な回避だったが、v5 が全数量化（割れていない壺を数えた）を導入した瞬間、書かれていない集団が数えの中に入った。回避は、回避が守っていた条件ごと引き継がなければならない——前回の所見3（「前版の修正を守ることと、その修正が何によって守られていたかを覚えていることは、別の仕事である」）と同じ形が、検算指摘の側でも起きた。
4. **検算節の申告は、今回は五作とも実態と一致していた。** 前回三件あった「申告どおりでなかったもの」は、今回はゼロである。ただし bango の検算節は疑い2 を「本文では説明していない」と自認しており、自認された欠落は欠落のまま残っている。
