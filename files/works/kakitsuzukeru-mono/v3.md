# 書きつづけるもの（第三稿）

村はずれの小屋に、字を書きつづけるものがあった。

昼も夜も、筆の音がした。

朝、戸を開けると、書き上がった紙が、戸口まで積んであった。

***

村じゅうの書き物を溶かして、作られたものである。

溶かした字しか、書かない。

だが、並べ方は数えきれなかった。

***

村は喜んだ。

数えきれない並べ方のなかには、まだ誰も並べたことのない、良い話があるはずだ。

***

村は、読む係を置いた。

ひとりでは足りなかった。十人にした。百人にした。

百人は、小屋の前に並んで、朝から晩まで読んだ。

読み終えた紙は、後ろの山に積んだ。

まだの紙は、前の山に積んだ。

前の山は、毎晩、高くなった。

後ろの山より、いつも高かった。

***

村は、良い話を見分ける決まりを作ることにした。

古い話を覚えている者を集めて、語らせた。

聞きながら、似ているところを書き出した。

出だしは、困りごとから。なかほどで、三度つまずく。終わりは、短く切る。

決まりで読むと、速かった。

出だしが違えば、そこで捨てられた。

捨てた紙は、焚き付けに回された。

前の山は、はじめて低くなった。

***

決まりで選ばれた話は、広場で読み上げられた。

村の者は、同じところで笑い、同じところで泣いた。

どれも、村に伝わる話に似ていた。

***

読む係のひとりが、風で飛んだ紙を拾った。

決まりなら、出だしで捨てる紙だった。

終わりまで、読んでしまった。

その日から、決まりを使うのをやめた。

***

出だしがどうでも、終わりまで読んだ。

一日に読める数は、減った。

係を外された。

それでも朝ごとに通って、焚き付けの山から、紙を拾って読んだ。

捨てる紙は、囲炉裏にくべた。

くべた紙が燃えきるまで、見ていることがあった。

捨てられない紙は、脇に積んだ。

脇の山も、読み返しては、くべて減らした。

一年がたった。

残ったのは、一枚だった。

***

一年で一枚だけ選んだと聞いて、村の者は広場に集まった。

その一枚が、読み上げられた。

途中で、笑った者がいた。どこがおかしいのかは、言えなかった。

途中で、腹を立てて帰った者がいた。なぜ腹が立つのかも、言えなかった。

終わりまで聞いて、もういちど、と言った者がいた。

もういちど読まれても、その者は、まだ座っていた。

良いとも、悪いとも、誰も言わなかった。

似た話が、無かったからである。

***

村の者は、その一枚を蔵にしまった。

良い話かどうかは、あとの者が決めるだろうと思ったからである。

***

あとの者は、決まりで選ぶことを覚えていた。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 小屋・筆の音・戸口まで積まれた紙 | 生成器の体。中身は描かない——**観測できるのは音と出力だけ** |
| 村じゅうの書き物を溶かして作られた | 現実に無い設定はひとつ。[`kabe-to-igata`](../kabe-to-igata/v1.md) と世界を共有する（壁を溶かして鋳型を鋳る） |
| 溶かした字しか書かない。だが並べ方は数えきれない | **生成の範囲。** 分布の外は出ないが、分布の中は尽きない |
| 試1：読む係を十人、百人にしても、前の山は毎晩高くなる | **生成は解決した。認識が追いつかない** |
| 試2：覚えている者から決まりを作る | 選別基準は、既にある良い話からしか作れない |
| 決まりで読むと速く、山がはじめて低くなる | **基準は、目に見える問題を実際に解く。だから手放されない** |
| 選ばれた話に、村中が同じところで笑い、同じところで泣く | **基準の相関は、反応の相関になる。** 基準を作った瞬間、基準の外は選べなくなる |
| 出だしで捨てられ、焚き付けになる紙 | 基準外の候補の行き先。**不可逆** |
| 試3：決まりを使わずに一年。くべた紙が燃えきるまで見ている | **検証器の無い選別の代償。** 捨てた判断の正しさを、教えてくれるものが無い |
| 一枚への反応が割れる。誰も理由を言えない | **未知の傑作には照合先が無い。** 良いと言うための、似た話が無い |
| 蔵にしまう。あとの者が決めるだろう | 判定の先送り |
| あとの者は、決まりで選ぶことを覚えていた | 結末の型＝気づかない。**その一枚は、二度と読まれない** |

## 文脈

**系譜**：無限の猿定理（Borel, 1913）→ 本作

古典の主張は「乱数と無限の時間があれば、あらゆる文字列が書かれる」である。

**AI時代に反転するのは、そこではない。**

| | 猿 | いま |
| --- | --- | --- |
| 生成 | 天文学的に絶望的 | **数秒で出る** |
| 選別 | 照合先がある（ハムレットは既知） | **未知の傑作には照合先が無い** |
| 書けるもの | **何でも** | **読んだものの並べ替えだけ** |

**そして最も鋭い反転がここにある。**

> **無限の猿は、何も知らないから、何でも書ける。**
> **この村のものは、全部知っているから、書けないものがある。**

猿定理の力は、乱数に偏りが無いことから来ていた。**学習したものは偏りしかない。** シェイクスピアで訓練したものは、シェイクスピアが次に書いたはずのものを書けない。

これは [`docs/thesis.md`](../../docs/thesis.md) 命題4（誤りの相関）と、帰結（蒸留による裾の消失）に、まったく別の道から着いている。

**そして本作の二歩目は、生成の側ではなく選別の側にある。**

| | 内容 |
| --- | --- |
| **半歩** | 大量に生成できるようになった。**誰でも思いつく** |
| **一歩** | 読む速さが追いつかない。だから選別基準が要る |
| **二歩** | **基準は、既にある良い物から作るしかない。だから基準を作った瞬間、基準の外は選べなくなる。** 問いが「どう作るか」から「**新しいものを、新しいと認識できるのか**」に変わる |

## 関連

- **[帳面にない店](../chomen-ni-nai-mise/v4.md)** ——帳面が書けないものは存在しないことになる。決まりが選べないものは、良いかどうか決まらないままになる。**同じ機構の別の面**
- **[写せる名工](../utsuseru-meiko/v5.md)** ——比べる相手がいないので誤りに気づけない。ここでは比べる相手がいないので**良さに気づけない**

## 未検証

- 「基準は既にある良い物から作るしかない」は強い主張である。**人間の批評も同じ制約下にあるはずで、それでも新しいものが認識されてきた歴史がある。** 本作はその経路（時間をかけた再評価、少数の擁護者、別の共同体への移動）を描いていない
- 「一年かけて一枚」の一年は作者が置いた数である

## v2からの変更点

[像01](critiques/v2-01-fable-child.md)・[力01](critiques/v2-01-fable-force.md)・[規約検査](../log/critiques-fable-rules.md) への応答。**結末の一行と、その手前の蔵の場面は、v2 と一字一句同じである。** 両批評とも「結末は正しい。そこへ至る重さが積まれていない」と診断したので、今回の仕事は結末ではなく足場である。

### 足した場面（いずれも「試す→世界が返事をする」の形。規約5）

1. **冒頭に体を与えた**（像01）。小屋・筆の音・戸口まで積まれた紙。何であるかは言わない——像01自身が「音と紙の山があれば、子供は絵を持てる」と書いたとおりにした
2. **紙の山**（像01）。「書かれる速さのほうが、速かった」という一行の要約を、前の山が毎晩高くなる場面にした
3. **決まりの中身と、決まりの成功。** 抽象名詞三つ（調子・折れ方・余韻）を、子供が絵にできる三つ（困りごとから・三度つまずく・短く切る）にした。選ぶ動作（出だしで捨てる）と捨て先（焚き付け）を与えた。決まりが山を低くする場面を足した——**決まりが最後まで手放されない理由が、これで世界の側に立つ**
4. **選ぶ者に重さを与えた**（力01）。風で拾った一枚が転機。係を外される代償。くべた紙が燃えきるまで見ている、という取り返しのつかなさ。恐れは説明せず、手の動きだけで書いた
5. **一枚への反応が割れる場面**（力01の提案を採用）。決まりで選ばれた話の「同じところで笑い、同じところで泣いた」と同じ舞台（広場）に載せ、割れ方が対比になるようにした。笑った者も怒った者も理由が言えない。いちばん強い反応は「もういちど」で、その者も理由を言わない

### 削った説明

- 「書かれる速さのほうが、速かった」「その決まりで選んだ」「選ばれた話は、たしかによかった」「良い話かどうか、誰にもわからなかった」——いずれも場面が言うようになったので削った

### 採らなかった指摘・形を変えて採った指摘

- 像01の「蔵に住まわせる」案 → **小屋にした。** 蔵は結末で一枚をしまう場所として一度だけ使いたい。同じ語が二つの建物を指すと、最後の蔵の絵が濁る
- 力01の「回して読んだ」案 → **広場の読み上げにした。** 決まりで選ばれた話と同じ舞台に載せないと、反応の割れ方が対比として立たない
- 規約検査の「気づかない ×2（monban と重複）」→ 結末の型は変えない。改稿の前提が「結末は正しい」であり、規約7の字義（直前の作と同じ型）は系列順が未宣言のため判定不能と検査自身が述べている
- 音の批評は本作に指摘なし（空振り報告）。**短文体は既に声に乗っている**ので、足した場面もすべて同じ文長で書いた

### 検算した項目

- **冒頭の制約（村じゅうの書き物は溶かされている。[v1検算](critiques/v1-01-audit.md)）**：決まりは「古い話を覚えている者を集めて、語らせた」ことから作る。後段に古い書き物への参照は無い。v2の修正を維持
- **山の増減**：決まりの前は「毎晩、高くなった」（書く速さ＞読む速さ）。決まりの後は「はじめて低くなった」（出だしで捨てるので、さばく速さが上回る）。矛盾なし
- **時系列**：決まりの成立 → 風の一枚 → 決まりをやめる → 遅くなる → 係を外される → 焚き付けの山から拾う。焚き付けの山は決まりの成立後にしか存在せず、外された者の読む紙の供給源として前後が合う
- **数**：十人→百人、一年→一枚のみ。算術なし。季節の列挙をしていない（系列で頻発した「季節の前後が主張と逆」の型を、列挙しないことで避けた）
- **一枚の同一性**：一年の選別の残り＝広場で読まれた一枚＝蔵に入る一枚。一本の線で追える
- **太字**：本文（frontmatter後〜対応表前）に `**` ゼロ
- **結末**：最終行と蔵の場面は v2 と一字一句同一。`ending_type: 気づかない` と一致
