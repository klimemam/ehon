# 頼む理由（第二稿）

町の椀屋は、塗師に頼んだ。
塗師は、木地師に頼んだ。
木地師は、山の樵に頼んだ。

椀ひとつが、山をひとつ下りるあいだに、三度、頼まれて生まれた。

塗師も、木地の挽き方くらいは知っていた。だが知っているのは頭で、手は知らなかった。
それに、日は一日しかない。塗るだけで、日は暮れた。

だから、頼んだ。
町じゅうが、そうやって仕事を回して食っていた。

***

ある年の市に、手形売りが来た。

職人の手を紙に押しつけると、手の癖ごと、紙に写る。
その紙を自分の手に当てた者は、手が、写されたとおりに動く。

並んでいたのは、都の名工たちの手だった。

手形からは、写しが取れた。写しからも、また写しが取れた。
だから値は、日ごとに下がった。

***

椀屋の店から、客が絶えた。
客が来ないので、椀屋は塗師に頼まなくなった。
頼まれないので、塗師は木地師に頼まなくなった。
頼まれないので、木地師は樵に頼まなくなった。

頼みは、川上へ向かって、順に消えた。

最後に残ったのは、山の主への払いだった。
木は、紙からは生えない。

町の者は、手すきの折に紙を当てて、自分の椀を自分で挽き、自分で塗るようになった。

***

塗師は、値を半分にした。

誰も来なかった。

隣の家の縁側で、嫁が椀を塗っていた。
その手つきには、塗師の手つきより、ためらいが無かった。

***

塗師は、早くした。
十日かけていた塗りを、五日で仕上げるすべを、夜なべで覚えた。

五日、と書いた札を、戸口に下げた。

札の前で足を止める者は、いた。
足を止めた男の袖からは、折りたたんだ紙がのぞいていた。

戸を叩く者は、いなかった。

***

塗師は、山の小屋にこもった。
ひと冬かけて、都のどの手形にも無い塗りを、自分の手に覚えさせた。

春の市に、その椀をひとつ、並べた。

足を止める者は多かった。褒める者もいた。
頼む者は、いなかった。

隣の筵では、手形が売られていた。
椀ひとつの値より、椀を塗れる手のほうが、安かった。

***

夏、日照りが来た。

町の井戸が涸れて、湧きの絶えない井戸は、川向うの一軒の庭の、ひとつだけになった。
朝から、桶を提げた列ができた。

塗師は、井戸の主に言った。
「汲むのと運ぶのを、わしが引き受けよう。水代の半分でいい」

主は笑った。
「汲む手なら、町じゅうにある。水の出る土は、うちの庭にしか無い」

それから、列の先の桶に手を貸しながら、言った。
「頼むというのは、無いものを借りに行くことだ。わしも昔は、椀はあんたに頼んだ。この手が、無かったからな」

主は、片手を開いてみせた。
なんの変哲もない、汲むだけの手だった。

***

峠の関では、札を持つ男が、日なたで居眠りをしていた。
その膝の前に、都から下ってきた者らが、銭を置いて通った。

畑の主の門前には、畑を借りたい者の列ができていた。

塗師は、列のいちばん後ろに並んだ。

***

塗師は、畑を借りた。
看板は、下ろさなかった。
叩く者のいない戸の内で、塗師は、自分の椀を塗った。

***

塗りものは、どの家でも、冬の夜なべ仕事になった。

冬の宵、通りを行けば、どの障子にも、椀を塗る手の影が映っている。
影は、どれも、同じ形に見える。

どれが塗師の影なのか、道から言い当てられる者は、いない。

## 作者による対応表

| 寓話 | 主張 |
| --- | --- |
| 椀ひとつが、三度、頼まれて生まれる | 多層の下請け。認知の外注の連鎖（[`backlog-agent-economy.md`](../backlog-agent-economy.md) S1） |
| 知っているのは頭で、手は知らなかった | 前提1：技能は写せない（暗黙知） |
| 日は一日しかない | 前提2：時間は有限。**この二つが多層下請けの柱である** |
| 手形 | 規約6の設定。技能の複製可能性（skill＝prompt+tools が写せる） |
| 写しからも写しが取れ、値は日ごとに下がる | 限界費用がほぼゼロに落ちる |
| 頼みは、川上へ向かって、順に消えた | C_外注 ＞ C_自前 の連鎖的な成立（素材 §13 の式） |
| 木は、紙からは生えない | 写せないもの（在庫・権利）だけに払いが残る（素材 §16） |
| 値半分 → 来ない | 返事①。値は頼む理由を作らない |
| 袖から紙がのぞく男 | 返事②。待ち時間そのものが消えた。頼んで五日待つより、今日始めるほうが早い |
| 褒める者はいた。頼む者はいなかった | 返事③。腕を上げても来ない。**理由は毎回、腕と無関係である** |
| 椀ひとつの値より、椀を塗れる手のほうが安い | C_自前 ＝ 道具代。腕の値段が、腕の産物の値段を下回る |
| 「汲む手なら、町じゅうにある。水の出る土は、うちの庭にしか無い」 | 返事④。残る頼みは資源と権利にだけ付く |
| 「頼むというのは、無いものを借りに行くことだ」 | **本作が発見する単位：頼む理由。** 腕でも値でも早さでもなく、相手に無いものを自分が持っているかどうか（[`phases.md`](../phases.md) §10） |
| なんの変哲もない、汲むだけの手／居眠りする札の男／畑の列 | 残る者は、井戸を持つ者、通行札を持つ者、畑を持つ者。誰も賢くない |
| 障子の影は、どれも、同じ形に見える | 分業の溶解の完成。ただし主張は見えの同一までで、運動の同一ではない——手形に無い塗りを覚えた手が、ひとつ、町にある |
| どれが塗師の影なのか、言い当てられる者はいない | 結末の型＝主語識別不能。問いにせず、識別不能という事実で置く |

## 文脈

系譜は「なぜ、人は仕事を人に頼むのか（分業と、企業や市場の境界）」。

| 層 | 先行者 |
| --- | --- |
| 分業は豊かさの源であり、市場の大きさに限られる | スミス『国富論』第一篇1〜3章 |
| 頼むには費用がかかる。だから組織の内と外の境界が決まる | コース「企業の本質」(1937)、ウィリアムソン（取引費用。[`survey-toc.md`](../survey-toc.md) G21） |
| 取引の費用が下がると、制度そのものが壊れる | ノース（G20） |

先行者はみな、「腕は写せない」を書かずに前提していた。書かれていないほど当たり前だったからである（[`method.md`](../method.md) §1）。その前提を外すと、頼む理由の在り処が腕から持ち物へ移る。「AIエージェント同士が取引する経済が来る」は半歩で誰でも言う。**その経済の深い階層が来ない理由**を言うのが本作である（[`backlog-agent-economy.md`](../backlog-agent-economy.md) §2 S1：二歩の判定）。

この主張は検証可能な予測と対になっている。[`phases.md`](../phases.md) §2 の外れ条件——2028年までに、権利・データ・設備・資本・身体のいずれも持たない純粋な認知作業の外注が、エージェント間取引で有意な割合を占めたら、本作の機構は外れである。

なお本作は対の一編を持つ。[`mata-tanomu/v3.md`](../mata-tanomu/v3.md) は、本作が消した「頼む理由」が別の単位で立ち上がる側（v_希少）を書く。本作単体では、二つの速度の片側しか描いていない。

## v1からの変更点

[検算v1-01](critiques/v1-01-audit.md)・疑い2（中）への応答。最終行（型＝主語識別不能）には触れていない。

### なぜ変えたか

最終場の一行「影は、どれも、同じ形に動く」は、運動の同一を主張していた。だが本文は、その例外を自分で作っている——塗師はひと冬かけて「都のどの手形にも無い塗り」を手に覚えさせ、結末でも自分の椀を塗っている。手形でない手が、ひとつ、町にある。v1 の検算5は「影の解像度では判別できない」と観測の限界で説明しており、本文と検算が別のことを言っていた。過大なのは本文の側なので、本文を観測の言明に落とした。

### 変えた範囲

本文一箇所、一語。「影は、どれも、同じ形に動く。」→「影は、どれも、同じ形に見える。」（検算v1-01の直し案のとおり）。ほかは表題（初稿→第二稿）のみで、本文はそれ以外 v1 と一字一句同一。対応表の当該行を本文に合わせて更新し、文脈の対の一編へのリンクを [`mata-tanomu/v3`](../mata-tanomu/v3.md) に更新した。設計の記録（「写せる名工」との衝突の判定・結末の型の選定・検算1〜10）は v1 を参照。

### 洗い出し（grep）

- 「同じ形」——本文1件（今回の行のみ）。対応表に1件（本文に合わせて更新済み）
- 「動く」——本文1件（「手が、写されたとおりに動く」＝手形の規則の側。道具の設定であり、影の観測とは別）
- 「見える」——本文1件（今回の行のみ）

### 検算した項目

1. 疑い1（重・時間列の接続）は後編の側で直した。同日の [`mata-tanomu/v3`](../mata-tanomu/v3.md) が「屋根屋は、八年、瘦せた」に改め、本作の時間列（値半分 → 五日の札 → ひと冬 → 春の市 → 同年夏の日照り → 畑の列）は無変更のまま接続する。検算v1-01の判定（本作の列を繰り上げると検算1・2と四段の試しが同時に動く）に従い、前編の筋は動かしていない。
2. 「見える」と検算5の一致。v1 検算5「影の解像度では手の癖の個体差は判別できない」が、そのまま本文の言明になった。塗師の手は同じ形には動かないが、障子越しの影は、道から同じ形に見える。最終行「どれが塗師の影なのか、道から言い当てられる者は、いない」は、観測の限界の帰結として立つ。v1 の検算1〜10のうち、5以外の九項は本文無変更につきそのまま成立する。
3. 疑い3（軽微・普及速度）は見送り。後編の初年普及は、本作の「写しからも、また写しが取れた」「値は、日ごとに下がった」が支える。本作の一年半は手形が椀ひとつの値を下回る時点であり、仕事をひとつ頼む値より紙が安くなる時点は、それより早くてよい。検算者も「矛盾とまでは言えない」としている。
4. 結末の型。主語識別不能のまま。「見える」への一語で、最終場の三行（障子に影が映っている／同じ形に見える／言い当てられる者はいない）はすべて道からの観測に揃い、最終行と同じ足場に立った。
5. 規約8。本文に太字なし（grep確認）。
