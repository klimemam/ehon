# 検算——頼む理由 初稿（新作）

対の一編 [`mata-tanomu/v2`](../../mata-tanomu/v2.md)（`consumes: tanomu-riyuu/v1`）と突き合わせた。

## 一　疑い

### 1（重）後編の時間列が、本作の時間列に接続しない

本作から復元できる並びは次のとおりである。

| 位置 | 本文 | 経過 |
| --- | --- | --- |
| 起点 | 「ある年の市に、手形売りが来た」 | 〇年 |
| | 客が絶える／頼みが川上へ消える／町の者が自分で挽き自分で塗る | |
| | 塗師、値を半分にする | |
| | 塗師、十日→五日にして札を下げる | |
| | 塗師、山の小屋に**ひと冬**こもる → 「春の市に、その椀をひとつ、並べた」 | 自己検算1が「手形到来から一年半後（翌々年の春の市）」と明示 |
| | 「夏、日照りが来た」→ 井戸の主 | 同年の夏 |
| | 「畑の主の門前には、畑を借りたい者の列」／塗師は列のいちばん後ろ | **同年（およそ二年め）** |

後編は、この「畑の列」を起点として十年を数えている。

> 手形が来て、十年がたった。
>
> あの年、畑の列には、屋根屋も並んでいた。塗師が並んだあとにも、列は伸びていた。屋根屋の番が来る前に、貸す畑は尽きた。
>
> **屋根屋は、十年、瘦せた。**

**畑の列が二年めなら、十年めまでは八年である。** 「屋根屋は、十年、瘦せた」は、畑の列を手形到来と同じ年に置いたときにだけ成り立つ。本作は同じ年に置いていない——値半分・五日の札・冬ごもり・春の市という四段の試しを、列の手前に積んである。

破れは二年ぶん。直し方は二通りあり、どちらを採るかで壊れる側が違う。

- **後編の「十年」を「八年」にする**——後編の柱（手形の年に葺いた屋根が十年めに一斉に古びる）は「手形が来て十年」のほうに乗っているので、屋根屋の年数だけを八年に下げれば済む。副作用が最も小さい。
- **本作の列を手形到来の年へ繰り上げる**——自己検算1（値崩れに一年半）と自己検算2（椀の値＞手形の値の成立時期）が同時に動く。四段の試しの積み上げも崩れる。

### 2（中）「影は、どれも、同じ形に動く」は、本文が作った例外を含んでいる

塗師は、ひと冬かけて「都のどの手形にも無い塗り」を自分の手に覚えさせた。結末でも「叩く者のいない戸の内で、塗師は、自分の椀を塗った」——**手形ではない手が、一つだけ町にある**、というのが本作の作った例外である。

最終場はこう書く。

> 影は、どれも、同じ形に動く。
>
> どれが塗師の影なのか、道から言い当てられる者は、いない。

自己検算5は「影の解像度では手の癖の個体差は判別できない」と、**観測の限界**で説明している。しかし本文の一行めは観測の話ではない。**動きそのものが、どれも同じ形だ、と書いている。** 塗師の手だけは、設定上、同じ形に動かない。

検算節の理屈（識別不能）と本文の一行（同一）が、別のことを言っている。片方だけを直せば消える——たとえば「影は、どれも、同じ形に見える」。一語で足りる。

### 3（軽微）値崩れの速さが、後編の初年の前提と噛み合わない

自己検算1は「値崩れの時間が経過している」として、手形が椀より安くなる時点を一年半後に置いた。後編は「手形が来た年、町の者は、たまっていた仕事を、みな自分の手で片づけた。屋根も、あらかたの家が、その年のうちに葺き替えた」——**初年に全戸へ紙が行き渡っている**ことを前提にする。

本作の「写しからも、また写しが取れた」「値は、日ごとに下がった」を採れば初年の普及は説明できるので、矛盾までは言えない。ただし、**同じ設定に対して、前編は「一年半かかる」、後編は「その年のうち」と、逆向きの速さを申告している。**

## 二　検算して通った項目

| 項目 | 結果 |
| --- | --- |
| 手形の値 < 椀の値 | 通る。椀＝木地代＋漆代＋手間、手形→紙代に漸近。前者が後者を下回らない |
| 樵まで消える連鎖が資源の壁で止まる | 通る。伐る技は写るが木と山は主の物。「最後に残ったのは、山の主への払い」と整合 |
| 残る払いの集合 | 通る。山・井戸・峠の関・畑。後編冒頭「井戸の前と、峠の関と、山と畑の主の門前だけ」と**完全に一致** |
| 井戸の主の台詞 | 通る。後編の引用「――頼むというのは、無いものを借りに行くことだ。」は**一字一致** |
| 手形の規則 | 通る。「紙に押しつけると写る／当てた者の手が動く」（本作）と「写した紙を手に当てれば、誰の手でも、同じに動く」（後編）は同じ規則 |
| 畑の列の順序 | 通る。本作「列のいちばん後ろに並んだ」／後編「塗師が並んだあとにも、列は伸びていた」。屋根屋が借りそこねることと矛盾しない |
| 井戸の場面の成立条件 | 通る。日照りで湧きの絶えない井戸が一つに絞られてから列を作らせている |
| 漆の乾き | 通る。十日→五日は工程の詰め。一晩で塗り上がる場面は無い |
| 規約8（本文に太字なし） | 通る（grep 確認） |
