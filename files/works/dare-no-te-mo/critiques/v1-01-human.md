# v1 批評01：安っぽさはないが、展開にワクワク感がない

**判定**：主題も文体も悪くない。だが**展開が無い。**

## これは物語ではなく静止画である

v1 の構造：

1. 大きな絵がある
2. 誰が描いたかわからない——多すぎるから
3. 寄与者たちの描写
4. 署名が無い
5. 評判になり、囲った者に銭が集まる
6. 女が「この耳はわたしが直した」と言う。証が無い
7. 問いで終わる

**世界の状態が、最初から最後まで変わっていない。** 絵は最初も最後も同じ絵である。6 だけが唯一の出来事で、それも一往復で終わる。

## 「壁と鋳型」との差

壁と鋳型には、**世界の状態を変える出来事が連続している。**

> 谷を出る → 水車が回らない → 散る → 壁が食い違う → 糸を張る → 壁が止まる → 糸を切る → 食い違いが戻る → 鋳型が古びる → 壁を溶かして鋳る

**一つずつが実験であり、結果が出るたびに世界が変わる。** だから次が気になる。

v1 の絵には実験が無い。誰も何も試していない。**女が一度だけ試して、一度で終わっている。**

## 次版への指示

**試す→世界が返事をする、を複数回重ねること。** そして、返事のたびに事態が悪くなる（あるいは複雑になる）こと。

女が一度で諦めるのではなく、**別の手を打ち、それも通らない**という段階を作る。壁と鋳型の水車と糸に当たるものが、この作品には要る。
